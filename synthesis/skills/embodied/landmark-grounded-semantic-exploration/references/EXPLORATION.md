# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Landmark chain & global map planning. The essential rule is to convert the question into an ordered chain of landmark goals or coarse map waypoints before attempting fine-grained search. The agent should first identify the highest-level spatial anchor (e.g., a massive building or a designated region on a satellite map), move to that area, and only then inspect the local target. This prevents the agent from aimlessly roaming a massive outdoor environment in a purely reactive manner.
  - Cross-scale control transition. Open urban or outdoor scenes require switching dynamically between large movement steps for area search and small movement steps for local verification. The agent should travel coarsely or utilize high-altitude views until the candidate landmark area is reached, then confidently slow down, descend, or reorient to execute precise egocentric inspections. This guarantees that small semantic payloads are captured reliably despite the enormous environment size.
  - Reactive confirmation checkpoints. A robust exploration policy must insert explicit visual confirmation checkpoints whenever a major landmark or map waypoint is reached. At each checkpoint, the agent should verify the semantic target visually (e.g., confirming if a hazy shape is smoke or just a cloud) and boldly adjust its internal search state. If the target is heavily occluded upon arrival, the agent must reactively compute new local waypoints to get a better angle.
  - Semantic follow-up after spatial narrowing. Once the correct region has been located, the agent should transition smoothly from spatial map navigation to pure semantic inspection. The policy should then definitively answer the core payload question, such as determining object color, store name, coffee availability, or the existence of hazards like fire. A brown-awning storefront located via maps still needs close-up semantic verification; relying solely on map metadata is prohibited.
  - Long-horizon ambiguity management. To handle massive environments, the rule is to preserve multiple hypotheses early, but force them to collapse strictly as new landmark evidence accumulates. The agent should maintain a small candidate set for possible regions or target objects, selectively discarding hypotheses only when a spatial relation or map coordinate is definitively falsified. This discipline prevents catastrophic cascading failures where choosing the wrong building at the start ruins the entire mission.
* **Target Trajectory Profile**:
  - Chained landmark or global-to-local dependency. A strong trajectory must fundamentally require spatial narrowing from a broad reference (like a city block or global map boundary) down to a highly specific local target. The agent should forcefully reject any city-space sample that asks about the nearest, immediately visible object without requiring a chain. The capability's core value lies in structured, multi-step search.
  - Visible large-to-local transition. The trajectory profile should contain clear, unmistakable visual evidence of moving from a coarse regional search phase to a local answer extraction phase. This dual-scale behavior explicitly differentiates landmark-grounded exploration from standard indoor close-range QA. A prime example should show sweeping aerial or long-street panning followed by zoomed-in, focused hovering near a specific storefront or vehicle.
  - Open-space geometric relevance. The data should heavily exploit the visual ambiguity of massive, open, or urban scenes where many candidate objects exist natively and significant viewpoint changes matter heavily. Trajectories must be discarded if the environment is too constrained to permit real navigational confusion. Tasks requiring long-horizon movement across varied topographies provide the best raw material for this skill.
  - Iterative visual confidence building. The stored path should include defining moments where the agent physically adjusts its viewpoint to verify a guess initially made from a long distance. For instance, paths where the agent dips below tree cover or sidesteps a barrier to double-check an occluded vehicle demonstrate genuine embodied reasoning. Purely straight-line flyovers without localized hovering are substantially weaker.
  - Answer-bearing terminal evidence. After the lengthy landmark chain or map waypoint sequence is resolved, the terminal trajectory state must provide an overwhelmingly clear view to answer the semantic payload confidently. The agent must reject sequences where the final target remains severely pixelated or blurry at the termination point. An unreadable sign or unrecognizable object category makes robust evaluation impossible.
