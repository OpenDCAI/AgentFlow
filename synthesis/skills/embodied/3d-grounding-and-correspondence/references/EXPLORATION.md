# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  * **Anchor-first multi-view sweep.** The core rule is to begin by locating stable anchors such as doorframes, bed edges, tabletops, or wall fixtures before searching for the target referent. First scan each observation for large, structurally persistent anchors, then note which anchors survive across views, and only then search for the candidate referent relative to those anchors. For example, if the target is 'the red suitcase near the bed,' the agent should lock onto the bed and side table first, because directly chasing the suitcase patch is brittle under viewpoint change.
  * **Instance disambiguation before point transfer.** The concept is to resolve object identity before attempting any pixel- or region-level correspondence transfer. The agent should first eliminate distractor instances of the same category, then confirm the exact object by local context, and only after that propagate point or region hypotheses into the next view. An edge case occurs when two chairs share the same color; in that case the agent must use neighboring geometry, such as being closer to the table leg or doorway, to choose the correct chair before matching points.
  * **Local geometry tracing.** The rule is to reason over corners, edges, surface normals, and part structure rather than whole-object labels alone. After identifying the object, the agent should describe the marked location in local terms such as 'front-left top corner' or 'handle midpoint,' then search for the same local geometry in the second view. For instance, if a point is marked on the rim of a mug, the agent should not jump to the mug center in the new view, because correspondence is defined over the same physical location, not the same object as a whole.
  * **View-change hypothesis generation.** The concept is to form an explicit hypothesis about camera shift or rotation before choosing the final grounded target. The agent should estimate whether the second view is left-shifted, right-shifted, closer, farther, or rotated, then use that motion hypothesis to prune impossible correspondence candidates. A concrete example is when a target appears more rightward in the second image because the camera moved left; the agent must reason about camera motion instead of assuming the target itself moved.
  * **Occlusion-aware re-identification.** The rule is to continue grounding even when the target is partially hidden or only partly visible in one of the observations. The agent should preserve a ranked set of candidate correspondences, use visible anchor relations to re-score them, and reject any candidate that requires impossible occlusion geometry. An edge case occurs when the referent is partly behind a lamp in the second view; the agent should still infer its identity if the remaining visible portion matches the expected anchored position.
* **Target Trajectory Profile**:
  * **At least two observations with shared structure.** A good trajectory must contain at least two observations that genuinely overlap in scene content and are connected by a recoverable viewpoint change. The agent should reject trajectories where the shared structure is too weak, because correspondence becomes guesswork instead of grounded reasoning. For example, two images that show entirely different sides of a house without any common anchor are not suitable raw material for this capability.
  * **Unique referent resolution.** The trajectory must support a single intended referent rather than multiple equally plausible ones. The agent should verify that category-level ambiguity can be broken by local context, surrounding objects, or precise point descriptions before keeping the trajectory. If two identical boxes sit beside the same shelf and no additional cue distinguishes them, the trajectory is too ambiguous and should be discarded.
  * **Recoverable local detail.** The trajectory must preserve enough local geometric detail to support part-level or point-level grounding. The agent should prefer views where corners, handles, edges, or marked regions remain at least partially visible across the pair. A bad edge case is a distant wide shot followed by a blurry close-up, where the corresponding physical point cannot be recovered with confidence.
  * **Moderate viewpoint change.** The desired profile includes real viewpoint variation, but not so extreme that correspondence collapses into ungrounded guessing. The agent should prefer small-to-moderate translation or rotation that creates meaningful parallax while still preserving recognizable anchors. A 180-degree flip from front view to hidden back view is usually too extreme unless exceptionally strong geometric anchors remain.
  * **Explicit distractors without impossible confusion.** A high-value trajectory should include plausible distractors that force real grounding work without destroying answerability. The agent should keep examples where multiple candidates exist but one can be ruled in using anchored relations and local geometry. For example, two mugs on a table are acceptable if only one is next to the notebook; five visually identical mugs in a cluttered pile are usually too noisy.
