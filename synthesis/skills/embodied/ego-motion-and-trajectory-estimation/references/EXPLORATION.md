# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  * **Temporal segment selection.** The core rule is to select clips where the motion segment of interest is long enough to support trajectory reasoning but short enough to remain analyzable. The agent should identify start and end times, preserve a coherent temporal window, and avoid mixing unrelated motion episodes into one sample. For example, a clip that includes both corridor travel and later idle camera shake should be trimmed so the benchmark targets intentional motion only.
  * **Landmark-based motion tracing.** The concept is to infer ego-motion by tracking how stable scene landmarks move relative to the camera over time. The agent should monitor doorframes, lane markings, furniture edges, or static buildings, and derive translation or rotation hypotheses from their changing projections. An edge case occurs when moving objects dominate the frame; the agent must ignore them and keep its estimate grounded on static structure.
  * **Motion-type disentanglement.** Exploration should separate translation, rotation, speed change, and object motion rather than collapsing them into one vague description. The agent should annotate whether the clip contains turning, forward travel, stopping, acceleration, or mixed motion before deciding what question type to synthesize. For instance, a clip with pure in-place yaw rotation is excellent for orientation questions but weak for path-length estimation.
  * **Pose-critical frame capture.** The rule is to preserve key frames around turns, stops, and goal-relevant state changes because those are where pose estimation becomes most informative. The agent should mark entry frames, turning points, and final alignment frames, then use them as anchors for later question construction. A concrete example is the moment just before a robot turns left into a room; dropping that frame can erase the evidence needed for the trajectory summary.
  * **Self-motion versus world-motion filtering.** The agent must deliberately distinguish camera motion from independent object motion in the environment. During exploration, it should flag moving cars, swinging doors, or animated humans as potential confounds and prioritize static background geometry for ego-motion estimation. A highway clip with many moving vehicles is still valid if lane markers and road boundaries remain visible enough to support the camera-motion estimate.
* **Target Trajectory Profile**:
  * **Ordered observations with clear temporal continuity.** A good trajectory must preserve the chronological order of observations and show a physically coherent path. The agent should reject jump cuts, discontinuous resets, or clips with missing intervals that break the motion narrative. If a robot appears instantly in a new room without transitional frames, the sample is unsuitable for trajectory estimation.
  * **Recoverable motion signal.** The trajectory must contain enough parallax, turn evidence, or path progression to support the target question type. For rotation questions, angular change should be visually evident; for path-length questions, translation over multiple frames should be visible. A nearly static clip with only sensor noise is not acceptable raw material.
  * **Low confound burden.** Good samples may include background activity, but the main ego-motion signal should still dominate the reasoning process. The agent should favor trajectories where static anchors remain visible through most of the clip and moving distractors do not fully occlude them. A busy street scene becomes poor material if buses fully block the lane markings for the entire time window.
  * **Question-type fit.** The trajectory profile should fit the eventual question type rather than trying to support every dynamic question at once. The agent should keep clips where one capability is especially well evidenced, such as a strong left turn for orientation or a long straight run for path length. A mixed clip can still work, but only if the chosen question targets the best-supported motion aspect.
  * **Metric plausibility.** The motion magnitude should be large enough to be meaningful and small enough to remain estimable from the available evidence. The agent should avoid clips with near-zero displacement for path-length questions or extreme fast motion that causes unusable blur. A gentle tabletop camera move is great for vector estimation; a violently blurred sprint clip is usually not.
