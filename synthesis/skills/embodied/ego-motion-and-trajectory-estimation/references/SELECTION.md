# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  * **Temporal evidence sufficiency.** Accept a trajectory only if the full motion claim can be justified from the preserved frame sequence. The selector should confirm that start state, intermediate turning or movement evidence, and end state are all represented. A trajectory summary question should not pass if the central turn is absent from the clip.
  * **Static-anchor availability.** Accept when static landmarks exist that let a solver disentangle self-motion from object motion. The agent should identify at least one persistent structural reference, such as walls, furniture, road edges, or buildings, before approving the clip. A fully sky-dominated drone clip with no anchored environment is a rejection for ego-motion tasks.
  * **Motion-type consistency.** The clip should support a single clean interpretation of the queried motion variable. If the question asks for yaw rotation, the selector should ensure that the evidence is not dominated by simultaneous heavy translation that makes angle inference unstable. A short in-place turn is far stronger for yaw questions than a complex spiral path.
  * **Answer robustness.** Accept only if a small change in solver wording or reasonable rounding does not alter which answer is correct. The agent should test whether the correct option remains stable under minor observational noise. If 46 and 47 degrees are equally plausible from the evidence, the sample should be widened into a range or rejected.
  * **Embodied relevance.** Prefer dynamic questions whose answer could meaningfully affect navigation, control, or world understanding in downstream embodied settings. Trajectory description, turn magnitude, and final pose are especially valuable because they connect perception to action planning. This keeps the synthesized data aligned with actual embodied-agent failure modes rather than abstract video trivia.
* **Rejection Criteria**:
  * **Jump-cut or reset clips.** Reject trajectories containing discontinuities that prevent physically coherent motion reconstruction. The selector should inspect for abrupt viewpoint changes inconsistent with feasible movement and discard them immediately. A clip stitched from two different rooms is unusable even if each part is individually clear.
  * **Dominant moving-distractor bias.** Reject when independently moving objects overpower the available static motion cues. The agent should not approve a path-length or camera-vector question if the main visual change is a passing vehicle while the camera barely moves. That would train object-motion confusion instead of ego-motion reasoning.
  * **Unbounded answer ambiguity.** Reject dynamic samples where multiple distinct trajectories fit the evidence equally well. The selector should ask whether the same visible sequence could reflect very different motions because of missing anchors or severe occlusion. If yes, the trajectory should not be synthesized into a quantitative question.
  * **Overloaded mixed-motion prompts.** Reject prompts that ask simultaneously for too many dynamic quantities from a weak clip. The benchmark should isolate one core competence at a time unless the evidence is exceptionally strong. A single short clip should not demand pose, speed, acceleration, path length, and yaw if only two of those are well supported.
  * **Low-value micro-motion.** Reject clips where the motion is so tiny that the task becomes annotation-sensitive rather than reasoning-sensitive. The agent should avoid synthesizing path or angle questions from near-static camera jitter. A few pixels of unintended wobble is not meaningful ego-motion.
