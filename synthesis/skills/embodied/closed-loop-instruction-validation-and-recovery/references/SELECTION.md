# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Feedback-to-Action Causal Integrity: The replanned objective reliably translates the explicit error code into its exact geometric or inventory inversion (e.g., 'Hand Full' directly causes 'Drop Item').
  - Deadlock-to-Branching Traceability: Demands strict evidence the agent tracked repetition history and forced a discrete topological or semantic strategy branch.
  - Trace-Grounded Functional Alignment: Confirms that retrospective evaluations accurately parse state variables, only stamping 'Success' if the execution trace maps the physical goal flawlessly.
  - Conditional Synchronization Success: Sequences must prove the agent stalled its progress naturally until the required environmental signal logically terminated the wait barrier.
* **Rejection Criteria**:
  - Endless Failure Loops: Automatically discard operations hammering a rigid boundary indefinitely without manifesting adaptive behavioral divergence.
  - Syntax-Only Success Affirmation: Reject evaluations declaring success purely because a text command parsed, ignoring a completely vacant real-world physical trace log.
  - Non-Reactive Status Monitoring: Dismiss instances where agents flee a delivery coordinate without securing definitive visual proof the payload was resolved.
  - Blind Temporal Pacing Disregard: Filter tasks demanding synchronous pacing audits where the agent ignores timestamps and evaluates speed solely by endpoint existence.
