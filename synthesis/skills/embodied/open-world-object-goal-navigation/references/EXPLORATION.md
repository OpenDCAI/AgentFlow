# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Instruction Semantic Decomposition: The primary operational rule demands translating complex natural language goals into layered visual filters. The agent dissects the core entity requirement, the secondary scale qualifiers, and the tertiary color/posture constraints to build a rigid matching template before committing to forward velocity.
  - Semantic Cluster Generation: While traversing unknown territory, the agent systematically links isolated entity detections into thematic room or zone clusters. Recognizing a 'stove' and a 'fridge' sequentially forces the internal memory mapping to logically tag that coordinate region as 'Kitchen', inherently assigning it future associative weight.
  - Object-Scene Co-Occurrence Extrapolation: Confronted with a destination objective, the agent cross-references the target against its known semantic groupings to deduce probabilistic relevance. An agent commanded to find 'soap' automatically biases its heading toward clusters tagged 'sink' or 'bathtub' and actively deprioritizes regions marked 'office desks'.
  - Multi-Scale Egocentric Variance: Recognizing open environments preclude global maps, the exploration loop forces active visual diversification. The agent alters its altitude, dynamically sweeping front, left, and downward fields of view continuously to defeat occlusions and capture latent landmarks hidden behind primary structures.
  - Confident Termination Distance Restraint: Finding the semantic target requires recognizing valid physical proximity rather than simply logging a distant pixel cluster. The exploration policy enforces a movement threshold requiring the agent to close the gap securely until object fidelity crosses an absolute safety confidence limit prior to stopping.
* **Target Trajectory Profile**:
  - Region-First Target Funneling: Top-tier data exhibits an unmistakable macro-to-micro approach funnel. The documented path initially highlights swift traversal locking onto a semantic zone (e.g., entering the broader kitchen), immediately followed by intensive, slow-motion localized sweeping to pinpoint the exact granular target.
  - Contextual Pruning Documentation: The ideal trajectory explicitly proves the agent physically pivoted away from a massive section of the area exclusively because the observed objects shared zero latent correlation with the queried goal state.
  - Obstacle-Aware Progression Paths: Trajectories must feature intelligent collision circumvention geometry. The movement footprint should indicate horizontal sidesteps, altitude adjustments, and velocity decays deployed to retain line-of-sight on structural anchors without slamming into dynamic or static world clutter.
  - Full Descriptor Utilization: A premium profile ensures that the simple category label ('bicycle') is violently insufficient to achieve the goal due to immense scene distractors. The optimal trajectory logs how the fine-grained visual descriptors ('black', 'resting on barrier') functionally pruned away equally weighted false-positives.
  - Decisive Stopping Metrics: The final termination frame guarantees the target structure is massive and centrally dominant within the visual frame, unequivocally validating the physical robotic stop decision as thoroughly grounded.
