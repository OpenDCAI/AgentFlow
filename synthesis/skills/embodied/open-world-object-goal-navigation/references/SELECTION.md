# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Egocentric Sub-goal Justification: Accept immediately if the transition between zones is demonstrably linked to recognizable spatial landmarks. The evaluating filter must verify the agent intentionally pivoted toward a 'coffee table' organically believing a 'magazine' might lie atop it. If random walk physics govern the logic, reject it.
  - Full Semantic Clause Dependency: Valid trajectories necessitate that identifying the true objective relies heavily on compounding multiple constraints (Category + Color + Geometry). The agent must mathematically fail to isolate the target if any single descriptive constraint was truncated.
  - Physical Motion Integrity: Accept solely if acceleration and turning arcs respect the foundational bounds of embodied locomotion. Sudden instant 180-degree snaps breaking kinetic continuity or passing straight through solid geometric boundaries severely compromises simulation realism.
  - Logical Pruning Efficiency Gain: Pass the sample if the agent reliably ignores huge swathes of available topology by effectively realizing its irrelevance. Evaluators must calculate trajectory parsimony; a path driving into every single empty closet while hunting a 'parked vehicle' represents a failed reasoning filter.
  - Termination Proximity Enforcement: Ensure the final visual coordinate strictly reflects a highly actionable operational distance. If a reviewer requires a digital zoom to even discern the purported target item in the culminating sequence, the agent prematurely halted operations and the path fails.
* **Rejection Criteria**:
  - Uniform Random-Walk Success: Violently reject sequences wherein the agent clearly stumbles blindly across the final objective while executing mathematical lawnmower patterns. Object-goal navigation mandates intelligent contextual steering; lucky strikes entirely bypass providing necessary reasoning tokens.
  - Map Metadata Extraction (Oracle Cheats): Discard trajectories immediately if the embodied agent pivots decisively toward an enclosed, wholly unobserved space harboring the target without possessing any bridging landmark chains. Navigating strictly via extracted backend simulator coordinate data absolutely destroys vision-based modeling goals.
  - Category-Only Simplification: Reject task environments generating absolutely zero distractor entities. If an open-world layout possesses merely a single, glowing red vehicle within a perfectly blank landscape, the robust multi-variable filtering apparatus lies entirely dormant and practically untested.
  - Unjustified Environment Battering: Dismiss movement patterns generating repeated, egregious structural collisions in simple terrain. The embodied navigation standard demands baseline obstacle awareness; data where the model violently glides along walls simply to acquire a visual angle is inherently flawed.
  - Premature Viewpoint Isolation: Reject operations wrapping up the execution cycle while the targeted item remains heavily obscured behind trees, geometry, or shadows. Valid stopping strictly commands clear, unobstructed views proving undeniable object verification.
