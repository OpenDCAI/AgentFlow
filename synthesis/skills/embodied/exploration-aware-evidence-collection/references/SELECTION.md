# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  * **Observation-answer alignment.** Accept a trajectory only if the answer can be justified from what the agent actually observed rather than from background common sense. Review the decisive frame and ask whether an auditor with only that frame and the question could verify the final response. If the answer is 'the faucet is off,' the accepted trajectory must include a frame where the faucet state is visible.
  * **Exploration necessity test.** A valid sample should fail under a no-move baseline or at least become substantially less reliable without exploration. The selector should compare initial visibility against final evidence before accepting the trajectory. If the target object is already fully visible at the start, the sample does not strongly test exploration-aware evidence collection.
  * **Efficient evidence path.** Accept when the path reaches the needed evidence with purposeful movement rather than excessive unrelated detours. The agent should tolerate a few exploratory corrections but reject trajectories dominated by aimless wandering. A five-step route to the sink is preferable to a thirty-step tour of unrelated rooms for the same faucet question.
  * **Decisive evidence timestamping.** Accept only if the trajectory includes a clearly identifiable moment when the critical information first becomes available. The agent should note that step explicitly so later synthesis can reconstruct a faithful trajectory field in the output JSON. This is especially important for open-ended answers, where grounding must be auditable.
  * **Answer uniqueness under full exploration.** The accepted trajectory should remove ambiguity rather than merely shifting it. After full exploration, there must still be one justified answer, not multiple plausible paraphrases tied to different unseen regions. If two floor lamps remain possible because the agent explored only one corner partially, the sample should fail.
* **Rejection Criteria**:
  * **Prior-knowledge solvability.** Reject questions that a language model could answer from household stereotypes without any scene evidence. The selector should remove prompts like 'Where is the fridge usually located?' because they measure commonsense, not embodied evidence collection. This skill requires questions whose truth depends on the explored environment.
  * **Irrelevant final observation.** Reject trajectories whose endpoint has little or no relation to the answered question. Even if the answer happens to be correct, the sample is invalid if the agent never actually looked at the relevant evidence. That is exactly the kind of unfaithful answering this capability is designed to prevent.
  * **Duplicate-target ambiguity.** Reject scenes containing multiple valid targets of the same type unless the question includes enough detail to isolate one. The agent should explicitly check for duplicate rooms, appliances, or objects before approval. A question about 'the lamp in the living room' fails if two similar floor lamps occupy different living-room corners and neither is specified.
  * **Exploration without information gain.** Reject long trajectories that accumulate steps without revealing new task-relevant evidence. The agent should distinguish path length from information value and drop samples where additional movement does not improve observability. A loop through the hallway that returns to the same uninformed viewpoint is wasted trajectory mass.
  * **Weak decisive frame quality.** Reject when the decisive evidence exists only as a tiny, blurred, or borderline visible detail. The selection stage should guard against cases where human annotators can answer only because they already know the target. A barely visible faucet handle in the far background is not strong enough for robust synthesis.
