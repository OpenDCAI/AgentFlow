# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  * **Question-to-evidence decomposition.** The main rule is to translate the question into the minimum observable evidence required for a grounded answer before moving the agent. The agent should identify which room, object, state, attribute, or count must be observed, then plan exploration steps aimed specifically at revealing that evidence. For example, a faucet-state question requires direct sink observation, not a generic kitchen tour.
  * **Region-first then detail refinement.** Exploration should first locate the relevant functional region and then perform fine-grained inspection within that region. The agent should navigate toward the most likely room or zone, then slow down or reorient to inspect the exact target state once the region is reached. An edge case is a laundry question where entering the utility room is necessary but still not sufficient until the appliances are visually counted.
  * **Evidence logging at decision points.** The concept is to record what became newly visible at each major step so later selection can verify that the answer truly depends on the trajectory. The agent should save the observation that first reveals the decisive evidence and mark the action that produced that view. This is crucial when two trajectories end near the same area but only one actually looked at the faucet, lamp, or washing machine.
  * **Hallucination-resistant stopping.** The exploration policy should stop only after the decisive evidence is visible, not merely when the agent feels near the answer location. The agent should ask whether the final observation would let an external reviewer justify the answer directly from the scene. A concrete failure case is stopping outside the kitchen doorway and answering about the faucet from prior expectation.
  * **Counterfactual exploration check.** The rule is to test whether a shorter or alternate route would still have exposed the needed evidence. The agent should reason about whether the chosen exploration path actually contributes information rather than adding redundant movement. If the answer could have been grounded two steps earlier, the later wandering should be marked as inefficient noise.
* **Target Trajectory Profile**:
  * **Task-relevant evidence exposure.** A good trajectory must expose the exact evidence needed for the answer at least once and preferably in a clear terminal or near-terminal view. The agent should prefer paths where decisive evidence is not tiny, peripheral, or heavily occluded at the key moment. A washing-machine count question is stronger when the final view sees the full appliance area rather than a sliver of one machine.
  * **Nontrivial exploration necessity.** The sample should require actual movement or reorientation to solve; a static-start solution is too weak. The agent should reject examples where the answer is already visible from the initial position unless the capability being tested is intentionally about deciding not to move. For this skill, a faucet hidden behind the counter is much better than one centered in the first frame.
  * **Unique answer guarantee.** The trajectory should support a single grounded answer and avoid scenes where duplicate regions or duplicate objects make the same question ambiguous. The selector should verify that alternative rooms or objects of the same type do not introduce multiple equally valid answers. If two laundry rooms exist and the question does not specify which one, the sample is invalid.
  * **Grounded endpoint relevance.** The final observation should be meaningfully related to the answer, because the capability is about evidence collection rather than blind wandering. The agent should prefer trajectories that end at or near the informative region and reject those that merely pass nearby without looking properly. A path that brushes by the living room but never turns toward the lamp corner is not acceptable.
  * **Moderate path complexity.** A strong trajectory is long enough to demand planning but not so long that irrelevant detours dominate the sample. The agent should favor efficient question-conditioned search over exhaustive exploration of the whole environment. This balance is important because the benchmark is meant to reward rational exploration, not random map coverage.
