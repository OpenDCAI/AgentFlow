# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  * **Boundary visibility threshold.** Accept a sample only if the relevant boundaries for the requested measurement are visible or recoverable from combined views. The selector should verify that top, bottom, left, right, or front/back extents are not fundamentally missing for the target quantity. A desk-height task passes when the floor contact and tabletop height are visible; it fails if the base is fully hidden.
  * **Point-grounding reliability.** For point depth tasks, accept only when each queried point sits on a clear, stable physical surface. The agent should reject marked points on reflections, shadows, or fuzzy texture transitions because those produce ambiguous geometry. A point on a glossy monitor reflection is not acceptable even if it visually resembles a valid surface point.
  * **Quantitative uniqueness.** Accept when the correct answer remains numerically or ordinally unique under small perturbations in interpretation. The selector should test whether minor rounding or annotation variation would still preserve the correct option or answer band. If two answer choices differ by only an implausibly tiny amount for the scene, the question is fragile and should not pass.
  * **Scene-scale appropriateness.** The expected numeric precision must match the scene and target scale. Indoor furniture dimensions may support centimeter-level answers, while tabletop objects may support millimeter-level answers, and the selector should align the tolerance accordingly. An outdoor path-length estimate phrased to the nearest millimeter should be rejected as mismatched precision.
  * **Cross-view value add.** When multiple views are available, accept only if they materially improve measurement confidence or completeness. The agent should prefer samples where the extra view reveals a missing edge, clarifies depth ordering, or resolves foreshortening. If the second view adds nothing and the first view already makes the answer trivial, the pair is not ideal synthesis material.
* **Rejection Criteria**:
  * **Semantic-only shortcuts.** Reject when a model could answer correctly from typical object priors rather than the actual observation. If the question 'How tall is the desk?' can be solved by memorizing default desk height because the scene offers no counterevidence or geometry, the sample is too weak. This commonly occurs with heavily cropped standard objects shown without surrounding context.
  * **Truncated extents.** Reject any object-dimension sample where the relevant extent is cut off, heavily blurred, or hidden by clutter. The selector must explicitly check every required endpoint of the measurement axis before keeping the example. A bookshelf whose top is outside the frame is an immediate rejection for height estimation.
  * **Unstable or deformable target geometry.** Reject deformable objects unless the question is explicitly about a stable measured segment that remains well-defined. The agent should avoid tasks on blankets, curtains, or piled clothing where dimension varies with pose and creates annotation noise. A rolled towel might be measurable if the question is about its visible diameter, but not if the prompt ambiguously asks for its 'size.'
  * **Precision mismatch.** Reject when the candidate answers demand a precision level unsupported by the evidence quality. The agent should compare expected numeric resolution with available visual signal and drop the sample if the gap is too large. For example, a noisy far-view outdoor car width estimate with 1-centimeter answer spacing is too brittle.
  * **Distractor collapse.** Reject any multiple-choice measurement question whose distractors are either obviously absurd or nearly indistinguishable from the correct answer. The selector should preserve informative negatives that reflect plausible estimation error bands. Choices like 10 mm, 950 mm, 10 m, and 1 km for an indoor desk height question are too easy and should be rewritten or rejected.
