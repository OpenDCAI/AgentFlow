# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  * **Scale-cue harvesting.** The main idea is to gather views where relative scale, perspective compression, and object boundary visibility make physical measurement inferable. The agent should search for scenes containing rigid objects with clear extents, supporting surfaces, and neighboring reference items, then preserve those views for later measurement synthesis. A concrete example is a desk seen with floor contact, leg visibility, and tabletop boundaries, which is far more useful than a close crop showing only wood texture.
  * **Measurement-target isolation.** The rule is to isolate exactly which geometric quantity will be measured before collecting extra observations. The agent should decide whether the target is depth at a point, relative depth between points, or an object dimension such as height or length, then gather views that expose that quantity directly. For instance, if the goal is object height, side views matter more than top-down views that mostly reveal footprint.
  * **Multi-view completeness search.** The concept is to collect enough complementary views that the object's relevant extent becomes complete rather than truncated. The agent should actively seek follow-up views whenever the target boundary is clipped, foreshortened, or occluded in the first image. An edge case is a tall lamp whose base is visible but top is cropped; that sample should not be synthesized until a complete height-supporting view is found.
  * **Point-specific depth sampling.** For point depth tasks, exploration should intentionally select points lying on surfaces with stable geometry and meaningful depth contrast. The agent should prefer points on edges, corners, or clearly separated objects, and avoid ambiguous texture-only regions with uncertain physical attachment. For example, a point on the front edge of a bed frame and a point on a distant suitcase produce a strong depth-comparison sample.
  * **Scene-specific precision calibration.** Different environments support different precision scales, so exploration should calibrate expected difficulty to the scene type. The agent should tolerate millimeter-scale targets on desktop scenes, centimeter-scale targets indoors, and broader tolerances outdoors, while keeping the question quantitative. A failure case is demanding millimeter precision from a distant outdoor object, which inflates noise and weakens the benchmark.
* **Target Trajectory Profile**:
  * **Complete geometric support.** A high-quality trajectory must expose the full extent of the target measurement or the full evidence chain for a depth comparison. The agent should retain only those samples where the relevant boundaries or point relations are visible enough for a justified estimate. A chair with its legs cropped off is a poor height target because the floor-to-top extent is incomplete.
  * **Stable rigid target.** The target should ideally be rigid and physically well-defined so the measurement corresponds to a meaningful real quantity. During selection, prefer furniture, containers, appliances, and fixed structures over deformable fabrics or objects in motion. A crumpled blanket is usually a bad candidate for dimension estimation because the notion of height or width shifts with the fold state.
  * **Reference-rich context.** Good trajectories contain surrounding context that supports size inference, such as floors, walls, tabletops, neighboring objects, or multiple views. The agent should reject measurement scenes that isolate the object against a blank background with no geometric cues. For example, a mug floating in a tightly cropped frame gives poor physical scale cues compared with a mug sitting beside a notebook on a table.
  * **Nontrivial numeric challenge.** The trajectory should require genuine quantitative inference rather than a categorical shortcut like 'small' or 'large.' Keep samples where the answer must be expressed as a depth, distance, or dimension estimate and where rough verbal guessing is insufficient. If the question can be solved by saying 'the nearer one' without considering the marked points, the trajectory is too weak.
  * **Reasonable ambiguity ceiling.** A good sample may contain mild clutter or viewpoint distortion, but it must still support one defensible measurement target. The agent should prefer moderate challenge and avoid scenes where the object boundary itself is undefined or depth cues are internally contradictory. A reflective glass surface creating duplicated boundaries often pushes the sample beyond acceptable ambiguity.
