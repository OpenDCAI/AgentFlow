# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Implement 'Bibliographic Dependency Chaining' by using the references, citations, or explicit mentions within one document to discover the entry key for a secondary silo. The agent should scan for keyword-laden citations and initiate a follow-up query specifically for that cited entity to bypass standard keyword limitations. For example, if a news article mentions a specific government gazette number, the agent must search for that gazette as the secondary source.
  - Deploy 'Disjoint Multi-Attribute Probing' to harvest independent factual components (e.g., a person’s title and an event's duration) when no single search result yields a comprehensive summary. The agent should identify which data points are missing from the primary result and launch targeted follow-up queries specifically for those gaps. A concrete edge case involves finding a report that lists an official's presence but omits their acting title, requiring a secondary pivot to a government directory from the same day to finalize the answer.
  - Execute 'Temporal-Anchor Disambiguation' to isolate specific, recent incidents from historical precedents stored in the model's internal memory. The agent should append high-precision temporal markers (e.g., month and year) and unique situational descriptors found in preliminary snippets to every subsequent search query. An edge case involves identifying a similar 2024 incident and explicitly refining the search to include the 2025-only trigger event 'military post attack' to ensure the facts match the current context.
  - Execute 'Cross-Silo Identity Pivoting' by identifying unique identifiers like DOIs, NCT IDs, or specific algorithm names that act as high-trust bridges between academic, regulatory, and industrial databases. Retrieve these identifiers from the first search step and use them to unlock subsequent repositories that are otherwise non-indexed. For example, a search in a tech blog might reveal a specific project ID which is then used to search an official patent database.
  - Deploy 'Blind Hypothesis Generation' for underspecified 'hint-free' prompts by brainstorming potential relational bridge categories like family, colleagues, or dataset inspirations. For every query issued without a clear path, the agent should test multiple bridge directions expecting to discover an unmentioned intermediary. As an example, if searching for a researcher's teacher, the agent should test both university faculty lists and co-author histories as parallel exploration paths.
  - Maintain a 'Belief State Transition Table' while actively browsing to track which components of a multi-hop query remain unresolved. After each page interaction, evaluate the utility of the information found to determine if the next action should be a new search or a deeper structural navigation within the current site. An edge case involves recognizing when a 'Search' step provided a snippet for Attribute A but not Attribute B, forcing a 'Visit' action to harvest the remaining data.
* **Target Trajectory Profile**:
  - The trajectory MUST demonstrate at least two to four distinct evidence sources contributing functionally non-redundant facts, proving strict sequential or parallel dependency. Turn N+1 must fundamentally rely on keywords, identifiers, or attributes retrieved exclusively in Turn N. For example, the agent finds the date of an event in Source A, which it then uses to find a specific attendee list in Source B.
  - The pathway MUST record the discovery of at least one 'Hidden Reasoning Hop' or 'Bridge Entity' that was conceptually hidden from the initial user prompt. If the prompt asks for a relation, the trajectory should show the agent identifying the unmentioned intermediary needed to link them. A concrete edge case is identifying that a person’s father can only be found by first identifying their stepmother through a social media report.
  - The trajectory MUST exhibit an explicit 'Temporal Disambiguation' step when dealing with recent events. The agent should document its intent to search for a specific month/year to avoid capturing parametric noise from older versions of similar events. For instance, the agent explicitly modifies a query from 'Guatemala state of emergency' to 'Guatemala state of emergency December 2025' after noticing multiple historical results.
  - The final evidence chain MUST culminate in a synthesis step where distributed evidence is integrated into a unified terminal answer. The path should make it clear that the answer could not have been obtained reliably from the starting query alone. An edge case to watch for is a search snippet that includes both attributes by chance; if this happens, the agent should still verify the answer through a reformulated evidence-seeking path to prove consistency.
