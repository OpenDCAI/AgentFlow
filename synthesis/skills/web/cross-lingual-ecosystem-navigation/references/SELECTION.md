# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept the trajectory exclusively if the agent identifies and uses at least one non-English UI element (e.g., an attribute dropdown, a purchase button, or a regional filter) that was necessary to solve the task. Merely reading text from a foreign page without interaction fails the 'navigation' and 'alignment' requirement. The agent must log: 'Clicking the [Kaufen] button to finalize the acquisition.'
  - Accept only when 'Instruction-Target Alignment' is verified, meaning the specific entity or attribute selected in the non-English UI perfectly matches the user's original goal description. There must be no residual error in the size, color, or quantity selection due to translation confusion. A success state demonstrates the agent reconciling 'Yellow' with 'Gelb' or 'Jaune' with 100% precision.
  - Accept only if the agent demonstrates 'Action-Efficiency Compliance' by completing the task in fewer than 10 total steps for e-commerce or simple search-and-verify tasks. This guards against the common 'over-click' failure found in agents navigating low-resource languages. If the agent takes 15 steps to find a simple product, the trajectory is rejected as inefficient.
  - Accept exclusively if the agent utilizes 'Ecosystem-Appropriate Platforms' (e.g., using a local Turkish portal instead of Google.com via VPN) to extract data that is only available on native-language indexes. The agent must document why the chosen platform was superior to English mirrors. For example, 'The official heritage list is only accessible via this regional government portal.'
* **Rejection Criteria**:
  - Reject any trajectory where 'Translation Hallucination' causes the agent to click an incorrect UI element, such as clicking 'Delete' (Sil) instead of 'Select' (Seç) because it confused the Turkish labels. Errors in mechanical action due to language misunderstanding are automatic failures. The intention must match the triggered UI event.
  - Reject benchmarks where the agent settles for 'English-Only Shortcuts', such as finding an English mirror of a Chinese site and ignoring the native-language interface requested. If the challenge can be resolved entirely in English, it does not test the skill. The trajectory must move through the non-English ecosystem to be valid.
  - Reject situations where 'Action Overuse' occurs—for example, if the agent performs 5 searches for the same keyword because it couldn't perceive that the search results had already updated in the target language. This indicates a failure of observation-alignment during the retrieval loop. Persistent, repetitive actions on the same page are disqualified.
  - Reject trajectories that display 'Attribute Blindness,' like selecting the default product size because the agent couldn't find or translate the size menu. The agent must demonstrate an active effort to find and click the specific requested attribute. A success path is one where the agent expands a dropdown to select 'Large' rather than settling for whatever was pre-selected.
