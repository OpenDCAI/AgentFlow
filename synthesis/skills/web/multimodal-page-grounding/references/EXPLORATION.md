# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Inspect the page through both structural and visual channels simultaneously before initiating execution. The agent must cross-reference DOM indicators with immediate visual screenshots to confirm which parsed elements authentically occupy the live interactive viewport. As a robust edge case, if the DOM contains three hidden duplicates of a primary action button, the visual screenshot must decisively dictate which coordinate the agent targets.
  - Execute continuous physical coordinate tracking for interface elements lacking discrete HTML command hooks. When tackling complex sliders, mapped visual plots, or designated drag-and-drop dropzones, the agent is required to isolate direct (x, y) coordinates off the screenshot. A standard edge condition involves computing the continuous pixel drag trajectory required to accurately pull a volume marker directly to a visually depicted 50% threshold without overshooting.
  - Execute 'Layout Motif Identification' to resolve textual relationships embedded in dense spatial constraints. The agent must inspect horizontal data tables, vertical key-value pairs, and grid containers to explicitly determine headers based on alignment and adjacency rather than raw text arrays. An edge case involves identifying that an implicitly nested row value inherits the property class described in a visually distinct, overarching column header.
  - Enforce visible spatial geometry and regional localized context anytime overarching prompts utilize ranking or orienting directives. Imperatives tasking the agent to locate “the 7th item,” “the leftmost toggle,” or “the overlaid warning grid” mandate the subordination of pure DOM array orders to explicit onscreen visual rendering structures. If the internal array sequence severely misaligns with the human-facing visual layout, spatial coordinates must universally govern the targeting process.
  - Systematically probe environment configurations for perceptual ambiguities or masking effects preceding irreversible interactions. Two interactable elements exhibiting completely identical tag attributes compel the agent to aggressively read surrounding color bounds and layout spacing to deduce accurate functional intent. Should overlapping ad-banners artificially conceal a critical targeted element, the model must recognize the graphical occlusion and instigate a scrolling recovery.
* **Target Trajectory Profile**:
  - A strictly validated target sequence MUST encompass at least one decisive perception or control interaction utilizing a visually grounded page state over static property lists. This strictly includes parsing an ambiguously laid-out data table via column proximity, resolving redundant buttons exclusively via explicit geometric positioning, or finalizing a drag-and-drop trajectory using spatial coordinate endpoints.
  - The traversal logic MUST log a verifiable state transition enforcing the explicit recalibration of the agent's internal visual anchor map. Highlighting a before-and-after metamorphosis in the screenshot framework—such as an active popup window heavily obscuring primary background architecture—is absolutely critical for demonstrating responsive visual perception.
  - A fundamentally capable execution path demonstrably merges HTML structural discovery logic with purely visual verification to finalize targeting. This rigorous separation faithfully emulates authentic interactive browser requirements, utilizing the DOM to register possibility but employing screenshots to authenticate accessibility or semantic proximity.
  - The culminating success phase MUST be decisively anchored to a verifiable graphical interface transformation or precise layout parsing. The autonomous agent is obligated to produce a completely novel layout view, conclude a continuous dragging permutation, or map a heavily nested visual table successfully into targeted structured outputs.
