# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept the recorded sequence exclusively if a central maneuver would be fundamentally ambiguous or fatally miss-executed without invoking screenshot-guided geometric grounding or layout motif mapping. This stringent baseline ensures the multimodal integration is technically non-negotiable for concluding the scenario.
  - Approve the path only when the core action log inextricably links explicitly captured coordinate maps or visual constraints to its targeting rationale. The agent must harmonize structural ID labels with observed physical cues like positional containment, relative axis alignment, or continuous drag mechanics.
  - Accept configurations strictly if the interactive environment dictates a substantial interface mutation directly responding to a mid-point physical event, or an extraction dependency on horizontal/visual alignments in dense grids. Generating a secondary modal, transitioning a visual object to a new dropzone, or mapping nested spatial attributes satisfies this metric.
  - Only validate task resolutions where ultimate completion translates directly into a visually distinct systemic state change definitively interpreted from the browser rendering or an assertion of spatial correctness. Achieving a specifically forwarded dashboard view or confirming a completed geometric puzzle alignment delivers optimal validation certainty.
* **Rejection Criteria**:
  - Forcefully reject submissions situated in environments where all necessary clues reside visibly in simplified, linearly ordered static text. Such configurations fundamentally bypass authentic multimodal grounding challenges because the visual coordinates pose zero friction. At bare minimum, visual cues or specific coordinate tracking must govern one definitive crossroad choice.
  - Reject operational logs confusing unseen DOM array sequencing with user-facing geometry when tasks implicitly assume a human perspective. Providing interactions manipulating a purely hidden seventh DOM result instead of the seventh visibly rendered item violates fundamental visual tracking rules.
  - Dismiss assignments evaluating completion based entirely upon opaque assumptions or undocumented semantic triggers unobservable via the available architecture. Scenarios mandating common-sense deductions utilizing hidden formatting variables fundamentally exceed appropriate benchmark targeting scopes.
  - Reject paths completely bypassing browser interaction logic via isolated OCR image deciphering queries artificially masquerading as comprehensive web control formats. A valid environment obligates physically responsive page elements actively manipulating dynamic coordinate states or deeply structured interactive HTML grids.
