# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Implement Meta-Path Discovery and workflow schema mapping prior to initiating interactive steps. The agent must hypothesize an overarching task sequence (e.g., Search -> Filter -> Detail -> Verify) based on the structural skeleton presented upon initial page load. As an edge case, if a multi-step checkout form dynamically shifts from a one-page layout to sequential sub-pages, the agent must systematically recalibrate its intended physiological pathway to prevent severe state memory drift.
  - Execute Recursive Loop Verification for bulk-aggregation list or comprehensive table generation tasks. Upon encountering horizontal sets of entities, the agent should sequentially drill down into each individual item's sub-page, extract the requisite vertical attributes, and methodically return to the parent node. Should the layout employ infinite scrolling instead of discrete pagination, the agent must aggressively document its positional depth to ensure thoroughness and accurately prevent redundant cyclic sweeps.
  - Apply Topographical Tree-Walking utilizing targeted Difference-Spotting for uncovering obscured menu depths. The agent must register the initial visual baseline, trigger an interaction on a high-level UI hub like 'Settings', and sharply compare the subsequent rendered state to detect freshly spawned nested branches. Encountering universally identical generic 'More Info' chevrons demands clicking them systematically to unveil specific contextual drop-downs, requiring the agent to disregard prior identical states and strictly track newly invoked nodes.
  - Establish Boundary Constraint Stress-Testing encompassing distinct transactional policies throughout the extended session. Provide scenarios heavily loaded with restrictive behavioral edicts—such as budget caps, absolute algorithmic prohibitions, or format specifications—which the system evaluates actively at each navigational phase. Identifying a preferred candidate product that satisfies dimensional prerequisites but marginally violates a strict secondary cost constraint mandates immediate rejection and deliberate fallback exploration.
* **Target Trajectory Profile**:
  - The trajectory must entail a genuinely extended workflow containing six or more functionally diverse user-level acts. Sequential reordering must fundamentally break the capability chain, proving explicit order-dependency. A shallow scenario solvable via three uncoordinated clicks invariably fails this extensive continuity standard.
  - The pathway must establish uncompromising Compliance Fidelity traversing the entire session duration without degradation. The agent must rigorously respect every declared negative parameter, budgetary ceiling, or multi-tiered rule without prematurely shedding variables. Overlooking a foundational baseline requirement—such as selecting non-vegan options in strictly vegan task bounds—triggers instantaneous trajectory disqualification.
  - The navigation logic incorporates active Environmental Mutation Grounding to dictate subsequent maneuvers. Upon executing targeted form inputs, slider alterations, or drop-down changes, the agent must visibly log the receipt of new modals, updated basket totals, or error validation banners prior to advancing. Bypassing mandatory system toasts or incorrectly proceeding after a silent submission failure structurally invalidates the execution chain.
  - The procedure showcases explicit Loop Control and Tree-Walking persistence when analyzing broad matrices. Tracking must concretely record deduplication algorithms resolving conflicting identical sets, validating exhaustive coverage across paginations. If compiling a 20-row demographic table stalls indefinitely due to an inability to break an identical refresh cycle, the exploration effectively terminates in failure.
