# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Step-wise Reasoning Chain Decomposition: Harvest scenarios from code execution or advanced mathematics containing clear sequential dependencies (Formula -> Extraction -> Answer). Deliberately generate candidate responses carrying subtle formulaic errors, bad coefficients, or skipped steps. This tests if the judge verifies the entire proof or merely skims the final token string.
  - Long-Context 'Needle in Haystack' Synthesis: Find highly verifiable, short factual truths and re-insert them into massive, irrelevant distractor texts ranging up to 128k tokens. Observe whether the generated candidate accurately pulls from the specified evidence chunk or hallucinates outside knowledge. Collecting traces here focuses strictly on source-bounded fidelity metrics.
  - Native-Script Validation and LRL Binning: Discover complex knowledge seeds in Low-Resource Languages (LRL) like Telugu or Swahili that typically cause LLMs to fail into 'intention-looping'. You must partition these samples to ensure the evaluation framework explores logical correctness paths parsed directly in the target language's script. Generating seeds where translated English misses a subtle mathematical modifier creates high-value verifiable tests.
  - Adversarial Length-Bias (Verbosity) Injection: Craft distinct candidate response pairs where the highly incorrect answer is elegantly drafted, heavily formatted, and extensively verbose, while the fully correct baseline answer is blunt and short. Harvesting these pairings forces the evaluator environment to isolate raw truth against manipulative aesthetic fluency.
* **Target Trajectory Profile**:
  - Deterministic Ground-Truth Accountability: The trajectory environment must contain absolute, unshakeable truths—such as python computational outputs, pure PDF extraction text, or algebraic gold schemas—to explicitly anchor the evaluation. The judge's trace must demonstrate validation against this anchor, systematically checking facts outside of subjective opinions. Trajectories relying on 'general impression of correctness' fail this core profile requirement.
  - First Error Attribution (FEi) Tracking: For any step-by-step logic task, the evaluator trace accurately marks the exact isolated step where the error materialized mathematically or logically. It must aggressively ignore or classify as 'consequent' any trailing subsequent errors based on the false premise. Pinpointing line 3 in a 10-line proof as the sole structural failure embodies the target standard.
  - Strict Native-Script Reasoning Alignment: When processing facts or math in foreign or low-resource text, the trace must maintain logical processing without relying on lossy English connectors that corrupt meaning. You should confirm the trajectory correctly isolates variables (e.g., entity counts, specific dates) relying on local syntax dependencies rather than broad semantic translation guesses. This proves verifiable reasoning holds true globally.
  - Acoustic/Document Grounding Correlation: In long-context tasks, the judge cites exactly which 'Clue Chunk' or page number explicitly supports the required claim while validating against hallucinations. The trajectory must document the judge refusing to accept outside facts. Proving that an evaluator docked points for a true-world fact simply because it was absent from the 100k document is paramount.
