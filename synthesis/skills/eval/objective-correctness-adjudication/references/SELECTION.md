# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Unassailable Verifiable Trace Presence: Accept trajectories strictly if they include a definitive, documented pathway to verifying the truth of the given claim without any subjective wiggle room. For math, this means an active step-trace; for contexts, an exact document quote. If the factual condition lies implicitly outside the context boundary, the sample must be rejected.
  - Decisive Step-Discrepancy Explainability: Ensure the retained evaluation rationale clearly names and pinpoints the exact failing operation rather than generating holistic summaries. The judge must explicitly note 'Incorrect multiplication at step 2' or 'Mention of protein XYZ is unsupported by the PDF.' Trajectories showing precise architectural tear-downs of logic pass this criteria.
  - Script-Pure Logical Adherence for LRLs: For multilingual or low-resource math logic, accept samples demonstrating that the correct evaluation label survives the linguistic complexity without defaulting to english-translation errors. Checking that the judge respects the native modifiers or conditional operators in the language validates cross-cultural objective alignment.
  - Strict Precision Mapping and Tolerance Compliance: If evaluating continuous math or engineering constraints, the trajectory strictly enforces tolerance adherence based on specific requested decimal precisions rather than generic percentages. An evaluation accurately failing a model for answering 1.45 instead of the strictly required 1.450 ensures high-level analytical fidelity.
* **Rejection Criteria**:
  - Length-Induced Sycophancy (Verbosity Traps): Categorically reject any evaluations where the judge awards higher points simply because a response provided extra, unverified, hallucinatory world knowledge not present in the provided context. If a wrong but beautifully long answer wins over a correct short one, the bias renders the sample useless for objective judging.
  - Broad Tolerance/Black-Box Hallucinations: Reject trajectories where an answer using a completely wrong formula or hallucinated method computationally stumbled onto a nearby numeric value and was incorrectly marked as a success. Also reject mathematical judgements wrapped in a 'black box' missing explicit derivations. Correctness relies on process integrity, not coincidental numeric overlap.
  - Translation-Shortcut Context Loss: Reject traces evaluating foreign factuals or math where the judge scores based entirely on an Anglocentric literal translation that demonstrably lost the key logic constraints. If translating the Telugu prompt wiped out the conditional variable, and the judge graded it 'correct' based on the flawed translation, it violates objective reality.
  - Word-Matching Syntactic Reliance (ROUGE-Trap): Reject factual evaluations relying merely on high syntactic text similarity while blatantly ignoring semantic negative modifiers. A judge that scores 'Paris is NOT the capital of France' as factually correct simply because the noun tokens match the gold target reveals critical reasoning fragility and must be excised.
