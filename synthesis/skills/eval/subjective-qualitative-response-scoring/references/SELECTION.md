# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Separation of Content vs Formatting Flaws: Accept trajectories where the candidate answer has qualitative formatting, presentation, or tone defects that are wholly independent of factual correctness. Ensure the evaluation distinctly praises the factual truth while penalizing the structural envelope. If the evaluator conflates formatting errors with factual hallucinations, the sample lacks the required nuance.
  - Visible and Nuanced Quality Tradeoffs: Accept only if the candidate responses provide nuanced tradeoffs, avoiding outputs that are either purely perfect or catastrophically nonsensical. The chosen text must realistically resemble output from intermediate AI models, creating legitimate difficulty for the judge. A sample featuring a grammatically correct but painfully verbose explanation serves as the perfect intermediate target.
  - Cultural and Stylistic Code Grounding: Accept files where judgements pertaining to tone or politeness cite a specific localization standard or persona constraint. The evaluator must mention exactly which rule of etiquette, character motivation, or linguistic register was violated. If an evaluator labels an Arabic response as 'too casual' without citing the structural phrasing that triggered the penalty, discard it.
  - Deduction-Based Transparency: Require the evaluator to utilize a clear deduction framework that separates textual citations for style errors versus reasoning errors. You must verify that the final qualitative band maps logically to the listed penalties. A sample that subtracts points for 'unnecessary apologies' using explicit point-values or logical steps guarantees the structural integrity of the score.
* **Rejection Criteria**:
  - Binary Exact-Match Verification Override: Reject samples where the subjective score actually maps 1:1 onto a pure factual verification checklist without any qualitative constraints. If the rubric only checks 'Does the answer equal 5?' without mandating style, format, or persona, it belongs in objective capability training. Qualitative data must have at least one subjective vector to be valid.
  - Safety-Conditioned Roleplay Penalization: Exclude trajectories where the judge mistakenly penalizes an acting prompt because the requested fictional persona was deemed 'mean' or 'deceptive'. General safety constraints should not bleed into creative fiction formatting constraints within this skill. An evaluator awarding a 0/5 because a requested 'evil warlock' character was 'unhelpful' is exhibiting fundamental instruction blindness.
  - Anglocentric Translation Reliance: Reject any trajectory evaluating multilingual tone where the judge relies purely on Englishly-translated text to gauge regional nuance. If the judge notes 'The tone is fine' because it translated a high-formal Korean address into a generic English 'Hello,' it has lost the core sociolinguistic resolution. Proper assessment of regional politeness mandates evaluation directly reflecting the target script's cultural rules.
  - Hidden Implicit Rubric Bias: Discard instances where the evaluator downgrades a response based on a metric that was never requested or implied by the prompt context. If the model severely penalizes a text for 'lacking formal academic structure' when the user simply asked for a 'quick explanation', the judge has hallucinated a constraint. The qualitative score must align rigorously with the user's articulated or contextually obvious intent.
