# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Multimodal State-Fault Pair Harvesting: Capture diverse agent trajectories where specific intent commands are paired with sequential (log-based or visual) ground-truth transitions. Establish a deterministic success baseline by tracking the Delta (State_Initial to State_Final) across CLI commands and Desktop UI coordinates.
  - Step-Level Correctness (PRM) & Blame State Mapping: Gather logs tracking how individual actions or sequential agent roles increase or decrease the probability of task success. Record the 'Reasoning' (ri) and the subsequent system state/handoff (oi+1) to determine key failure branches, calculating if downstream steps 'Repaired' or 'Harmed' the current trajectory.
  - Reasoning-to-Action Discrepancy Auditing: Systematically scan reasoning-action triplets {ri, ai, system_state} to find instances where an agent's internal thought process contradicts its executable code or UI click coordinates (e.g., intending to click 'Submit' but clicking 'Cancel' due to DOM misalignment).
  - Inter-Service & Role-Handoff Dependency Discovery: Identify trajectories requiring the agent(s) to navigate dependencies across multiple applications or multi-agent handoffs. Group by complexity and evaluate whether the failure fundamentally emerged from a 'Missing Prerequisite' left by an earlier process step.
* **Target Trajectory Profile**:
  - Execution-Based Outcome Integrity: The trajectory must definitively prove that outcome success is grounded in objective environmental changes (new files, lowered metrics) or objective logic, strictly ignoring the agent's conversational assertions of 'success'.
  - Traceable Error Origin Localization: The trajectory profile requires the evaluator to point to the specific timestamp (t*) or role index (Planner/Critic) where the failure was introduced and became unrecoverable, fulfilling the 'Earliest Persistence' diagnostic logic.
  - Temporal Reasoning Traceability: The trace must document the 'Look-Think-Act-Reflect' loop, analyzing exactly how feedback (or error logs) from Step N influenced Step N+1. It identifies if an agent successfully pivoted strategy after hitting an environment blockage.
  - Harmful Side-Effect Sensitivity: An optimal sample evaluates 'Instruction-Unrelated' state changes, prioritizing the detection of agents that accomplish a goal but simultaneously break system configurations, delete extraneous objects, or violate explicit safety policies.
