# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Expert Domain-Knowledge Target Selection: This strategy involves identifying professional-grade knowledge silos like Chemistry PhD research, Finance MBA memos, or Physics PhD proofs to ensure the evaluation target exceeds generalist capabilities. The agent must systematically search for tasks that require junior-level professional expertise to complete, such as multi-page reports or complex chemical synthesis plans. A concrete edge case involves distinguishing between 'General Business' questions and 'MBA Finance' questions, where the latter requires specific technical metrics like IFFIm securitization models rather than vague market summaries.
  - Multi-Dimensional Rubric Category Decomposition: The goal is to separate evaluation criteria into three distinct expert-level categories: Extraction (information retrieval fidelity), Reasoning (logical and mathematical validity), and Style (tone and formatting). The agent must map every high-level user request to at least two of these categories to ensure a holistic professional audit. For instance, a titration task is decomposed into 'Extraction' of volume values and 'Reasoning' for the calculation of pH at the neutralization point.
  - Static JSON Rubric Bundle Compilation: This strategy transforms abstract expert criteria into immutable, machine-readable JSON specifications to prevent logical drift during long-context evaluations. Each criterion must be assigned a unique ID and a binary 'fulfillment predicate' (Yes/No) that acts as the terminal decision point. An example involves compiling a 60-item checklist for a physics paper where each item, such as 'Calculates the ratio E/N', is a discrete node that must be satisfied independently of general discourse quality.
  - Expert-Weighting Priority Assignment: This involves assigning importance levels—Critical, Major, Minor, and Additional—to each rubric criterion based on its impact on the final professional verdict. The agent must evaluate the hierarchy of the prompt to determine which errors (e.g., wrong chemical formula) constitute a total failure versus those (e.g., minor rounding error) that are merely stylistic. A concrete case is a consulting memo where 'identifying the correct competitors' is a Critical extraction task, while 'using British English' is a Minor style preference.
  - Grounding Document Truncation & Needle Sourcing: For tasks involving massive source texts up to 128k tokens, this strategy identifies the specific 'clue chunks' necessary to satisfy each rubric item. The agent must create a mapping between the 'Sentence IDs' of the source documents and the 'Criterion IDs' to prove that the evaluation is grounded in provided evidence. A high-value seed is a 200-page investment report where only page 42 contains the liquidity policy breach data required for the extraction rubric.
* **Target Trajectory Profile**:
  - Dimension-Specific Grounding Integrity: A premium trajectory must document the judge checking the response across multiple distinct axes—Extraction, Reasoning, and Style—without letting a success in one mask a failure in another. The log should show the judge explicitly noting: 'The reasoning for the axion ratio is perfect, but the Extraction rubric failed because the model omitted the Q5 representation dimension.' This prevents the 'Halo Effect' where a professional-sounding tone tricks the judge into ignoring factual gaps.
  - Importance-Weighted Hierarchical Adjudication: The trajectory must show the final score being calculated as a weighted average of criterion fulfillment based on the expert-assigned priorities. You must verify that a failure on a 'Critical' criterion (like a fundamental safety error in chemistry) significantly penalizes the overall grade more than a 'Minor' formatting error. A profile that delivers a 'Failure' status because a Critical reasoning step was skipped, despite all Minor style items being met, represents the required rigor.
  - Expert-Level Justification & Rationale Generation: Outstanding trajectories feature a judge that provides a technical justification for every 'No' vote, citing specific laws, formulas, or document segments. The evaluator should not just say 'The math is wrong,' but instead state: 'The calculation for the 2020–2024 defense spend CAGR is incorrect because the model divided 2024 by 2020 without raising it to the power of 1/4.' This provides an auditable trail that allows human experts to verify the judge's domain-specific reasoning.
  - Stochastic-Invariance under Rubric Perturbation: The target profile ensures that the grading result remains stable even if the order of criteria in the checklist is shuffled or if the phrasing is slightly modified. The trajectory must record the judge using the locked JSON hash to maintain consistent logic across 100% of the checks, resisting the 'Ordering Bias' common in LLM evaluators. A trajectory that assigns identical scores regardless of whether 'Style' or 'Reasoning' appears first in the bundle confirms semantic consistency.
