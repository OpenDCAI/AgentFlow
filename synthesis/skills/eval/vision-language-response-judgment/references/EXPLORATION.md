# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Forensic Attribute Probing: The goal is to discover text-image pairs where the judgment depends on detecting 'generation artifacts' such as anatomical errors (e.g., 6 fingers), misaligned structures, or lighting depth inconsistencies. You must systematically scan the image for boundaries where foreground and background elements meet, checking for 'halo' effects or disconnected textures. For example, finding an AI-generated portrait where the jewelry is merged with the skin provides a high-stakes forensic seed that tests authenticity-aware observation.
  - Semantic Transition and GUI State Harvesting: Collect raw environment data capturing pre-action visual states and post-action visual consequences to stress-test dynamic transition modeling. To execute this, you must record specific DOM changes or pixel shifts that occur after a 'scroll' or 'click' action is simulated. An edge case involves identifying a 'sticky' sidebar that remains static while the main content scrolls, which measures the agent's ability to distinguish persistent from dynamic UI elements.
  - Anatomical and Physical Law Sanity Checks: The strategy seeks to harvest cases where the visual content violates basic common-sense physics, such as objects floating or reflections not matching their sources. You should focus on complex interactions between entities, like a man holding an object that lacks weight-appropriate grip or a shadow that points toward the light source. A concrete instance is an image where a glass of water is tilted at 45 degrees but the liquid level remains parallel to the bottle rather than the ground.
  - Visual Perception and Subjective Aesthetic Sweep: Catalog varied UI domains (landing pages, receipts, dashboards) prioritizing instances that capture drastic variations in aesthetic complexity and functional density. Intentionally include 'broken' or cluttered designs to set a baseline for low cognitive comfort and high visual noise. For example, comparing a dashboard with overlapping charts against one with clean grid alignment allows the synthesizer to establish 'Subjective Ground Truth' for aesthetic quality.
  - Visual-Task Diversity and Retrieval Trace Capture: Discover multimodal seeds from several visual task types including charts, screenshots, and text-in-image diagrams. You must record which specific visual 'clue chunks' (e.g., a legend, a specific bar, or a label) drive the answer to ensure the trace is auditable. An example includes identifying the specific OCR span from a menu that proves a candidate's price-check was correct or hallucinated.
* **Target Trajectory Profile**:
  - Authenticity-Dependent Grounding Trace: A premium trajectory must prove that the evaluator identified the image's AI-generated nature by citing specific forensic markers (e.g., 'the man's lanyard is misaligned with the neck'). You should verify that the log records the judge explicitly ignoring the general 'prettiness' of the image in favor of identifying logical flaws. This 'Forensic-First' prioritization ensures the synthetic data calibrates the model against the 'Realism' versus 'Authenticity' traps.
  - Action-Conditioned Semantic Accuracy: The trajectory must document the evaluator comparing a predicted GUI transition against the actual system-state change. You should confirm that the rationale explains exactly which part of the transition was 'halucinatory,' such as an agent predicting the bottom menu would disappear when it is actually anchored. This verifies high-level transitional logic rather than just static pixel matching.
  - Psychological-Perceptual Dimension Segregation: Outstanding trajectories feature a judge that differentiates between 'Clarity' (cognitive load) and 'Aesthetics' (emotional impact) for subjective images. You must ensure the judge can penalize a UI for being 'Confusing' while still rewarding its 'Professional Color Palette.' Successful segregation validates that the judge resists the 'Visual Halo Effect' where one good feature masks major structural flaws.
  - Factual Content-to-Evidence Alignment: The trajectory must feature evaluators executing diagnostic explanations using concrete textual pointing references locking onto directly visible evidence elements. You should verify the judge cites: 'The taller bar on the left represents 80%, meaning Response A correctly identifies the lead category.' This mapping ensures that the synthetic data rewards evidence-anchored reasoning over lucky guesses.
