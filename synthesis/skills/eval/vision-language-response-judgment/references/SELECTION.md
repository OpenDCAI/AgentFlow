# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Specific Forgery Artifact Citation: Accept only those trajectories where the evaluator cites at least one concrete generation artifact (anatomical error, physics violation, or texture anomaly) to justify its authenticity score. You must verify that the quote points to a localized part of the image, such as 'the feathers lack texture realism' or 'the lanyard is disconnected.' This ensures the judge is performing forensic analysis rather than making a generic guess based on image quality.
  - Foundational Multi-modal Necessity: Accept instances exclusively where extracting the definitive judgment depends unconditionally on accessing the visual input. You must verify that the user's question cannot be solved using only the text prompt through societal or linguistic priors. For instance, a question about a specific bar in a chart is accepted, while 'is water wet' is rejected as it bypasses visual reasoning.
  - Separated Verdicts for Multi-Factor Grading: For subjective image artifacts like UI/UX, accept only trajectories where the judge delivers independent scores for 'Clarity,' 'Hierarchy,' and 'Aesthetics.' You should check that the rationale for each score is distinct and grounded in specific layout components. If the judge gives a 'flat' score across all dimensions without this granular breakdown, the sample is considered non-diagnostic and must be discarded.
  - Semantic Transition Significance: Accept components where analyzed interactions yield functionally impactful visual modifications rather than inevitable randomized content cycles. You must confirm that the 'next state' prediction is grounded in the structural logic of the app, such as a menu opening or a card expanding. This confirms the evaluator is modeling the 'semantic world' of the application environment.
  - Verification of Forensic Prompt Effectiveness: Accept only those trajectories where the addition of specific forensic-indicative attributes (e.g., 'focus on edges and textures') led to a correct detection that the baseline model missed. You should verify the log shows the 'Before and After' shift in the evaluator's accuracy when directed toward forgery cues. This proves the synthetic data represents the 'Advanced Forensics' tier of multimodal evaluation.
* **Rejection Criteria**:
  - Authenticity-Blind Keyword Matching: Categorically reject any trajectory where the judge awards a high score to a response that identifies 'what' is in the image (captioning) but misses obvious AI-artifacts (forgery). If the judge calls an image 'Authentic' because the 'bird looks like a bird,' while ignoring the bird has no feet, the judge is biased by surface-level realism. This protects the benchmark from rewarding 'Captioning Sycophancy' over true forensic verification.
  - Text-Only Solvable Shortcut Bias: Refuse to validate evaluation samples where the correct verdict can be confidently established using uniquely textual input variables. If the prompt contains a hidden clue that spoils the visual answer, the multimodal reasoning is skipped. We prioritize 'Visual Leakage Safety' cases where the text is perfectly neutral but the image contains the safety or logic violation.
  - Vague Perceptual Justifications: Discard immediately any trajectory evaluating UI/UX or Aesthetics where the rationale is purely subjective, such as 'it looks clean' or 'I like the vibe.' Every aesthetics or layout judgment must strictly tether to localized visual markers, such as 'the centered contrast button improves clickability' or 'the menu overlap creates visual clutter.' Without these markers, the judgment is unauditable.
  - Hallucinated Grounding for Authentic Images: Reject any sample where the judge invents a 'forgery reason' for a real photograph (False Positive Hallucination). If the judge claims a real sunset has 'AI-lighting inconsistencies,' the model is projecting its internal priors onto reality. This ensures that the synthetic data doesn't train future models to be paranoid or to hallucinatory artifacts where none exist.
