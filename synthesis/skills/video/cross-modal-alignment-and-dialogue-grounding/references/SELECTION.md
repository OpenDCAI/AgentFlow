# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Mandate 'Implicit-Grounding Semantic Depth' where the question-answer pair requires transferring a semantic clue from a query modality to a target modality. You must simulate an ablation: if the visual content can be described without knowing the audio context, the sample is rejected. A valid sample requires identifying 'which' cooking step is shown based on the 'specific speech' about flavor.
  - Mandate a 'Refined-Soundex Distance Threshold' of 5 or less when accepting an ASR correction suggested by visual OCR. You must calculate the phonetic distance between the original ASR word and the visual correction candidate. Accept the correction only if the two terms are phonetically similar enough to justify a sensor error, such as 'NextSeat' (6) vs 'Nexeed' (5).
  - Require 'Timestamp Formatting Precision' where the ground truth interval must be expressed in absolute seconds (e.g., 94.6s - 105.4s) rather than relative indices. You must verify the interval captures the full scope of the multi-modal event from onset to offset without truncation. Accept the sample only if the visual and auditory boundaries are synchronized within a 0.5-second tolerance window.
  - Enforce 'Modality-Agnostic Accuracy' where human-equivalent review confirms the audio caption is 90%+ accurate and the visual boundary is definitive. You must manually audit a segment to ensure the cross-modal anchor acts as a definitive 'key' (e.g., there aren't five different people laughing at different times making the target impossible to isolate).
* **Rejection Criteria**:
  - Immediately reject 'Modality Leakage Samples' where the audio transcript explicitly contains visual descriptions (e.g., a narrator saying 'now I am using the red spatula'). You must discard these because they allow the agent to answer 'Audio-to-Video' queries using text-only reasoning, bypassing true modality alignment.
  - Discard any trajectory exhibiting 'Unfounded Contradiction Neglect' where the agent ignores an obvious conflict between visible text and spoken words. Audit cases where the speaker says 'A' and the slide says 'B'. If the final reasoning simply ignores 'B' without explaining using modality comparison, the sample fails the disambiguation requirement.
  - Eliminate 'Disjointed Asynchronous Segments' where the audio and video in the exploration log are offset by more than 1 second due to editing or capture errors. You must calculate the sync-delta; if the 'bang' sound happens while the door is still wide open and hasn't started moving, the sample is rejected.
  - Reject recordings with 'Self-Identifying Time Metadata' such as on-screen clocks, visible timestamps, or narrators stating the exact time. You should treat visible clocks as an illegal shortcut that bypasses the agent's internal temporal modeling relying on event-boundary parsing.
