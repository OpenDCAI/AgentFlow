# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Mandate 'Multi-Source Evidence Convergence' where an episodic fact is supported by both independent visual detection and a secondary semantic or auditory anchor. You must evaluate the segment to ensure a target (e.g., shampoo) is found within the proximity of its predicted anchor (e.g., sink). Accept the sample only if the 'Discovery Path' follows a logical reasoning chain from clue to target, proving the agent used environmental context rather than a lucky guess.
  - Require 'Calibrated Confidence Set Validation' ensuring that only information with a high statistical reliability threshold is promoted to a final answer or shared between segments. First, calculate a conformity score for the LLM's classification of an object as 'Relevant'; if the score falls below the 0.8 quantile of the calibration set, the link is discarded. This ensures that the synthesized data relies on robust semantic associations rather than hallucinated or weak co-occurrences.
  - Enforce 'Task-Relevant Information Density' ensuring the captured segment contains a definitive state change or existence fact that answers a potential user question. You must check that the 'before' and 'after' states of an object (e.g., turned off vs. turned on) are distinguishable within the explored interval. A valid memory sample requires that the object's presence or state was explicitly verified, such as seeing napkins on a dining table to confirm an 'Existence' query.
  - Verify 'Episodic Retrieval Dependency' ensuring that the final answer is impossible to guess using common sense or the current frame alone. First, check if the object's location is a 'typical' place (e.g., milk in a fridge); accept only if the video documents a specific variable interaction or unique location (e.g., cushion on a dining chair) that deviates from generic priors. This ensures the benchmark measures memory recall and long-horizon search rather than categorical guessing.
* **Rejection Criteria**:
  - Immediately reject 'Generic Activity Shortcuts' where the exploration activates on background noise or mundane scenes without a specific queryable object being manipulated or identified. First, discard clips like 'walking down a hall' that lack a 'Memory Seed'—the specific moment an object's state is captured—regardless of the trajectory length. For example, if a user is just talking, the camera capture contains no memory data and must be purged as a 'cognitively barren' loop.
  - Discard any trajectory exhibiting 'Unfiltered Communicative Distractions' where irrelevant or low-confidence semantic cues are used to guide navigation. First, audit the search path; if the agent follows a link (e.g., 'see a mirror, look for a cushion') that lacks a physical or semantic basis, the sample is rejected for 'Miscalibration'. We aggressively filter out 'hallucinated relevance' where the agent explores a bathroom for bedroom items.
  - Eliminate 'Static State Hallucinations' where the memory trigger activates on a loop or background flicker without any actual state change in the environment. First, measure the pixel-delta during the observation window; if the camera wearer is static and no object attributes change, the sample is a 'Static Cheat'. This protects the agent from generating data on segments where nothing actually changed to be remembered, such as a static view of a TV that is never interacted with.
  - Reject trajectories relying on 'Narrator Spoilers' where the answers (like 'the washing machine is on') are spoken explicitly without the agent needing to visually verify the object. You must perform a transcript audit; if the ground truth answer is recoverable from text alone without the visual-auditory trigger interaction, the task is bypassed. Memory recall must be derived from the interpretation of raw environmental cues rather than being told the answer directy.
