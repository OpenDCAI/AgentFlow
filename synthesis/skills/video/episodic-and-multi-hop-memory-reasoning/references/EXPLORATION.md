# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Implement Semantic Anchor-Point Indexing to identify high-probability 'Relevant Objects' that serve as multi-hop bridges to unobserved targets based on common household co-occurrence patterns. First, scan the environment for global landmarks or anchor objects like sinks, beds, or mirrors that typically cluster with specific user targets. For example, if searching for shampoo, the agent should prioritize the exploration of 'Bathroom' segments characterized by mirrors and faucets, documenting these anchors as evidence-rich nodes.
  - Execute Audio-Gated HOI Harvesting to isolate information-dense interaction windows where memory-relevant state changes (like placing or hiding items) are most likely to occur. First, utilize a lightweight audio-transcription or event-detection pass to flag sounds of opening, clicking, or sliding that signify a hand-object interaction. A concrete scenario involves syncing a 'refrigerator hum' or 'drawer slide' sound to the exact visual frame where an item is placed, ensuring a high-fidelity memory seed is captured.
  - Execute Hysteresis-Based Activity Segmenting to define robust temporal boundaries for episodic events and prevent fragmented memory capture during multi-room movements. You must set high activation thresholds to start a 'Memory Capture' state when a target is seen and lower decay thresholds to maintain the tracking state even if the object is temporarily occluded. For instance, maintain the tracking of a 'wallet' entity as the user walks from a brightly lit kitchen into a dark hallway to ensure the final resting position is not lost due to lighting shifts.
  - Perform Multi-Pass Semantic Labeling to correlate raw environment pixels with narrations, transcripts, or external intent tokens provided in the metadata. First, run a visual detection pass to label all entities, then align these labels with spoken words or text instructions to verify current object states. For example, if a narrator mentions 'cleaning the pool table', logs should flag the presence of balls or cues at that timestamp to answer existence-based queries later.
  - Conduct Personal-Interaction Anchoring to track the 'life-cycle' of objects from first contact or mention to their final stable state in the environment. You must identify the exact moment a participant picks up or mentions a salient object and follow its trajectory continuously until the manipulation terminates. An example is logging the path of a remote control from the couch to a shelf, creating a causal chain that explicitly answers 'Where did I leave X?' queries.
* **Target Trajectory Profile**:
  - A good trajectory must feature an 'Interaction-Triggered Retrieval Gap' where the decisive episodic fact is captured during one segment and then queried after a significant temporal or spatial delay. First, ensure the object of interest moves or changes state (e.g., turned on/off) during an early segment and is no longer visible when the question is posed. For example, if the agent sees the washing machine 'on' at T=50s, the trajectory remains valid if the question 'Is it on?' occurs at T=500s during a kitchen scene.
  - The trajectory must support 'Multi-Hop Grounding Coherence' where the path from start to target requires navigating via intermediate semantic cues. First, verify that the agent identifies a 'Relevant Object' (like a pool table) before finding the 'Target' (like pool balls) in a logical succession. A valid path demonstrates that seeing the table provided the reasoning stimulus to investigate the specific surface for the final answer.
  - Maintain 'Identity-Locked Role Consistency' throughout the entire duration of the exploration to ensure that entities identified in different rooms are part of a unified mental map. First, ensure that a 'blue chair' identified in the bedroom is tracked as a distinct instance from a 'blue chair' in the living room to prevent spatial hallucinations. If the agent confuses two similar objects in different locations, the trajectory fails the spatial memory requirement and must be discarded.
  - Ensure the path demonstrates 'Hand-Object Engagement Priority' where the presence of the user's hand or a robot's end-effector indicates a salient memory event. First, verify that the trajectory focuses on kinetic engagement rather than passive observation of static scenery. A successful extraction traces a hand manipulating a medication bottle cap, rather than just the bottle being visible in the background, to ensure the action is 'encoded' as a personal event.
