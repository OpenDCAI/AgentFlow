# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Require at least two independently meaningful temporal clues or Narrative Arc milestones before accepting a trajectory. First, evaluate the stream to ensure the notes cover at least 30% of the total duration through periodic anchors. For example, in long-video summarization, one note must locate a setup event, and another note must specify the decisive climax or plot resolution.
  - Mandate Multi-Event Informational Necessity where the query forces an integration of evidence from at least two segments separated by significant time or visual cuts. First, simulate baseline vision checks on Segment A only and Segment B only; if neither segment alone answers 'How it changed', accept the sample. For example, 'How did the tone shift?' must require seeing both the intro and the conclusion.
  - Enforce a Consistency-of-Identity Threshold across the tracked horizon. First, verify that the subject of the plot question is persistently traceable despite aggressive jump cuts or visual variance. For instance, if a character is off-screen for 40 minutes and reappears, the sample is accepted if their identity is contextually secure and the evolution remains stable.
  - Require Logical Convergence Determinacy where the relationship between events follows a single narrative interpretation. First, verify that the Reasoning (e.g., A led to B because of rule established at T=5) is based on explicit visual/audio evidence. For example, do not keep notes like 'look later in the match' when the actual clue is the exact causal event linking the halves.
* **Rejection Criteria**:
  - Reject trajectories that collapse into generic summary shortcuts or rely on title-level leaks. First, discard any sample where common sense or an obvious keyword is enough to answer the plot progression without watching the temporal evidence. For example, if a tutorial video's plot is just following a standard manual without divergence, the sample is rejected.
  - Discard any trajectory exhibiting Excessive Redundancy where the video duration is long but the 'Plot' is effectively a static loop. First, measure the semantic delta between intervals; if the state is purely repetitive (e.g., a static view of a city), discard the sample. This prevents training on long-form videos that offer no narrative development.
  - Eliminate Disjointed Plot Segments where the segments provided for reasoning have absolutely no logical or thematic connection. First, check if the subjects and themes in the first half are completely unrelated to the second half (e.g., spliced unconnected clips). If the agent cannot bridge them using a causal logic chain, the sample lacks a plot and must be purged.
  - Reject trajectories whose answer cannot be justified from the stored exploration path or relies exclusively on narrator spoilers. First, mute the audio; if the 'How the story changed' answer becomes a guess because a voiceover explicitly explained it before it was visually earned, discard the sample. Causal narrative logic must be derivable from the visual-temporal events.
