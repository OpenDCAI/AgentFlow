# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Perform an 'Axis Topology and Truncation Audit' by checking for non-standard 'direction' values and non-zero 'min_value' settings. The agent must verify if the Y-axis is 'top-to-bottom' (inverted) or if it has been truncated (e.g., starting at 7 instead of 0) to avoid being misled by exaggerated visual gaps. An edge case is identifying a 'log' scale applied to linear data, which would suppress the visual impact of large differences, requiring a scale-reset in the mental model.
  - Execute 'Relational Scale and Dual-Axis Alignment' to verify if separate scales hide the true mathematical relationship between categories. For charts mapping two metrics, the agent must explicitly compare the min/max bounds of both scales before comparing slopes. A concrete example is a chart where 'Profit' and 'Revenue' use separate axes, making a small profit bar look larger than a huge cost bar; the agent must normalize these to a shared 0-100% boundary to judge the ratio correctly.
  - Conduct a 'Complexity and Cognitive Load Assessment' based on chart-specific best practice thresholds. The agent must count the number of categories or slices in the chart and compare them against established usability limits, such as the '7-slice maximum' for pie charts. For instance, if a pie chart contains 20 categories, the agent should proactively identify the 'clutter' as a design violation.
  - Apply a 'Visual Grammar and Dimensionality Verification' to detect distracting or distorting stylistic choices. The agent should inspect the use of 3D effects, gridline density, and color logic to ensure they do not obscure the data. For example, it must flag 3D bar charts as misrepresentations because perspective makes front-facing bars appear artifactually larger. An edge case is the use of a 'rainbow' color palette for sequential data, which the agent should identify as a violation of perceptual consistency.
* **Target Trajectory Profile**:
  - The trajectory must record a distinct 'Deception Diagnosis' or 'Quality Audit' turn where rules are applied to the visual structure. The trace must document observations like: 'Detected Inverted Y-Axis; visually lowest bar represents the highest value' or 'Detected Truncated Axis: base starts at 50, exaggerating deltas.' This establishes that the agent's critique is evidence-based and structural.
  - A high-quality profile demonstrates 'Logical Reconstruction' where the agent maps a 'bad' chart back to a 'good' representation. The trace should show the agent proposing specific code changes—like setting `ylim(0)` or unifying a dual axis—based on the detected violation. For example, the agent should log: 'Improving the Data-Ink ratio by removing redundant background gridlines.'
  - The trajectory should preserve the 'Metric of Deviation'—the gap between what the chart visual geometry implies and what the data says. The trace should explicitly calculate the visual distortion factor (e.g., 'Visual gap is 400% but data gap is 10%'). This quantitative audit is critical for demonstrating that the agent understands how design choices affect inference.
  - A robust profile concludes with an 'Educational Recommendation' that ties the fix back to numeric truth. Instead of just naming the error, the agent should explain 'why' it is an error using the data (e.g., 'Dual axes make it impossible to compare magnitudes, hiding the fact that Series B is an order of magnitude smaller').
