# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Plan 'Narrative-Integrated Scaffolding' by identifying specific analytical 'pivot points' in the outline where a visual proof is strictly required. Before drafting, the agent must map each section of the report to a corresponding visualization intent (e.g., 'Gap Analysis', 'Trend Discovery', or 'Outlier Isolation'). For example, an 'Economy' section should explicitly plan for a trend line to support claims about growth speed versus absolute volume. This prevents 'Insight Freezing' where the model runs out of visual evidence space during long-form generation.
  - Conduct a 'Bi-Directional Schema Alignment' check to ensure the chosen variables for the chart perfectly match the linguistic entities in the planned narrative. The agent must verify that if the text intends to discuss 'Regional Disparity,' the exploration trace confirms the 'Region' column holds enough unique values to support a readable bar chart or map. A concrete edge case is planning a geographic map for a dataset that only contains country-level ISO codes without a mapping to continents, which would necessitate a data join before the reporting phase begins.
  - Determine the 'Visual Specification Parameters' (chart type, aggregation, and filters) by evaluating the relationship type defined in the user intent. For categorical-magnitude comparisons, the strategy should favor bar charts; for temporal evolutions, line charts with trend-smoothing; and for multidimensional distributions, violin or box plots. For instance, if the intent is to show 'Consistency across regions,' the agent should plan for a violin plot to display the spread of data rather than a simple bar chart of means. This ensures that the exploration phase yields the highest possible 'Informativeness' during synthesis.
  - Perform a 'Visual-Feedback Ready' data audit to identify potential rendering failures like high-cardinality labels or sparse matrices. The agent should inspect the data grain to see if a chart with 100+ categories will be unreadable (e.g., a bar chart of 200 individual cities) and proactively propose a 'Top 10' or 'Aggregated by Province' view. An edge case is a dataset with extreme outliers that would flatten a linear scale, where the agent identifies the need for a logarithmic scale or an outlier-shaving filter in the exploration notes.
* **Target Trajectory Profile**:
  - The trajectory must demonstrate an 'Interleaved Iteration Loop' where text generation is suspended and resumed based on visualization completion. The trace should show a `Pause -> Request Visualization -> Inject Result -> Resume` pattern for every major evidence point in the report. This confirms the agent is not following a 'text-first' or 'graph-first' staged pipeline, which is the primary cause of text-chart inconsistency. An edge case is a trajectory where the agent explicitly corrects a narrative claim because the generated chart reveals a pattern (e.g., a decline) that contradicts the agent's initial textual hypothesis.
  - A high-quality profile records 'Embedded Insight & Annotation' planning within the exploration or drafting trace. It should document the agent's intent to highlight specific chart features (like a 'Significant drop in 2020' or 'Extreme outlier in Category B') using labels or on-chart boxes. For example, the agent might log: 'User needs to see the Belarus outlier; adding an arrow annotation in the spec.' This ensures that the resulting visual is not just a raw data dump but a targeted reporting artifact.
  - The trajectory must isolate the 'Multidimensional Synthesis' step where multiple metrics are combined into a coherent global view or dashboard. The trace should show the agent selecting complementary variables (e.g., CO2 emissions per capita and GDP per capita) and deciding to plot them together to reveal a correlation. A robust profile will show the agent rejecting a single-variable plot in favor of a scatter plot or heatmap to satisfy the 'decision-oriented' requirement. This distinguishes deep reporting from simple surface-level description.
  - The trace should conclude with a 'Validated Report Continuity' check, ensuring that the transitions between chapters maintain a consistent design language and variable naming convention. The agent should log a final check that colors used for 'Female' in the first chart are identical to colors used for 'Female' in the final summary dashboard. An edge case to avoid is a trajectory that finishes with a successful chart but fails to provide a grounded summary that ties that chart to the report's overarching conclusion.
