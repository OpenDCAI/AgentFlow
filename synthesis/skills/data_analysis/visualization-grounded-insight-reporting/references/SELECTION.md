# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept only if every significant numerical claim in the text is explicitly supported by a corresponding visual element (line, dot, bar) in the report. Reviewers must see a 1:1 mapping between the text's 'noteworthy exceptions' and the chart's visible outliers. For example, if the text mentions a '9.5 year gap in Belarus,' that exact country and value must be clearly identifiable in the accompanying chart images. This is the primary metric for Text-Chart Consistency.
  - Accept only if the textual narrative provides 'Information Depth' by interpreting patterns (skew, variability, or relationships) rather than just repeating labels. The report must contain analytical insights like 'The wide spread in African mortality distribution suggests high variability in healthcare access,' rather than just 'Africa has the highest rate.' This ensures the agent is performing decision-oriented analysis as opposed to surface-level description. Traces lacking this synthesis are too shallow.
  - Accept only if the visualizations demonstrate 'Publication-Ready Readability,' including clear axis labels, descriptive titles, and necessary statistical enhancements (like trend lines or medians). The trace must include the use of iterative refinement where the agent checks the initial chart image and adjusts legend placement or Font size for clarity. A successful selection shows the agent caught and fixed an unreadable chart (e.g., labels overlapping) during the pipeline. This confirms high aesthetic and functional utility.
  - Accept only if the report demonstrates 'Visual Consistency' by using a unified color palette and semantic design language across all figures. A report must use the same color to represent the same entity throughout the entire document (e.g., always green for 'Renewables' and red for 'Fossil Fuels'). This allows the reader to track variables intuitively without re-learning the legend for every chapter. Traces that flip-flop legend colors must be discarded even if the math is correct.
* **Rejection Criteria**:
  - Reject trajectories where the narrative and visualization are decoupled (e.g., the text talks about '2023 trends' but the chart shows '2020-2022' data). This 'Inconsistency' error typically occurs in staged pipelines. Successful reporting requires that the temporal, geographic, and metric scopes are perfectly synchronized across both modalities. If a mismatch exists, the analytical value of the report is fundamentally undermined.
  - Reject reports that suffer from 'Low Visualization Density' or 'Visual Gaps' where long narrative sections are unsupported by evidence. If a report contains 1000 words but only one simple chart at the very beginning, the 'Insight Reporting' capability is poorly exercised. High-quality reporting requires an interleaved denseness where visuals and text serve as mutually reinforcing evidence throughout the entire document. Cases where the writer 'stops' requesting visuals after one failure must be rejected.
  - Reject examples where the writer generates 'Hallucinated Bullet Points'—narrative claims that cannot be found in or derived from the provided visuals. Even if the data exists in a raw table, telling the user to 'look at the chart for the peak in 2021' when the chart does not show 2021 is a critical reporting failure. The text must be strictly grounded in the *rendered* artifact, not just the underlying database. Traces where text contradicts the picture must be purged.
  - Reject trajectories that focus on 'Aesthetic Refinement Only' without delivering quantitative insights. This skill mandates which analytical methodologies are applied and how they are reported; it is not a styling exercise. If the agent spends its entire turn changing bar colors from blue to light blue without adding a single interpretive line about the data's meaning, it fails the 'Informativeness' threshold. Reporting must center on evidence, not just cosmetics.
