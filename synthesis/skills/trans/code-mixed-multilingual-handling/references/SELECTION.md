# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - 100% Invariant Propositional Coverage across all language spans. Accept the trajectory only if every piece of information found in the mix—whether it was in the Matrix or Embedded language—is represented in the final translation. The validator checks if ‘orange juice’ and ‘soup’ from a Tamil-English mix both appeared in the output. If a whole sentence in the minority language was omitted, the sample is rejected as a CSL failure.
  - Accuracy of Speaker-Action Attribution in multi-party dialogues. The sample is authorized if and only if the semantic actions (the 'who', 'what', 'to whom') match the original role-play distribution of the source. For example, if Marcus is the one picking up the passenger in the original CS text, he must be the one picking up the passenger in the English answer. Mistaking the subject of a Mandarin sentence for the subject of the English turn is a catastrophic SMA violation.
  - Successful Navigation of Phonetic Dissonance in Romanized inputs. Accept trajectories that show the agent correctly identifying the guest language from Romanized text (e.g., correctly identifying 'prajuritipun' as Javanese/Malay-root for 'soldiers'). The selection filter confirms the agent didn't discard the Romanized string as unreadable characters or 'junk' text, proving it recovered the semantic intent.
  - Fidelity to Digital Registry and Slang Markers within the mix. Accept the sample if the translation preserves the emotional tone and internet-slang level of the original (e.g., keeping 'lol' or emojis). The validator confirms that the translation 'vibe' remains informal if the source used casual code-switching. This ensures the socio-linguistic 'flavor' of the bilingual speaker is not lost.
* **Rejection Criteria**:
  - Code-Switching Loss (CSL) via Minority Segment Omission. Reject the trajectory if the agent produces a translation that only reflects the English (or Matrix) words and effectively ignores the meaning of the guest-language words. This is a common failure where LLMs 'cheat' by translating only the high-resource parts. A clear rejection is a summary of 'I have a cold' that skips the parts about 'painful' and 'support' just because they were in Tamil.
  - Speaker Misattribution (SMA) resulting from Linguistic Confusion. Discard any sample where information originally stated in one language is attributed to the wrong speaker in the translation because the agent failed to track the turn-taking through the language shift. If Anna asks a question in Mandarin and Marcus answers in English, but the agent says 'Marcus asked a question,' it is rejected. This indicates a failure of discourse tracking.
  - Meaning Shift (MST) due to Poor Guest-Language Translation. Reject the results if the agent translates the minority language spans incorrectly, leading to a factual or logical distortion of the original dialogue. For instance, if a Chinese span about 'pickup at the airport' is translated as 'going to the airport to catch a flight,' it is a meaning-shift rejection. Factual truth is non-negotiable.
  - Language Collapse or Untranslated Residual Spans. Reject any sample where the output is not purely the target language (e.g., an English translation that still contains Mandarin characters or Tamil words). The goal of this skill is a clean, meaning-preserving transfer; leaving 'untranslated residue' suggests the agent failed to decode the guest language entirely.
