# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Implement a 'Bilingual Consistency Scan' to identify all segments of the minority (embedded) language. The agent must traverse the text and label every token as either the Matrix Language or the Guest Language to prevent Code-Switching Loss (CSL). For example, in a Malay-English mix, the agent should find the word 'tengok' and map it to 'look' immediately rather than skipping it as noise. An edge case involves recognizing Romanized spellings of low-resource languages that might look like English typos but are actually meaningful CS tokens.
  - Establish 'Speaker-Context Anchors' for every turn in a code-switched dialogue. The agent must maintain a look-up table of who said what, particularly when the speaker's identity is established in one language but their action is described in another. First, identify the speaker tags; second, correlate the specific language span to that tag. For instance, if Marcus speaks in English and Anna replies in Mandarin, the agent must not attribute the Mandarin-original intent to Marcus in the final translation.
  - Analyze 'Burstiness' and 'I-Index' to detect the frequency and location of language switches. The agent calculates the switch points to understand if the language alternation happens at the word level (intra-sentential) or the sentence level (inter-sentential). This helps in predicting whether a single word might have a specific cultural nuance or slang meaning within the mix. A concrete step is identifying if the switch happens after a conjunction like 'and' or 'but', which often signals a change in the propositional frame.
  - Map 'Phonetic-to-Semantic' roots for Romanized code-switching in low-resource pairs. Many speakers use Latin script to spell out Tamil, Hindi, or Malay phonetically; the agent must normalize these phonetic strings to their standard meaning. First, it identifies the phonetic pattern of the guest language; second, it resolves it into a known lemma. As an example, the string 'naa try panren' must be recognized as the Tamil 'I will try' rather than a misspelling of 'no try'.
* **Target Trajectory Profile**:
  - Demonstrates 0% Code-Switching Loss (CSL) by including every propositional unit from the mixed text. The trajectory must document the agent's observation of the non-English spans and their subsequent integration into the source-aligned translation. The trace should record: 'Detected Mandarin span "有人去机场接Mark吗"; translating and mapping as a travel inquiry from Anna.'
  - Features resistance to 'Speaker Misattribution' (SMA) through turn-by-turn logic. The trajectory shows the agent verifying that the person who performed the action in the source (e.g., Leslie confirming the time) remains the same in the English translation. The log should state: 'Turn 3 (Leslie) processed; confirmed afternoon intent belongs to Leslie and not the previous speaker.'
  - Exhibits 'Meaning Shift' (MST) mitigation by avoiding literal or 'lazy' translation of the minority language. The path documents the agent checking the specific meaning of a CS phrase within the dialogue's narrative context rather than relying on a generic dictionary gloss. An example is correctly identifying that a Chinese internet term inside a Spanglish mix refers to a social sentiment, not a physical object.
  - Prioritizes 'Matrix Language Integrity' to ensure the final monolingual output is fluent. A high-quality run proves that while the source was a messy mix, the target is a grammatically perfect monolith that doesn't 'stutter' at the original switch points. The agent's log verifies: 'Fused the Mandarin subject with the English predicate to create a single, cohesive English sentence.'
