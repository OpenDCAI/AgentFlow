# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Perform a 'Core Concept Extraction' pass to isolate primary semantic nodes from the source text. The agent must scan the input sentence to identify nouns, verbs, and adjectives while marking 'functional glue' like articles (a, an, the) or auxiliary verbs (am, is, are) for potential removal. This ensures that the resulting gloss contains only the high-information labels required for sign language representation. For example, in the sentence 'A man is working', the agent specifically targets 'MAN' and 'WORK' as the only surviving nodes.
  - Implement a 'Morphological Stripping' strategy to identify verb roots and tense markers. The agent analyzes every verb to determine its inflected form and then maps it back to its dictionary infinitive, such as converting 'singing', 'sang', or 'will sing' into the base label 'SING'. This process aligns with the Sign Language constraint where signs typically represent the root concept rather than morphological variations. An edge case involves identifying irregular verbs correctly so that 'went' is accurately recovered as 'GO' in the target gloss.
  - Analyze the 'Syntactic Reordering Potential' based on the target sign language's spatial logic. The agent evaluates the relationship between subjects, objects, and locations to predict a move from standard spoken-language order (SVO) to sign-language order (often SOV or Topic-Comment). This requires marking the 'Topic' of the sentence to ensure it is placed prominently at the beginning of the gloss sequence. For instance, in 'I am going to the store', the agent identifies 'STORE' as the destination topic to potentially shift the order to 'I STORE GO'.
  - Execute a 'Functional Word Purge' audit to identify elements that should be omitted in glossing. The agent meticulously marks particles, prepositions, and conjunctions that are typically expressed through spatial positioning or facial expressions rather than discrete signs. It creates a 'Deletion Map' for words like 'of', 'to', and 'the' to prevent them from leaking into the final gloss output. An example is removing the 'to' in 'go to school' to ensure the gloss remains the compact 'GO SCHOOL' or 'SCHOOL GO'.
* **Target Trajectory Profile**:
  - Exhibits 'Concept-Label Purity' by strictly outputting only the semantic kernels of the source. A high-quality trajectory shows the agent rejecting the inclusion of spoken-language-specific auxiliary tokens in the target string. The trace records: 'Observation: Detected auxiliary verb "is"; Action: Omitting from gloss to maintain sign-language label purity.' This demonstrates an understanding that glossing is a reductionist labeling process.
  - Demonstrates 'Infinitive Accuracy' by documenting the normalization of all action words. The optimal path shows the agent identifying an inflected verb and explicitly converting it to its base lemma for the gloss. The log states: 'Identified inflected Bangla verb "খেয়েছি"; Mapping to infinitive root "খাওয়া" for BdSL compliance.' This proves the agent is applying specialized linguistic rules rather than general translation.
  - Maintains 'Monotonic or Spatial Alignment' of the gloss sequence. The trajectory highlights the reasoning behind reordering tokens to match the logical progression of a signer's movements. Specifically, the trace confirms: 'Reordering tokens to place the location before the verb to follow standard sign-syntax logic.' A successful run shows the agent moving from 'I am going to school' to 'I SCHOOL GO' as a deliberate structural choice.
  - Features 'Script Persistence' congruent with the requested target locale. The path confirms that the gloss labels are written using the target language's script (e.g., Bangla script for BdSL gloss) but following the new syntactic rules. The agent's log verifies: 'Instruction requested BdSL; ensuring all gloss labels use Bangla script characters while removing spoken-language grammar markers.' This prevents the accidental use of English labels in a non-English sign language task.
