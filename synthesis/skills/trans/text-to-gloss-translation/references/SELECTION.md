# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - 100% Lemmatization Compliance for all action-oriented tokens. Accept the trajectory only if every verb in the target gloss is in its base or infinitive form (e.g., 'WORK' instead of 'working'). The validator checks the target glossary to ensure zero inflected suffixes remain in the output. A failure is triggered if a Bangla gloss still uses the '-cchi' or '-be' tense markers.
  - Strict 'Functional Purge' Ratio ensuring the removal of grammatical glue. The sample is authorized if articles, prepositions, and auxiliary verbs found in the source are entirely absent from the target. The agent verifies that the final word count of the gloss is significantly lower than the source sentence. For example, 'The cat is on the mat' must result in a gloss no longer than 3-4 words like 'CAT MAT ON'.
  - Semantic Invariant Preservation across the spoken-to-sign boundary. The trajectory must prove that despite the removal of words, the core message (Who, What, Where, When) remains intact. First, extract the 'Fact Units' from the source and confirm their presence in the gloss labels. A valid sample ensures that the 'Yesterday' or 'School' from the source is not lost during the simplification process.
  - Isomorphism of Target Script and Glossing Logic. Accept the results only if the output uses the correct script (e.g., Devanagari, Bangla, Latin) as requested for that specific sign language approximation. The selection filter checks that the agent didn't switch to English glosses for a Bangla sign language task. For instance, a BdSL gloss must use 'খাওয়া' and not the English word 'EAT'.
* **Rejection Criteria**:
  - Retention of Spoken-Language Syntax and Auxiliary 'Glue'. Reject any sample that keeps words like 'am', 'is', 'the', or 'to' in the target gloss, as these are not discrete signs. This is a common failure where the agent performs a literal word-for-word translation instead of a gloss. A clear rejection is 'I AM GO TO SCHOOL' when a gloss like 'I SCHOOL GO' was required.
  - Failure to Lemmatize Verbs resulting in Inflected Glosses. Discard the trajectory if the agent uses conjugated verbs (like 'runs' or 'ran') in the gloss sequence. Glossing strictly requires the concept label, which is the infinitive. If the agent outputs 'I eating' instead of 'I EAT', the sample is rejected for failing the primary sign-language linguistic constraint.
  - Informational Entropy leading to Omission of Key Entities. Reject samples where the agent's simplification process accidentally deletes a core subject or object (e.g., 'Boy plays ball' becomes just 'PLAY'). The output must prioritize all labels that would be physically signed. A rejection trigger occurs if the location or time marker in the source is missing from the resulting gloss.
  - Instruction-Script Mismatch (Linguistic Leakage). Reject any trajectory where the agent uses English labels (e.g., 'HELLO') when the instruction specifically asked for a non-English gloss (e.g., 'নমস্কার'). This typically happens when models default to American Sign Language (ASL) patterns. The agent must strictly use the Bangla script for Bangla glosses to satisfy the user's specific linguistic environment.
