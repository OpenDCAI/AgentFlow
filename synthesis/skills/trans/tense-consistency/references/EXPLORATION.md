# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Identify 'Aspectual Anchor Tokens' within a tenseless source pool to establish the base timeline. The agent must scan for particles like 了 (le), 着 (zhe), or 过 (guo) and temporal adverbs such as 'yesterday' or 'in the future' to deduce the intended narrative frame. For example, the presence of 'le' at the end of a sequence often anchors the translation to the English simple past or present perfect rather than a continuous present. If the text lacks these, the agent should default to a standard 'Literary Past' for fiction or 'Present' for news.
  - Differentiate between 'Narrative Perspective Shifts' such as direct dialogue vs. omniscient narration. The agent analyzes the text structure to separate quoted speech—which often uses the present tense—from describing narrative actions which should remain in the past. This involves marking the boundaries of quotation marks or dialogue tags to prevent the 'past tense' rule from incorrectly flattening a character's spoken words into the past. An edge case is an inner monologue where no quotes are used, requiring the agent to use contextual cues to keep the 'I think' separate from the 'He walked'.
  - Implement a 'Temporal Logic Mapping' pass to ensure sequential event ordering. The agent creates an internal timeline where Event A precedes Event B, ensuring that the target grammar (e.g., Past Perfect vs Simple Past) reflects this relationship. First, list the actions in order of occurrence. For instance, if a character is 'remembering' an earlier event, the agent must tag that segment as a candidate for the 'had + past participle' construction in English.
  - Catalog 'Narrative Mode' markers to set the global tense constraint. Determine if the source text is a summary, a real-time play-by-play, or a historical novel to select the dominant target tense before translating the first sentence. First, analyze the genre and style markers. In a fast-paced battle scene, the strategy might favor a 'Cinematic Present' to heighten tension, whereas a generic story uses the 'Narrative Past' by default.
* **Target Trajectory Profile**:
  - Exhibits 'Frame Persistence' across discrete sentence boundaries. A high-quality trajectory shows the agent checking sentence 2 against the tense used in sentence 1 to ensure zero drift. The trace should explicitly state: 'Maintaining the simple past used in the previous sentence to ensure narrative consistency.' A failure would be translating sentences in isolation and ending up with a mix of 'walks' and 'talked'.
  - Demonstrates 'Successful Flashback Transitions' via explicit morphological shifts. The path documents the agent identifying a temporal shift (e.g., 'Three years ago...') and adjusting the English aspect accordingly. The trace should log: 'Detected flashback marker; shifting from simple past to past perfect to denote prior time-frame.' This proves the agent is not just applying a flat rule but reasoning through the timeline.
  - Maintains 'Aspectual Isomorphism' where Chinese completion markers map to finished English actions. The trajectory reflects the agent's logic for converting particles into English perfectives or simple tenses. The log records: 'Identified the 'le' particle as a marker of completion; choosing the simple past 'arrived' over the present 'is arriving'.'
  - Avoids 'Robotic Tense Defaulting' by adapting to varied narrative voices. Unlike a fixed policy, the trajectory shows the agent choosing tenses that match the genre, such as using the Present Tense for a dramatic social media post but the Past Tense for a historical web novel. The trace highlights: 'Genre identified as contemporary web novel; applying consistent literary past tense throughout the segment.'
