# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - 100% Tense Uniformity in narrative-only sequences. Accept the trajectory only if all sentences describing a single timeline use the same primary tense (e.g., all Simple Past). First, extract the verbs from each sentence; if some are present and others are past without a logical marker (like 'now' or 'once'), the sample must be rejected. For example, 'He went home and opens the door' is an automatic failure.
  - Accurate Handling of Temporal Shifts during dialogue or flashbacks. Accept the sample if the Agent successfully shifts out of the narrative tense for quotes or specifically signaled past events. The selection filter verifies that the 'quote' block has a different, yet logical, tense compared to the surrounding 'describer' text. An example is a past-tense narration hosting a present-tense 'I am' direct quote.
  - Presence of Explicit Temporal Markers in the source to justify the translation choice. The trajectory is only authorized if the source text contains at least one cue (adverb, particle, or logical sequence) that allows a human to verify the chosen tense. First, point to the source token that indicates 'past' or 'present'. A valid sample ensures we are testing 'recovery' rather than 'guessing'.
  - Grammatical Correctness of Aspectual Inflections. Accept only if the English verb forms are morphologically correct and logically represent the duration of the source action (e.g., 'was walking' for ongoing vs 'walked' for completed). The validator checks if the English aspect matches the implied duration in the Chinese source. For instance, a sentence describing an ongoing storm should use a progressive form if the source implies continuity.
* **Rejection Criteria**:
  - Unjustified 'Tense Flipping' between adjacent sentences. Reject any sample where the tense changes for no narrative reason, such as a character performing two sequential actions in different tenses (e.g., 'He looked up and smiles'). This is the most common failure in MT and must be strictly excluded. Even if the words are correct, if the timing is broken, it fails.
  - Failure to Recover Omitted Time References. Discard the trajectory if the agent uses a present tense for a clearly past event simply because the source sentence was short. If the preceding context implies a past-tense story, but the current sentence is translated as present, it indicates the agent lost the 'Discourse Frame'. A clear rejection is a story starting with 'Once upon a time' and shifting to 'He runs' in the second line.
  - Hallucinated Narrative Tense in factual texts. Reject the sample if the agent applies a 'storytelling' past tense to a news article, instruction manual, or factual report that should naturally be in the present. The tense must be domain-appropriate. For example, translating a recipe as 'He took two eggs' instead of 'Take two eggs' is a failure of genre-consistency.
  - Loss of Flashback Logic resulting in chronological confusion. Reject trajectories where a flashback is translated in the same tense as the current action, making the story impossible to follow. The agent must use past perfect or adverbs to distinguish between 'now' and 'then' in the story. If the reader cannot tell what happened first, the translation is a failure.
