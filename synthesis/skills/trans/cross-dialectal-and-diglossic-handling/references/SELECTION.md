# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Linguistic Authenticity verifying that phrasings match native spoken patterns of that specific variety. Accept the sample only if the translation avoids 'robotic' syntactic mappings from the standard language, such as keeping Mandarin grammar in a Cantonese output. For example, if the Cantonese target uses correct colloquial vocabulary like '我哋' instead of the Mandarin '我們,' it passes the authenticity check.
  - Semantic Equivalence to the original source ground truth despite heavy register re-mapping. The sample must match the core facts and logic of the original source perfectly, even if the vocabulary changes entirely to fit the dialect. The agent checks if all numbers, names, and technical details (like 'final score 5-1') survived the translation into the colloquial mode. A valid sample ensures that a change in 'flavor' did not result in a change in 'fact.'
  - 100% Morphosyntactic Agreement within the chosen dialectal system. Accept the results only if the target text follows the specific grammatical rules of the regional variety (e.g., correct placement of aspectual particles in Cantonese or honorific verbs in Javanese). The validator checks for 'register collision' where a formal pronoun is paired with a street-level verb. For instance, 'le candidate e i candidati sono arrivati' passes, but mixing registers fails.
  - Successful Avoidance of 'Translationese' via active transcreation of communicative intent. Accept trajectories where the output moves beyond word-for-word mapping to use regional intensifiers and proper word ordering. The agent evaluates if the translation uses locally natural intensifiers like 'ketīr awī' instead of generic standard adverbs. A successful case shows the agent adapting the 'vibe' of the source to the cultural common ground of the target user.
  - Target Script and Regional Character Purity compliance. When a task requires Hong Kong Traditional Chinese, the validator checks the character usage to ensure no simplified characters or Taiwan-specific character variants leaked in. Any leakage of untargeted characters or standard matrix forms in a strictly colloquial task triggers rejection. For example, using '體' (traditional) is accepted for HK, whereas '体' (simplified) is rejected.
* **Rejection Criteria**:
  - Mirrored/Verbatim Standard Language Defaulting when a specific variety was requested. Reject samples where the agent provides a Modern Standard response because it was more 'confident' in the high-resource variant. This is a common failure where models avoid the complex dialectal shift. A rejection case is an agent outputting Mandarin '我們' instead of '我哋' when a Cantonese target was demanded.
  - Dialectal-to-Standard 'Pivoting Hallucinations' resulting in meaning confusion. Reject the sample if the translation process misinterpreted a regional word as a standard word with a different meaning. The selection layer checks for 'pivoting' errors where a local word (e.g., 'badé' meaning 'will') is translated as a physical object because the model missed the register marker. A clear rejection is treating a colloquial negation as a noun.
  - Inaccurate Register Mixing leading to socio-linguistic incoherence. Reject trajectories where the agent mixes markers from different social levels, such as using casual pronouns with formal honorific verbs. This represents a failure of cultural grounding and social identity. For example, if the agent claims to provide 'Krama Javanese' but uses 'Ngoko' roots, the sample is discarded.
  - Unauthorized 'Simplification Drift' during standard-to-dialect transitions. Reject any trajectory where the agent simplifies complex professional or academic terms into vague lay terms just because the target is a spoken dialect. Domain-specific translation demands that difficulty levels remain equivalent. A rejection trigger is changing a specific legal term into its 'street' equivalent, which corrupts the precision of the content.
  - Directional Inconsistency and Language Leakage. Discard any result where the target language contains un-translated segments from the source language or the prompt language. This is common when models are overwhelmed by the 'Written-to-Spoken' re-mapping task. A rejection trigger occurs if an English-to-Cantonese translation task yields a string with Mandarin written characters inside a colloquial sentence.
