# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Perform a 'Lexical Bridge-Word' scan to identify polysemous terms that change meaning across professional sectors. Start by extracting 'target terms' such as 'system,' 'division,' or 'cell' and cross-reference them with at least four distinct domains (e.g., Law, Military, Corporate, Biology). For each term, identify the specific target-language lemma that satisfies the domain's technical standard, such as ensuring 'system' maps to '体系' in Law but '系统' in IT. An edge case involves identifying words that are technical in one domain but lay-language in another, requiring a decision on whether to use a professional or common register.
  - Execute a 'Syntactic Complexity Audit' to identify high-density clausal structures typical of scientific abstracts. Scan the source text for long-distance dependencies, nested relative clauses, and passive voice constructions that represent formal academic logic. Meticulously map these structures in the exploration trace to ensure they are not split into simple sentences or summarized during translation. For example, if a 50-word sentence in a medical paper contains a condition, an observation, and a conclusion, the agent must tag this as a single 'Fidelity Unit' to be preserved.
  - Implement 'Domain-Specific Neologism Harvesting' to identify emerging terms in research and technology that lack dictionary entries. The agent must search the source for newly coined terms (e.g., specific 'gamification' sub-types or 'biotech' processes) and check their usage in recent target-language professional publications. First, isolate the candidate neologism, then search for its transliterated or translated equivalent in local journals. An edge case is deciding whether to keep a term in English (borrowing) or attempt a loan-translation based on frequency in the active field.
  - Perform a 'Fact-Unit Locking' pass to protect numbers, citations, and specific entities in technical reports. Identify all numerical data, bibliographic citations (e.g., 'Stockemer and Wigginton, 2019'), and proper nouns within the technical context. Explicitly record these as 'Verifiable Literals' that must not be rounded, omitted, or simplified during the translation phase. A concrete error case is a model summarizing '38 in-depth interviews' as 'some interviews' to save context space, which must be strictly avoided.
  - Catalog 'Logical Perturbations and Academic Fallacies' to ensure the preservation of intentional errors in pedagogical or benchmark content. The agent must identify segments where the logic is objectively wrong or incomplete in professional texts and tag them as Fidelity-Protected Errors. First, verify if the source is an intentionally flawed solution or argument. Then, lock the specific fallacy type—such as faulty mathematical causality—and ensure the translation reflects the same logical gap. As an edge case, if the source states a mathematically false premise like 'all non-integers are rational', the agent must output exactly that literal falsehood in the target language and never try to correct it.
* **Target Trajectory Profile**:
  - Prioritizes 'Scholarly Register Stability' over high-frequency literal translation. The trajectory must show the agent rejecting a common dictionary word (e.g., 'middle age') in favor of a domain-appropriate term of art (e.g., 'median age' or '中位年龄'). The trace records: 'Observation: Domain is Medical; Rejecting colloquial term "middle"; Action: Selecting technical term "median" for clinical accuracy.' This proves the agent is acting as a specialized localization expert rather than a general-purpose model.
  - Demonstrates 'Complexity Preservation' where deep clausal hierarchies survive the linguistic transfer intact. A high-quality trajectory shows the agent checking that every subordinate clause in a research abstract remains a part of the original logical unit in the target language. The log must explicitly state: 'Identified 60-word scientific claim with nested conditions; Action: Maintaining the single-sentence structure in the German target to preserve argumentative force.' This directly counters the common failure of models 'tiring' and shortening technical text into simpler, uninformative fragments.
  - Illustrates a 'Domain-Conditioned Verification' loop where the output is audited against professional standards. The path documents the agent performing a secondary scan specifically to check if the chosen vocabulary matches the user-defined domain tag (Law, Science, etc.). The trace should capture: 'Initial draft used general term "system"; Observation: User specified Law domain; Action: Correcting to "体系" to comply with administrative register.' This ensures the final output is refined based on the specified constraint.
  - Adheres strictly to 'Entity-Fidelity' constraints for technical metadata and citations. The trajectory proves that the agent treated citations, dates, and proper names as untouchable structural anchors. The trace verifies: 'Encountered citation "(Neves et al., 2016)"; Action: Locking string verbatim within the target sentence to ensure academic reference integrity.' This prevents the 'summarization trap' where models drop citations to improve the 'flow' of the text at the cost of its scholarly utility.
  - Features 'No-Correction Guardrails for Academic Logic'. The sequence functionally prevents task drift into problem-solving or editing during academic translation tasks. A correct path actively audits internal reasoning to ensure the agent is not fixing a flawed professional document, but preserving its exact logic and state. The log states: 'Instruction is translation; identifying embedded mathematical logical fallacy; resisting correction mode and rendering the flawed argument literally.' This targets the pathology where LLMs fix academic texts instead of preserving the author's original intended errors.
