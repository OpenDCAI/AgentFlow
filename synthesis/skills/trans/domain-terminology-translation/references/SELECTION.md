# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - 100% Lexical Disambiguation matching the professional gold standard for the identified domain. Accept the trajectory only if polysemous terms (like 'power', 'system', or 'interest') are translated using the precise lemma belonging to the specified field (e.g., energy for Science, authority for Law). Verify this by checking the target tokens against a domain-specific dictionary or glossary. If the 'Science' domain is requested and the agent uses a political term for 'power', the sample is an automatic failure.
  - Preservation of 'Informational Density' measured by clausal mapping and literal counts. Accept the sample if the translation maintains isomorphically similar complexity to the source (e.g., one long technical sentence remains one long technical sentence). The validator checks the sentence count; if a 45-word scholarly claim is split into three 15-word sentences, it must be rejected for structural simplification. This ensures the professional weight and 'Scholarly Aura' of the text are not degraded during translation.
  - Accurate 'Technical Mapping' of neologisms and emergent factual data. The trajectory is authorized only if contemporary terms or recent findings (e.g., 'gamification strategies') are rendered using the most current professional terminology. First, identify the 'emergent entity' in the source, then confirm the target output reflects the accepted scholarly or industry translation. A valid sample ensures that the agent is not relying on stale training data to translate current professional events.
  - Zero 'Summarization Leakage' in the final translated answer. Accept the trajectory only if no informational units (numbers, adjectives, parenthetical caveats) were dropped to improve readability. The agent compares the 'Semantic Unit' count between source and target; any reduction in detail triggers a rejection. For instance, if the source mentions '38 in-depth interviews' and the answer says 'interviews were conducted', it is a fidelity violation.
* **Rejection Criteria**:
  - Defaulting to 'General Domain' vocabulary despite specialized instructions. Reject any sample where the agent ignores the requested domain (e.g., Law) and outputs high-frequency lay-language terms. If the instruction asks for a 'medical report' but the agent uses 'stomach ache' instead of 'gastric distress', the sample fails the register-compliance check. This prevents the synthesis of 'lazy' data that collapses specialized distinctions into generic baseline prose.
  - Unauthorized 'Logic Simplification' or 'Fact Rounding' during translation. Discard the trajectory if the agent simplifies numerical data (e.g., 'approximately 1.5 million' becomes 'over a million') or logical conditions to make the text 'flow' better. Professional and academic translation requires exact parity. A clear rejection is a case where the agent 'rounds' a sports score or a scientific concentration, which destroys the factual utility of the benchmark.
  - Hallucinated 'Domain Knowledge' that goes beyond the source content. Reject any sample where the agent adds extra information about the topic (e.g., adding historical context to a legal document) that was not present in the original text. The agent must strictly translate the provided source and avoid the 'Expert Persona' trap where it provides unrequested explanations or updates. For example, translating a 2024 report by adding facts from 2025 is a source-alignment violation.
  - Loss of 'Structural Integrity' in formatted research metadata. Reject results if the translation of an abstract or paper title breaks the conventional professional layout (e.g., improperly formatting a JATS XML section or dropping a required header). High-quality domain translation includes respecting the 'Container' of the text. If a citation is moved to a nonsensical place or a technical label is translated in lower-case when the domain requires shouting-caps, it is discarded.
  - Computational or Deductive 'Solve-Mode' Hallucination. Reject any sample where the agent skips the translation and instead attempts to correct, solve, or deduce answers based on the professional domain logic. This is a catastrophic failure of the translation constraint for academic texts. The validator checks if the target corrected an intentional error present in the source (e.g., changing an incorrect math formula into a structurally correct one). If the output fixes the source's professional flaw, it is rejected as a fidelity violation.
