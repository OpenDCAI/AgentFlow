# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - 100% Target Morphological Isomorphism matching the required person, tense, and gender markers. Accept the trajectory only if every grammatical category in the target sentence is correctly inflected to match the primary entity's traits. First, verify the agreement between the subject and the verb using a linguistic parser or regex check. For instance, in an English-to-Ibibio task, the sample is rejected if the prefix 'ñ-' is missing from the first-person verb.
  - Zero 'Morphological Defaulting' to high-resource or masculine baseline forms. The sample is authorized only if the agent avoids 'generic' forms (like masculine singular) when the context clearly dictates a specific feminine or plural ending. The validator checks if the model resisted the statistical bias of high-resource languages. A valid sample ensures that a female scientist is correctly rendered with feminine modifiers in Russian or Spanish.
  - Isomorphic Clause-Density Preservation for dense technical sentences. Accept the results only if the original single-sentence logic and nested hierarchies (e.g., Condition -> Consequence) remain fully intact in the target language. The selection filter checks the sentence count; if one long source sentence is split into three short target sentences, the sample fails the structural fidelity check. This ensures that the professional density of the source is not lost during the process.
  - Accurate implementation of Tonal Diacritic markers in phonetic scripts. Accept only if the target text contains all the required accents (grave, acute, etc.) needed to preserve the semantic meaning of tonal languages. The validator compares the character-level diacritic distribution against a known native reference. For example, if 'Yorùbá' is missing its tone marks, the sample is rejected because it destroys the readability and accuracy of the target locale.
* **Rejection Criteria**:
  - Synthetic Hallucination of Verb Roots or Prefixes. Reject the trajectory if the agent creates 'invented' words by combining a correct root with an incorrect prefix (e.g., using a Swedish prefix on a German verb). This typically happens when models are confused by closely related languages like Anaang and Efik. A clear rejection is a case where the prefix 'n-' is used in a context requiring the 'ñ-' nasal variant.
  - Syntactic Fragmentation and Unauthorized Document Simplification. Discard any sample where the agent takes a single high-density source sentence and arbitrarily breaks it into multiple simple sentences to avoid complex grammar. This is a common failure in LLMs where the model prioritizes ease over structural accuracy. If the original text was a complex legal or medical claim, splitting it alters the rhetorical and logical force.
  - Defaulting to 'Prestige' Language variants for minority varieties. Reject instances where an agent, when asked for a minority variety like Oro, defaults to a more dominant language like Efik. The selection layer checks for 'Lexical Leakage' from high-resource neighbors to ensure the minority variant's unique traits are preserved. For instance, if the Anaang word for book is replaced by the Efik version, it is an accuracy failure.
  - Loss of Morphological agreement across Distance Stressors. Reject the sample if the agreement between the sentence head and the predicate collapses after more than 15 intervening tokens. The agent must show sustained grammatical memory throughout the entire clausal span. A rejection trigger occurs if the subject is female at the start but the verb reverts to the masculine default at the end of the paragraph.
