# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Identify high-contrast translation tuples consisting of a source, a machine-generated draft, and the desired target. The agent must first analyze the source to establish the core 'Truth' (including entities, numbers, and logical relationships) before looking at the draft. It then scans the draft to mark potential conflict points where the meaning is absent or distorted compared to the source. For example, if the source mentions a 'Toronto-based' company but the draft omits the location, the agent logs this omission as the primary repair node.
  - Target specific 'Hallucination' and 'Drift' categories in LLM-generated translation hypotheses. This involves scanning the candidate output for words that sound plausible in the target language but have no basis in the source text, often introduced by the model's parametric memory. The agent must check every noun and verb in the draft against the source sentence to ensure zero meaning-leakage occurred during the initial pass. An edge case is a model 'rounding' specific numbers (e.g., 5.6 to 5) or adding adjectives like 'amazing' to a technical report draft.
  - Execute a 'Syntax-to-Semantic' parity check to surface structural errors and robotic artifacts. The agent analyzes the draft's sentence structure, looking for awkward literalisms or syntax carry-overs that result in 'Translationese' rather than natural phrasing. It specifically targets word-for-word mappings of idioms or fixed phrases where the draft fails to capture the figurative weight. A concrete step is identifying a German draft that preserves an English SVO (Subject-Verb-Object) order in a context where German requires the verb-final position.
  - Map domain-specific terminology failures where the draft defaults to high-resource common language lemmas. The agent cross-references technical terms in the draft with a specialized glossary or domain knowledge to see if a professional term of art was swapped for a generic word. It specifically identifies instances where a polysemous word like 'interest' was translated as 'curiosity' in a financial draft. A concrete example includes correcting a medical draft that uses 'stomach pain' instead of the source's 'gastric distress'.
  - Detect 'Ambiguity Introduction' in low-resource or complex scripts like those found in Indian languages. The agent must examine the draft for syntax errors that make the query unreadable or semantically confusing for native speakers. This involves identifying when a machine translation uses general modifiers that change the query's intent (e.g., swapping 'frequent' for 'ordinary'). It documents these as critical corrections needed to maintain the communicative intent of the search query or document.
* **Target Trajectory Profile**:
  - Demonstrates analytical comparison between source and draft to justify every modification. A successful trajectory shows the agent clearly pointing out the specific errors in the machine-generated draft (omissions, repetitions, or drift) before making corrections. The trace records: 'Observation: The draft used a literal translation for the idiom; Action: Substituting with a target-native equivalent.' This proves the agent is acting on identified evidence rather than just re-translating from scratch.
  - Prioritizes 'Source-Fidelity' as the non-negotiable anchor for all edits. The trajectory logs confirm that the refined version is corrected to match the source precisely, ensuring that all semantic units (numbers, dates, proper nouns) are restored. The agent's reasoning should explicitly mention: 'Draft omitted numerical value 56.5; Restoring specific value to ensure factual accuracy.' A failure to avoid is a trajectory that accepts a 'good-sounding' draft that actually contradicts the source data.
  - Features a 'Register-Unification' pass where the final answer maintains a consistent tone. The trajectory documents the agent identifying stylistic 'mixed-logic' in the draft, where some phrases are formal and others are slang, and resolving them into a single coherent register. The log verifies: 'Identifying casual classifier in medical draft; Updating to formal register to match the source professional environment.' This demonstrates high-level socio-linguistic awareness.
  - Shows 'Fidelity Persistence' for complex technical strings and citations. The quality run documents the agent protecting protected literals like JATS XML tags, URLs, or chemical formulas that were corrupted in the draft. The trace records: 'Detected corruption of the citation format in the draft; Reverting to the exact string found in the original source.' This ensures that the 'editing' process does not destroy the computational or academic utility of the text.
