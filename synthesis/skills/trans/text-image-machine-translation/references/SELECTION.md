# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - 100% Format Adherence restricting boundary tags in final output. Mandate that generated output strictly deploys the sequence of <recognize>, <think>, and <translate> elements required to assess cognitive stages. First, parse the target text via regex for these exact markers. Second, verify internal contents respect the formatting rules. Complete failure is triggered when outputs drop OCR mapping tags or conflate logic and extraction stages.
  - OCR Fidelity and Grounded Visual Reasoning referencing verifiable external objects. Confirm the cognitive translation trace cites definitive, recognizable visual elements embedded within the input graphic files to shape its translation process. Target validations ensure the cited 'yellow logo', 'broken stone corner', or 'shoes' legitimately exists within the bounding picture matrix before clearing the sample.
  - Successful 'Noisy-Source Recovery' in the final output string. The sample is authorized if the agent correctly translated a corrupted or misspelled text word (like 'snickers' or 'inch') into its visually correct equivalent. The selection filter checks if the agent's decision was directly backed by a documented visual observation in the trajectory.
  - Isomorphism aligning spatial presentation constraints to generated equivalents. Test instances are flagged as functional if text output replicates the spatial density or layout logic necessary to support its meaning. For example, rendering five brief translated advertising bullet points perfectly mapped against five recognized bounding boxes found parallel along the edge of an image asset.
* **Rejection Criteria**:
  - Hallucinating Visual Cues propagating reasoning distortion. Discard test combinations immediately if the logical explanation tags reference fictional objects or layouts solely designed to prop up a weak semantic guess. A clear exclusion happens if an agent cites seeing 'a medical icon' leading it to translate an ambiguous word as a drug, yet no such icon actually prints into the image's coordinate space.
  - Recognition-Translation Semantic Disconnection. Eliminate entries showcasing severe disparities where the targeted output heavily deviates from the raw characters defined in the recognition block without a mathematically sound visual explanation. If the initial recognition pulls 'Happy Birthday' but the final translation states 'Merry Christmas' despite visual alignment, it constitutes pure generative drift.
  - Fidelity-Ambiguity Mismatch resulting in literal typo translation. Discard the trajectory if the agent fails to correct a source-text typo and instead outputs a literal, nonsensical translation of the text noise. If the text says 'yellowing snickers' and the agent outputs a phrase for 'yellowing snacks' despite shoes being clearly visible, it indicates a failure of visual semantic grounding.
  - Severe Processing Truncation scaling visual inputs. Exclude data outputs yielding premature stops or improperly closed structural formatting brackets resulting from excessive tokenization caps. Complex historical manuscripts, dense storefront images, and cluttered UI pages frequently saturate memory contexts; responses omitting the final clauses fail document completion constraints.
