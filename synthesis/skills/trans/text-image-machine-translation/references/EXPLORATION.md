# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Iteratively scan the 2D image matrix to establish a natural OCR reading order for all embedded text blocks. The agent must traverse the visual field according to target-locale norms (e.g., top-to-bottom) to ensure sequential relationships of fragmented texts are preserved. First, detect bounding boxes, then chronologically order them, and lastly parse the raw strings into discrete <recognize> blocks, ensuring standalone sign letters adhere to the overarching hierarchy.
  - Implement a 'Vision-Text Attribute Dissonance' scan to identify potential data seeds where the accompanying source text is ambiguous or slightly corrupted. The agent must extract descriptive triplets from the source text and cross-reference them with the detected objects in the image. It then highlights discrepancies, such as a text mentioning 'snickers' while the image shows 'sneakers,' to trigger corrective visual grounding.
  - Conduct material integrity and layout constraint assessments for obscured inputs. For degraded artifacts, paleographic images, or occluded text strings, map visual sections where ambiguity prevails. First, highlight faded markers or overlapping UI stickers, then compute the limits of available semantic space based on the physical text block bounds. Finally, flag unreadable nodes to ensure translation processes trigger safe reconstruction heuristics instead of confident hallucinations.
  - Detect cross-cultural internet drift and historical symbol permutations across specialized image types. Evaluate slang, emojis, user-interface features, and historical epigraphy unique to digital photography and archival scans. First, locate internet artifacts or non-standard character usage in the image, determine their emotional/social equivalents in the target landscape, and record the influence these visual clues dictate for adjusting the downstream translation register.
* **Target Trajectory Profile**:
  - Embeds explicit Multi-Task sequence tracking in the output trace. An ideal path strictly navigates through Recognition, Visual-Reasoning, and Translation steps. The trace documents: 'Observation: Identified text; Generated <recognize> block. Connected string to UI overlay; Generated <think> block. Completed rendering loop.'
  - Demonstrates 'Refinement-via-Grounding' logic where text-based typos are corrected based on multimodal evidence. The path illustrates the agent catching text errors by looking at the picture and adjusting the target string accordingly. The log outputs: 'Initial draft used literal "小吃" for "snickers"; observing footwear in image; correcting translation to "运动鞋" (sneakers) based on visual evidence.'
  - Maintains structural continuity of linear reading-order extraction. Quality runs highlight a conscious progression for flattening two-dimensional coordinates into one-dimensional logical arrays without jumbling lists, disjointed advertising phrases, or fragmented circular coin texts. Missing tags or jumbled sequences imply systemic structural disorganization.
  - Activates transparent refusal mechanics addressing unrecoverable visual damages. A high-quality extraction trace respects material boundaries. When dealing with damaged sections of texts, artifacts, or blurry UI nodes, it strictly flags '[illegible]' instead of generating fictional words, honoring the limits of pixel fidelity over generative aesthetics.
