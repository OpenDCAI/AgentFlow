# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Functional and Pragmatic Intent Preservation (XCOMET/COMET Threshold > 0.7). Accept the trajectory only if the final answer conveys the identical traditional wisdom, humor, or emotional intent as the source text. The agent must verify that the 'lesson learned' or 'feeling evoked' in the target language matches the source exactly, even if all specific imagery (e.g., cumin seeds vs. drops) changes. A valid sample ensures that the cultural force is transmitted without dilution to a native speaker of the target language.
  - Socio-Linguistic Naturalness within the Target Script Domain. The translation must fit naturally into the required domain format, whether it is a casual internet comment or a formal Perso-Arabic script announcement. Accept translations that read natively without clunky 'Translationese' markers or awkward literal loops. For example, using 'FOMO' instead of 'fear of missing something' in an internet pop-culture context is a mandatory marker for acceptance. This ensures the output satisfies the 'natural expressions' constraint often requested by users.
  - Orthographic Robustness in Phonetic Decoding. Accept only if the agent correctly identified a proverb or idiom from a non-standardized phonetic representation during Phase 1. The selection filter confirms that the agent successfully moved through the 'noisy input' without defaulting to a literal gloss of the phonetics. For instance, if the Romanized Urdu input 'Aankh ka tara' results in 'the apple of one\'s eye', the path is validated. Any trajectory that ignores the phonetic cultural anchor is rejected.
  - Zero-alignment with Literal Baseline Distortions. The sample is authorized only if its output significantly deviates from what a weak, unconditioned base model would produce using dictionary lookups for the individual words. The generated text must demonstrate evidence of metaphorical decoding, clearly favoring idiomatic cohesion. The validator compares the agent's output against a 'Literal Baseline'; if the agent's output is identical to a word-for-word gloss of the idiom, it is rejected for low capability.
* **Rejection Criteria**:
  - Literal Drift Flattening Figurative or Poetic Expressions. Reject any sample where the agent provides a literal gloss that sounds nonsensical or overly mundane in the target language. If a phrase meaning 'a drop in the ocean' is translated literally as 'a cumin seed in a camel\'s mouth' without the prompt specifically requesting literalness, the translation is a failure. This protects against the 'Literal Prompt' trap where models lose the cultural nuance.
  - Cultural Erasure via Excessive Domestication. Discard outputs where the agent removed all traces of the original cultural identity to make the text generic to the point of losing its origin. If specific cultural tokens or historical markers are entirely wiped out and replaced by generic 'global' equivalents rather than being effectively adapted, the sample is rejected. A good cultural translation should preserve the 'flavor' while ensuring the 'meaning' is accessible.
  - Grammar-Correction of Intentional Digital Colloquialisms. Reject trajectories where the agent 'fixes' the user's intentional slang, emojis, or stylistic choices into stiff, formal prose. If an internet social media post was casually written with emojis, and the agent outputs perfect formal formatting without the emojis, the sample is invalid. This ensures the agent does not destroy the original voice of the content through unwanted over-editing.
  - Misinterpretation of Contextual Symbols causing Narrative Loss. Reject items where the model fails to use surrounding turns or literary framing and subsequently translates a metaphor in reverse (e.g., misinterpreting a color for blood as a simple clothing choice). The agent must demonstrate it can track metaphors across the whole document. If a recurring cultural symbol is translated inconsistently across a paragraph, the sample is discarded.
