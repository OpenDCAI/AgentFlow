# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Source Figurative Seed Templates from both formal and informal corpora. The agent must gather proverbs and street slang written in standard scripts and non-standardized phonetic variants like Romanized Urdu or Hinglish. First, categorize the script type as Perso-Arabic, Latin, or Cyrillic. Then, verify if the literal translation produces a 'nonsensical' or 'insufficient' result in the target language. For example, a phrase like 'A cumin seed in a camel\'s mouth' should be tagged as an idiomatic candidate because its literal English meaning is obscure compared to its actual cultural function.
  - Identify Script-Variant Orthographical Dissonance in informal digital communication. Scan digital forums and texting datasets for instances where native speakers use Latin characters to spell out regional idioms phonetically. The agent must map these phonetic strings (e.g., 'Aankh ka tara') to their standardized script counterparts ('ﺁَﻔᘙ Ⴄၖ ّ؇ﺭﺍ'). First, normalize the phonetic spelling to a common base. Finally, anchor the resolved phrase to its figurative meaning to prevent the model from treating the string as a sequence of unrelated or misspelled words.
  - Map 'Cultural Aura' and Pragmatic Inversion markers using multimodal cues. When exploring social media sources, locate comments where emojis, memes, or typographic slang (like repeated letters) qualify the sentiment of the text. The agent must analyze whether an emoji inverts the sentence's literal meaning, such as a negative statement followed by a laughing emoji implying irony. First, identify the core sentiment. Then, record the visual modifier. Finally, determine how these elements together shift the 'truth-value' of the translation request.
  - Retrieve Extended Narrative History to ensure symbolic continuity. To make literary or cultural translation solvable, extract at least 3-5 preceding discussion turns or adjacent metadata describing the genre (e.g., 'ancient poetry' vs 'modern trap lyrics'). Document exactly how the surrounding context dictates the interpretation of color or objects as metaphors. For instance, in a tragedy, 'red' should be explored as a marker for sacrifice or blood. This prevents the agent from generating disjointed literal translations that ignore the established story arc.
* **Target Trajectory Profile**:
  - Prioritization of Cultural Resonance over Literal Morphological Mapping. A high-quality trajectory must show the agent actively deciding to discard literal wording in favor of a native equivalent in the target language. The trace records: 'Observation: Identified the Urdu phrase as a proverb concerning insignificance; Action: Selecting the English social equivalent "A drop in the ocean" instead of a literal cumin seed description.' This demonstrates that the agent is prioritizing the 'intended effect' on the reader over simple token-for-token dictionary substitution.
  - Explicit Resolution of Script Ambiguity for Phonetic Inputs. The trajectory proves the agent navigated inconsistent Latin-script spelling to recover the underlying native-language idiom. The log should state: 'Detected inconsistent Romanized Urdu spelling; normalized phonetic tokens to identify the idiom "Oont ke munh mein zeera"; mapping to figurative intent.' This showcases the agent's ability to handle the noisy, non-standardized orthography typical of low-resource or informal digital environments.
  - Demonstrated Use of Paralinguistic Cues to Inform Register and Tone. The path documents the agent noting that emojis, slang, or non-standard punctuation alter the core intent of the prompt. The agent's reasoning should explicitly mention mapping these stylistic cues to equivalent mood indicators in the output space. For example, the trajectory records: 'Identified the skull emoji as a pragmatic intensifier for distress; adopting a more dramatic lexical register in the English output.' This ensures the translation captures the 'vibe' as well as the meaning.
  - Avoidance of 'Translationese' via Semantic Isomorphism. The system must showcase active linguistic reconstruction where the output sounds like a native speaker's utterance rather than a machine gloss. If translating a highly colloquial phrase, the tracking log notes the parsing of the underlying sentiment and the purposeful restructuring of the syntax. It strictly confirms that the agent is not simply outputting a character-to-character substitution. For instance, the trace proves the agent replaced a formal passive voice with a street-casual active voice to match the source's social context.
