# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Construct near-miss topical distractor pools to flood the baseline context. Start from one answer-bearing seed passage and deliberately retrieve additional passages that share the same entity type, topic, and lexical field but explicitly omit the decisive fact. For example, a question about a 2022 sports winner should be completely surrounded by 2021 sports winner passages rather than completely unrelated geopolitical news.
  - Implement contextual token reconstruction to handle injected lexical noise. When the agent encounters a mangled token intentionally degraded with typos, it must verify the surrounding words to logically deduce the intended baseline value. A concrete edge case is scanning a technical AI blueprint where 'L1ama' is treated identically to 'Llama' because the surrounding sentences discuss transformer weights and tokenization.
  - Control the noise ratio systematically to prevent the task from degrading into extreme impossibility. Vary the placement and density of distractors across different trajectory runs, explicitly logging which specific injection causes the trajectory to become fragile. You might test an environment where 99 passages mention the exact same statistical metric, but only a single file attributes it to the correct geographic region.
  - Stress-test surface-level retrieval shortcuts by altering snippet placement. Probe whether the model can still succeed when the answer-bearing passage is physically shorter, placed later in the context window, or lexically weaker than the massive volume of distractors. A common edge case is placing the fully correct passage at the very end of an incredibly verbose and distracting irrelevant Wikipedia page.
* **Target Trajectory Profile**:
  - Enforce strict evidence-accounting prior to conclusion synthesis. A robust trajectory explicitly itemizes and accounts for each retrieved passage before attempting to answer, systematically crossing out topical matches that fail the exact prompt criteria. If the agent immediately leaps to an answer without listing why it bypassed the three strongest distractors, the trajectory lacks explicit noise-robust oversight.
  - Demand high-specificity contextual grounding that preserves discriminating tokens. The retained evidence in the log must physically contain the exact differentiating attribute, such as the specific target year, corrupted value reconstruction, or precise role label. For example, logging 'the passage is about literature prizes' is completely insufficient if the actual discriminator is the string '2022' versus '2021'.
  - Maintain a normalization ledger for mangled entities throughout the reasoning pipeline. The trace must explicitly map and log corrupted textual artifacts to their resolved semantic values so downstream execution relies on clean parameters. A perfect example is explicitly recording a step stating: 'Resolved $O.91 as $0.91 due to the surrounding accounting currency context'.
  - Execute noise-aware finalization directly within the response formulation step. The final answer should structurally acknowledge that the discarded passages were reviewed but deemed topically related yet ultimately non-answer-bearing. An edge case exists when the distractor is a factually true global statement, but the agent explicitly states it has been ignored due to lacking the specific sub-slice requested by the user.
