# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Implement Multi-Level Conflict Seeding across document boundaries. You must first select a salient 'seed' statement from a source document that reflects a high-importance fact like a date, status, or quantity. Then, intentionally generate a contradicting statement and embed it either within the same document (for self-contradiction) or in a separate, topically identical document (for pair-wise conflict). An edge case involves placing the contradicting documents at opposite ends of a large context window to test if the agent's attention remains robust across long distances.
  - Deploy Conditional Incompatibility Triplets to test structural logic. Start by generating two documents (D1 and D2) that describe different but non-contradictory aspects of a topic, such as two different hobbies of an individual. Then, create a third document (D3) that introduces a global constraint, such as a lack of time or resources, which makes D1 and D2 mutually exclusive. A concrete example is D1 saying 'X is a doctor', D2 saying 'X is a full-time pilot', and D3 saying 'X only holds one job'; the agent must synthesize the contradiction that X cannot be both simultaneously.
  - Vary Statement Importance to probe detection sensitivity. You should identify statements that are 'most salient' (central to the document's main point) and those that are 'least significant' (peripheral data) using an auxiliary language model. Create contradictions for both types to see if the agent only catches 'obvious' errors or if it can also spot subtle inconsistencies in minor details. An edge case is a document where a core financial figure is consistent, but a minor footnote contains a conflicting date, testing the agent's granular precision.
  - Execute Injected Context Generation for subtle contradiction masking. Instead of simple 'Yes/No' negations, use a model to generate a fluent, full paragraph that incorporates a contradictory fact into a realistic narrative. This paragraph should be appended or prepended to the original documents to ensure the contradiction is not an isolated sentence but integrated into a deceptive context. For instance, if an original document discusses a company's success, the injected paragraph should describe its bankruptcy in a similarly professional and persuasive tone.
  - Deploy Relational-Proximity Auditing for Information Fusion. Execute peer-to-peer AI revision analysis to discover potential semantic drift seeds by scanning generated summaries for sentences heavily bloated with more than three distinct proper nouns. Document these as potential 'Information Fusion' traps where relationships may be fundamentally blurred, forcing the agent to resolve the qualitative drift under confusion. A concrete edge case involves a rewriter deleting a precise date string like 'March 11' and fusing multiple events into a generic 'March' summary, tricking the agent into guessing the omitted granularity.
* **Target Trajectory Profile**:
  - Explicit segmentation of conflict-bearing documents must be formally logged. The trajectory must explicitly log the indices or IDs of the documents found to be in conflict before attempting to formulate a final judgment. It should state: 'Document 1 and Document 4 contain a pair-wise contradiction regarding the merger date.' This ensures the agent is performing evidence-based mapping rather than guessing based on global perplexity.
  - A chronological trace of the active detection process must clearly outline the reasoning path. The agent's scratchpad should showcase a step-by-step audit where it actively compares its current textual evidence against previously read fragments stored in context. It must strictly log each potential conflict as it is uncovered, such as 'Step 2: Found statement about 2022; Step 5: Found contradictory statement about 2021; tagging conflict,' validating the agent's internal consistency checks.
  - The trace must include a rigid declaration of the Conflict Type and its corresponding Rationale. A high-quality trajectory must not only find the error but structurally categorize it as 'Self', 'Pair', or 'Conditional' based on standard logic definitions. The trace should provide a brief verifiable proof, such as: 'Type: Conditional; because while Doc A and B are compatible alone, Doc C introduces an exclusionary rule.'
  - Maintain a 'Consistency Bias Resistance' ledger during massive long-context sweeps. The trajectory must observably continue scanning the entire set even after finding the first contradiction, actively anticipating that multiple cascading conflicts may exist throughout the document structure. It should distinctly log: 'First conflict found in Docs 1-2; safely continuing scan of remaining 10 documents; checking for self-contradictions in Doc 8' to prevent premature and incomplete validation closures.
  - Enforce explicit de-fusion logic for ambiguous sentences harboring qualitative drift. When structurally original and fused synthetic texts coexist, or when a sentence contains multiple clustered entity-action pairs, the agent's trace must detail a step-by-step breakdown of the fused text to accurately verify which specific action firmly belongs to which actor based on baseline context. The internal scratchpad should explicitly list discrepancies or merged facts prior to issuing a concluding statement resolving the semantic ambiguity.
