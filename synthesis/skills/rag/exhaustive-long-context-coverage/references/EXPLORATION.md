# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Map required evidence by document or hierarchical branch. During the initial exploration phase, create a comprehensive coverage map stating what role each document or specific section plays, such as a comparison candidate, a numerical entry for a global sum, or a pure distractor. This explicit mapping prevents the agent from getting lost in massive texts and guarantees a structured approach. A clear example is mapping out 'Chapter 1: Financials' and 'Chapter 4: Risks' before attempting to aggregate any localized budget fragments.
  - Control evidence dispersion and density deliberately across the corpus. Spread required facts so the answer cannot be confidently provided unless the trajectory captures almost 100% of the long-context scope or fully exhausts a specified nested subtree. By enforcing extreme fragmentation, you test the absolute breadth of the agent's attention window. An edge case is distributing 20 separate numerical values across 20 identically formatted legal reports, forcing the agent to read every single line without skimming.
  - Execute high-density entity batch grouping for statistical tasks. When facing queries testing massive distributions, map (Entity, Attribute, Value) triplets uniformly across the entire index to synthesize robust datasets. The agent must systematically traverse these mappings and categorize them accurately before moving to an analytical deduction state. For instance, cataloging the nationalities inside 100 different biographical Wikipedia documents to find the most common geographical region.
  - Track omission risk explicitly through impact analysis. Ensure that removing any single target file or nested paragraph meaningfully and measurably changes the final grouped categorization, maximum calculation, or statistical frequency. If dropping a document alters nothing, the context is merely artificially padded rather than genuinely exhaustive. A concrete test is removing the final document in the sequence and confirming that the computed overall 'highest asset value' drastically shifts to a different corporation.
* **Target Trajectory Profile**:
  - Maintain a continuous document ledger before synthesizing conclusions. The trajectory must log inspected documents and explicitly itemize the core extracted values before outputting an aggregated metric or summary. This strict accounting demonstrates that the agent did not creatively hallucinate the summary but rather built it from grounded, localized chunks. For example, explicitly writing 'Document 4: Score 85; Document 9: Score 92...' inside the scratchpad prior to claiming 92 is the maximum.
  - Ensure broad coverage sweeps precede mathematical or hierarchical operations. The agent must sweep the complete context scope or exhaust the identified hierarchical branch entirely before comparing, statistically grouping, summing, or declaring distributions. Stopping early and extrapolating severely degrades the integrity of the long-context task. An edge case is an agent halting its search at Section 3.1 because it found three names, fatally missing the twenty names listed inside Section 3.2 through 3.8.
  - Enforce uniform treatment of identically formatted documents or sub-sections. The agent must apply a highly consistent extraction and parsing procedure to similar files within the long context to prevent hallucinated variances driven by fatigue. This repetitive precision ensures that structurally identical records yield identical extraction paradigms. A practical example is parsing 50 sequential medical intake forms and utilizing the exact same regex-like logical extraction for 'Patient Age' across every individual form without drifting.
  - Specify the aggregate factual scope formally in the final output. The final answer must explicitly reference the comprehensive extraction volume utilized during the reasoning process rather than providing an unanchored float or bare entity. By stating the boundaries of the search, the model proves it understood the holistic nature of the prompt. For example, phrasing the answer cleanly as 'Out of the 42 candidates identified across all 8 branches, precisely 14 possess the required security certification.'
