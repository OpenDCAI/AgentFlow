# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Bivariate Normal Temporal Alignment: Accept a trajectory only if meal types (Breakfast, Lunch, Dinner) align with natural time windows modeled by the annotation distribution. You must verify that the midpoint and duration follow a bivariate Gaussian curve with standard deviations that prevent unrealistic dining times (e.g., lunch at 10:00). A concrete failure is a meal that starts less than 4 hours after the previous one, violating the 'natural gap' constraint.
  - Poisson-Gaussian Attraction Verification: Accept only if the number of attractions follows a Poisson distribution (λ based on persona) and individual visit durations align with category-specific Gaussian means. The selection unit must check that an adventurous traveler visits more than one attraction while ensuring each visit is at least 60-90% of the standard duration for that category. If an agent scheduled a 15-minute visit to a 3-hour Museum, the seed is rejected.
  - Geodesic Transit Proximity Audit: Accept only if every Point of Interest (POI) in the list has a corresponding transit stop within a functionally reachable radius (ideally < 1km). Human or script verifiers must calculate the geodesic distance from the POI coordinates to the stop provided in the trace. A seed where the 'nearest' transit stop is 250km away because the agent guessed a coordinate represents a logic break and must be discarded.
  - Monotonic Chronological Integrity: Accept only if the entire day's sequence—from accommodation start to accommodation finish—is strictly monotonic with non-overlapping time intervals. You must verify that the agent didn't schedule a 'Flight' during a 'Meal' or an 'Attraction' visit that extends past the 'Departure Time' of the return flight. Any timestamp that is out of order or overlaps with a prior action's duration is grounds for immediate rejection.
  - Hard Constraint Conjunctive Match: Accept only if the plan satisfies 100% of the explicit hard constraints, including cumulative budget, room types (e.g., no-shared), and cuisine preferences. The selection unit must perform an itemized sum of all costs to ensure it remains below the user-provided limit. If a 'No Pets' rule is specified but the agent selects a 'Dog Friendly' cottage, the planning logic is considered unsafe and the seed is noise.
* **Rejection Criteria**:
  - Spatio-Temporal Hallucinations: Reject any seed where the agent claims the environment is consistent (e.g., 'Everything is in Seattle') but the actual logs show cities or transport nodes outside the closed sandbox. This includes 'Teleportation' logic where a traveler reaches a city that has no flight or driving connection. For example, if the plan includes a flight F001 but no such flight exists in the source database, the trajectory is discarded.
  - Static Template Rote Memorization: Reject any trajectory that produces a 'generic' plan that ignores the unique persona components or specific event requests in the prompt. This failure is characterized by the agent providing the same standard attractions for both a 'Luxury' and 'Economical' traveler without altering the accommodation or dining price points. Authentic planning requires the agent to differentiate its choices based on the traveler's latent priorities.
  - Terminal Goal Mismatch (Unclosed Loop): Reject any trajectory that fails the 'Return-to-Origin' requirement or fails to provide accommodation for every night of the trip. The plan must show the traveler either at their final destination or back at their origin city by the end of the final day. A concrete indicator of failure is ending the plan at an Attraction on the last day without a sequence leading to the return flight.
  - Ambiguous Logic Justification: Reject seeds where the 'Remark' or 'Thinking' block fails to justify why specific POIs were chosen over others when the constraints were tight. The planner must demonstrate 'Subjective Optimization,' such as 'Choosing restaurant X because it is the only one serving Indian food near the museum.' If the agent provides no causal link between the constraints and the artifacts, the capability is not doing real work.
