# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Sub-Entity Dependency Discovery: Search for distal goals representing aggregations of distinct entities or sections (e.g., reaction enthalpy of three molecules, or a report with three chapters). Analyze if 'Entity A' and 'Entity B' can be isolated as independent parallel sub-task nodes. Recognizing that a comprehensive workflow features distinct branches prevents fragmented processing and context saturation.
  - Heterogeneous Task Categorization: Label every potential sub-problem as strictly belonging to distinct cognitive types (e.g., Retrieval, Reasoning, or Composition). Determine the dominant requirement—such as fetching facts vs structuring arguments—to select appropriate low-level executor tools. For instance, cataloging a 'verify data' node as a Retrieval-Reasoning hybrid explicitly sets up its tool access hierarchy.
  - Adaptive Recursive Depth Control: Evaluate the atomicity of a defined task node based on complexity limits like token density or action count. Continually question if the active node can be executed safely in a single pass. If a writing objective exceeds 500 words or a spatial move exceeds 20 grid units, systematically force another hierarchical split to maintain strict precision tolerances.
  - State-Based Dependency DAG Mapping: Track prerequisite transitions by assigning state flags (ACTIVE, SUSPENDED, SILENT) to newly generated sub-tasks representing structural lineage. Guarantee downstream terminal assembly tasks inherently begin as SUSPENDED until mandatory upstream parent nodes finish securely. Mapping rigorous node prerequisites actively averts logical execution drift.
  - Workspace-Memory Context Isolation: Sequester irrelevant environment facts separating generic global descriptors from hyper-localized task branches effectively preventing context ballooning. Filter memory streams distributing exclusively critical anchor parameters passing strictly towards assigned child sub-goals. Providing identical raw inputs spanning unlinked task families destroys efficiency generating generalized processing hallucinations.
