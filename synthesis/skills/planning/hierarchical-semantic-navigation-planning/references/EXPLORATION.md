# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Construct a Hierarchical Scene Description Tree (SDT) by scanning the 3D environment in a bottom-up manner starting from atomic objects. First, use a multimodal vision-language model to describe every object's category, attributes, and functionality within a 480x480 view. For example, a 'sofa_1' should be logged with its function ('seating/comfort') and color ('gray velvet') to ensure it is searchable by user lifestyle prompts later.
  - Implement Semantic Zone Partitioning by clustering navigable viewpoints based on both physical connectivity and environmental semantics. Instead of simple spatial clustering, your partitioning algorithm must prompt an LLM to determine if an adjacent viewpoint belongs to a currently active 'functional zone' (e.g., bedroom, kitchen). A concrete edge case involves a robot identifying that two rooms connected by a door are distinct zones, while two open-plan areas sharing a carpet form a single zone.
  - Map Cross-Level Topological Connectivity by documenting the edges between individual views, viewpoints, and the final scene-level zones. You must create a 'Connectivity Adjacency Matrix' that records which zones are reachable from each other and which specific viewpoints act as the thresholds (doors, hallways). For instance, log that 'Zone 1 (Living)' is connected to 'Zone 5 (Kitchen)' via Viewpoint 12, allowing for recursive pathfinding across the hierarchy.
  - Generate Multi-Granular Environmental Summaries by aggregating data from lower levels of the tree into viewpoint, zone, and scene descriptions. Each viewpoint-level annotation must summarize the spatial layout of its six component views into a holistic panoramic description. For example, if three views show a bed and two show a desk, the viewpoint-level description must define the area as a 'multifunctional bedroom/workspace'.
* **Target Trajectory Profile**:
  - The target trajectory must demonstrate a 'Global-to-Local Descent' where the agent progresses from a Scene-Level overview to a View-level target. Concretely, the trace should show the agent identifying the target 'Zone' first, followed by the specific 'Viewpoint' and 'View' containing the goal, and finally the atomic 'Object'. This approximates the NavRAG retrieval framework where target localization follows a top-down, layer-by-layer progression.
  - Trajectories must incorporate 'User Role Simulation' by mapping the navigation objective to a specific persona (age, gender, occupation, lifestyle). The trace should record the agent's logic for choosing a destination based on the persona's needs, such as a 'Graphic Designer' requiring an 'inspiring workspace' found in the attic zone. A failure to link the persona's lifestyle to the selected functional area indicates a breakdown in demand-oriented planning.
  - Include 'Functional-Relational Anchoring' where every landmark or destination is justified by its attribute and purpose within the 3D layout. The trajectory logs must confirm that the chosen path reflects the 'connectivity relations' of the scene tree, avoiding teleportation between disconnected zones. For instance, 'moving to the bathroom through the hallway because the bedroom has no direct door' is a grounded, high-quality trace signature.
  - Wait for 'Semantic Discovery Confirmation' before issuing terminal stop actions at the object level. The trajectory must show that the agent 'recognizes' the vessel sink or the wooden table in the target view before ending the plan. A profile that stops at a coordinate without a preceding 'Visual Verification' against the scene-tree attributes (e.g., 'I see the round vessel sink here') is insufficient for training embodied logic.
