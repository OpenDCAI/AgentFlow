# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Primal Gap and Best-Known-Solution (BKS) Alignment: Accept a trajectory only if the final proposed plan achieves a primal gap significantly lower than a baseline greedy approach when compared against the BKS. You must calculate the gap using the provided formula and ensure it stays within the [0, 1] range. If the agent claims a solution is optimal but its cost is 50% higher than the BKS for a known TSPLib instance, the seed is rejected.
  - Structural Sensitivity Verification: Accept only if the trajectory demonstrates a specific strategic pivot when encountering non-metric or SAT-induced structures. Verifiers must cross-reference the agent's algorithmic choice (e.g., using a Tomita solver for SAT-MIS) against the problem type. If the agent uses a simple Euclidean-based 2-OPT for an Asymmetric TSP, the seed must be rejected as mechanically incompatible.
  - Auditability of Optimization Logic: Accept only if the trace records the 'internal reasoning' for choosing specific metaheuristics, like Simulated Annealing or LNS, over a standard greedy search. Every major change in the state (e.g., swapping edges or relocating medians) must be preceded by a cost-benefit reflection. A valid seed should have at least one 'hill-climbing' or 'rejection' event to prove the agent is exploring the search space effectively.
  - Computational Efficiency Grounding: Accept only if the trajectory achieves its result within a reasonable plan-length-to-benefit ratio. You must verify that the agent didn't take 10,000 steps to solve a 10-node problem, indicating a failure to use efficient search reduction. A sharp seed shows the agent using powerful 'macro-moves' (like large-neighborhood destruction) to jump closer to the optimum.
  - Infeasibility vs. Failure Discrimination: Accept a trajectory only if the agent correctly identifies an 'Infeasible' state (e.g., no tree can span the nodes) vs. a 'Search Failure'. The agent must provide a logical proof or trace showing where the constraints were violated. If the agent labels a solvable PACE challenge instance as 'Impossible', it represents a failure of lookahead logic and is discarded.
* **Rejection Criteria**:
  - Locality Bias Hallucination: Reject any trajectory where the agent assumes 'Local Proximity' equals 'Global Optimality' in a non-Euclidean or SAT-induced graph. This occurs when an agent chooses nodes only by their degrees or distances without checking the global structural logic. For example, picking nodes in a graph solely because they look 'close' when the constraints are purely logical/symbolic.
  - Scale-Induced Hallucination: Reject any seed where the agent claims to have solved a 10M-node problem but only provides a sequence for the first 10 nodes. This indicates 'Plan Truncation' and a failure to handle the extreme-scale artifact. The planning artifact must represent the *complete* solution sequence or a repeatable reduction macro for the entire set.
  - Deterministic Guessing minus Search: Reject any trajectory where the agent 'guesses' a complex bin-packing or TSP configuration in its first step without visible tree-traversal or lookahead. If an agent providing a perfect TSP path for a 5,000-node graph in one thought block, it must be discarded as data-leakage or stochastic luck. True planning requires visible algorithmic work.
  - Non-Local Inconsistency: Reject trajectories where the agent proposes a solution that satisfies local edges but creates a global loop or violation. This is common in Steiner Tree problems where an agent connects Terminal A to Steiner B but fails to connect Steiner B to the rest of the tree. The final artifact must be a globally consistent structure (e.g., a connected Hamiltonian cycle).
  - Ambiguous Optimization Logic: Reject seeds where the 'Remark' or 'Thinking' block fails to justify why the final answer is better than the initial greedy one. The planner must demonstrate 'Optimization Awareness,' explicitly stating 'I performed this swap which reduced the total distance by 15.2 units.' Without this causal link, the capability is not doing active work.
