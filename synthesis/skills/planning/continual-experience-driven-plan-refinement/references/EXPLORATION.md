# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Streaming Task Sequence Mapping: Formulate the environment as a continuous sequence of tasks where the output, feedback, and reflection of Task T are strictly archived as a reusable 'Experience Entry' for Task T+1. This ensures that every trajectory is logged with status metadata defining its programmatic outcome as either a success blueprint or a failure warning. For example, a 'Cold Start' is executed using high-entropy search, but the resultant data structurally informs the memory pipeline so the next similar task avoids identical blind searches.
  - Intent Entropy Filtering: Systematically explore environment seeds where user queries exhibit exceptionally high semantic entropy, lacking explicit scope or proposing ambiguous 'occasions' instead of defined attributes. You must prioritize tasks where a zero-shot direct response would fail, extracting how human expert trajectories successfully broke the vague intent down into phased 'Thought Patterns'. For example, if a user asks for 'music for a rainy day,' categorize this as an 'Intent-to-Attribute' translation challenge forcing the agent to capture a phased planning loop.
  - Strategic Reasoning Abstraction: Instead of merely logging primitive actions, extract the underlying causal 'Why' by generating internal reflection traces that summarize the plan decomposition as a reusable heuristic template. Analyze the environment-state relationship to derive broad functional formulas, such as verifying that multi-object bundles fundamentally require finding an anchor item first. Embed a 'Reasoning Strategy' tag that permanently links these semantic abstractions to their corresponding successful outcomes within the database.
  - Failure Mode Forensic Identification: Target environments supporting dynamic branching to capture 'Near-Miss' trajectories, halting execution specifically to evaluate structural assumptions upon witnessing negative feedback loops. Generate standalone 'Correction Memories' isolating explicitly the flawed action sequence and the conceptual pattern that caused it to prevent comparable regressions. Ensure precise discrimination is maintained, differentiating persistent logic errors from purely uncontrollable stochastic environment permutations in the historical archive.
  - Hierarchical Trace Distillation: Decompose successful multi-hop trajectories into explicitly partitioned, role-aware segments splitting macroscopic orchestrator logic from fine-grained execution metrics. Isolate 'Full-Task' intent patterns denoting broad intention structures separately from 'Subtask' logs designating rigid tool manipulations. For instance, catalog the overall coordination strategy exclusively for the team leader while retaining raw API execution parameters uniquely for the specialized worker application to ensure modularity.
* **Target Trajectory Profile**:
  - Cumulative Improvement Mapping: The resultant trajectory output must trace directly correlated improvements measuring success ratios or efficiency spanning a continuous five to ten task gradient. Expect an observable contraction regarding redundant computational cycles navigating subsequent structurally identical operations. A successful compilation visualizes solving an inaugural task applying twenty exhaustive steps dropping sharply down to eight definitive actions ultimately.
  - Evidence-Based Strategy Reallocation: The pipeline must instantiate a 'Memory Retrieval' function anchoring all newly commenced activities verifying prior knowledge exploitation initially. Transcribe moments whereby the agent comprehensively quotes internalized reflections directly linking isolated strategies ahead of taking active environment states. Statements resembling 'transplanting previously established sorting protocols handling current financial constraints' satisfies requirement criteria explicitly.
  - Phased Hierarchical Intent Structure: The target trajectory must exhibit a clear separation between 'Plan Generation' and 'Plan Execution,' where an ambiguous intent relies on historical 'Thought Patterns' to decompose into distinct sub-phases. Concretely, the trace should show the agent identifying that it cannot finish the task in one shot and must first acquire knowledge to 'Re-plan' its subsequent moves based on past template success. A successful profile shows the transition from Phase 1 (Information Gathering) to a 'Replan' event triggered by experience memory.
  - Modality-Invariant Scaling Demonstrations: Sequences evaluating restricted sub-agents (SLMs) must reflect augmented functional accuracy matching massive models leveraging explicitly localized memory frameworks effectively. Logging requires displaying minimal-parameter models accomplishing rigid tool manipulation structures natively enabled exclusively via extracted subtask arrays. Demonstrating complex parameter inputs injected perfectly despite diminished local capacities proves memory utility significantly.
  - Think-Refine-Act Decision Looping: Compulsory implementation mapping closed-loop logic bridges traversing internal cognition matrices towards historical memory integration explicitly denoted throughout trace generation. Record defined 'Memory Refine' thought blocks detailing active decisions either electing to permanently prune failing data nodes or merge overlapping strategic frameworks cohesively. Proves architectural evolution maintains concise procedural topologies actively resisting disorganized linear record bloating.
