# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Understand the optimization target, submission contract, and read-only evaluation harnesses before proposing changes. The agent should read the metric definition, baseline expectations, and any constraints on epochs, model size, or memory usage. An edge case is when a seemingly strong modeling idea violates the task’s allowed compute resources, forcing early rejection.
  - Perform an Environmental Resource and Hardware Audit to establish the physical boundaries of the research/experiment run. The agent must query the GPU count, VRAM capacity, and total time budget before proposing a strategy. For example, if only one GPU is available, the agent should prioritize Parameter-Efficient Fine-Tuning (PEFT) over full-model training to avoid OOM crashes.
  - Perform a Methodology Proposal pass. Explicitly document the proposed algorithm, core assumptions (e.g., median vs mean parameter aggregation, or specific loss functions), and expected mathematical impact. This prevents jumping into brute-force tuning without a theoretical or justified research direction.
  - Use small, interpretable first experiments to estimate sensitivity. Modify one consequential dimension at a time—such as an alternative loss function, learning rate, or a new normalization scheme—then execute and compare results to isolate causality before scaling up.
* **Target Trajectory Profile**:
  - A strong trajectory must contain at least one baseline measurement and one post-edit measurement under comparable conditions. Improvement is inherently comparative; without a measured baseline, the result is merely code execution.
  - The trace should isolate a small number of plausible intervention levers per iteration, supported by a clear rationale (e.g., mitigating outlier influence or addressing class imbalance). This teaches disciplined scientific modeling rather than blind hyperparameter thrashing.
  - The trajectory should preserve evidence of 'Negative Result Awareness' where the agent intentionally abandons a research path that is failing to yield gains. High-quality data captures the agent noticing that a new loss function is causing 'gradient explosion' and surgically reverting to a simpler baseline before trying a different innovation.
  - The trajectory must exhibit 'Stewardship of State' through the use of snapshots or checkpoint recovery. The agent should demonstrate it knows how to periodically check for saved weights and resume an interrupted training run from the last known good state, which is vital for long-horizon execution.
