# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Deconstruct the user's intent into an explicit 'Dimensional Checklist' (e.g., Who, What, Where, When, Why) before scanning the document. The agent must systematically rewrite the prompt's informal goals into a set of mandatory slots that must be filled. For example, if a user asks for 'the gist of the news,' the agent should internally map this to finding the primary actor, the main event, the timestamp, and the location. An edge case involves identifying when a document lacks one of the 5W elements, requiring the agent to note the absence rather than hallucinating a placeholder.
  - Implement 'Register-Shift Mapping' to translate professional or technical jargon into a target audience vocabulary (e.g., Technical-to-Layman). The agent should scan for domain-specific terms like 'Nynorsk' or 'hypoxemia' and map them to descriptive equivalents like 'a written variant of Norwegian' or 'low blood oxygen.' A concrete step involves building an internal bridge between the professional term found in the text and the simplified phrase intended for the final summary. An edge case arises when a term has no direct simple equivalent, forcing the agent to explain the concept in a short sentence while maintaining the original's gravity.
  - Execute 'Strict Boundary Isolation' to separate on-target facts from attractive but off-target tangential information. The agent must flag segments of the document that involve personal anecdotes, meta-commentary, or historical context that does not satisfy the current focused lens. When summarizing a news report on consumption, for instance, the agent should ignore a detailed biography of the author if the focus is strictly on the statistical data. This prevents 'narrative bleed' where irrelevant story elements corrupt the focused extraction slots.
  - Perform a 'Source Authenticity Audit' to prevent the injection of external 'training-data' knowledge or hallucinated quotes. The agent must verify that every name, date, and quote used in the summary exists verbatim or semantically within the provided context window. If the agent recognizes a familiar entity (like a famous politician), it must strictly reject any details about that person not present in the document. An edge case is the model's tendency to finish a quote based on web-search memory (e.g., 'Minister said...' followed by a famous quote not in the text), which must be blocked during the drafting phase.
* **Target Trajectory Profile**:
  - The trajectory documents a 'Slot-Filling Navigation' pattern where the agent explicitly labels its discoveries according to the requested focus dimensions. Instead of just reading top-to-bottom, the log should show the agent jumping between sections to find the 'Who' in the lead and the 'Why' in the concluding analysis. A successful trace shows: 'Located primary entity [Minister Brekk] for "Who" slot; identified [10% production fall] for "What" slot.' Failure cases often show generic sequential reading with no explicit slot-mapping logic.
  - The trajectory exhibits 'Constraint-Aware Pruning' where the agent records the deliberate removal of salient facts to meet length or focal limits. The agent must demonstrate structural awareness by logging: 'Discarding details on historical 1990 data to preserve character budget for the 5W core elements.' This proves the agent is making value-based trade-offs to comply with user constraints. An exceptional log entry would state: 'Summarized 4 paragraphs into 600 characters while preserving all 5 investigative anchors.'
  - The trajectory highlights 'Stylistic Adaptation Proofs' showing the transition from technical source text to targeted output register. The procedural steps should reflect the agent identifying a complex sentence and logging the simplified version it plans to use. For example: 'Reading "diacritic-heavy target scripts"; translating to "special characters used in writing" for layman audience.' This provides a verifiable chain of custody for stylistic shifts.
  - The trajectory shows an 'Integrity Filter' action where the agent compares a generated candidate sentence against the source to catch external hallucinations. The log should record a verification step: 'Checked quote against source; identified quote part [X] was not in document; re-drafting to remove external content.' This is critical for high-stakes domains like news or medical reporting where model-invented quotes are a frequent failure mode.
