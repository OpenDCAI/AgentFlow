# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Segment the long source by narrative or discourse markers. During exploration, note where the source introduces actors, shifts topics, resolves earlier questions, or changes time periods, rather than just cutting the text blindly by token count. This creates a discourse map that survives later chunking and compression steps. An edge case is a long report where an appendix looks low-salience globally but contains the definition needed to make earlier claims coherent.
  - Construct an explicit claim-to-evidence ledger for legal or argumentative drafting. When responding to a complaint or synthesizing a case, explicitly list every allegation found in the source and map it to a specific piece of evidence in the supporting files. This guarantees that the generated response addresses every required point without accidental omissions or ungrounded assertions. A concrete example is mapping the plaintiff's claim about a 'July 10th meeting' to the specific 'July 10th Visitor Log' file.
  - Build a central chronological timeline to triage contradictions. Extract isolated dates and critical event sequences from opposing sources and align them into a singular master timeline mechanism. If two sources directly clash regarding a specific timestamp, flag the discrepancy for resolution via independent, objective evidence. An edge case is resolving a clash between a subjective witness statement and an automated server log by prioritizing the server log in the final summary.
  - Identify specific semantic constraints for multimodal asset interleaving. When formatting parameters demand embedding images directly within the generated text, map paragraphs discussing visual traits against discovered image metadata simultaneously. Recognizing a text span that dictates architectural details should prompt the agent to explicitly log the insertion point for the associated image. A concrete step is placing a placeholder tag like [IMAGE_LOUVRE] immediately after the descriptive sentence in the planning draft.
  - Track running entities and unresolved references across chunks. Keep a compact state list of the major entities, themes, obligations, or plot lines that persist across chunks. This prevents later summaries from referring to a person, topic, or decision without enough context. A common example is a running context flag that prevents the agent from adopting 'he' or 'the company' long after the original antecedent was lost in a previous window.
* **Target Trajectory Profile**:
  - A good trajectory seamlessly weaves cross-document thematic consistencies. The logs confirm the active integration of partial summary variables, maintaining narrative momentum properly without illogical chronological scene-skipping. If permuting or jumbling sequences accidentally destroys the logical flow, it confirms causal dependencies are actively functioning.
  - A good trajectory documents explicit block-compression methodologies. It establishes precisely why tangential or trivial narrative components underwent pruning. It maintains structural transparency by recording decisions to discard secondary sub-plots. A strong trace highlights exactly how detailed saturation was mitigated to protect the central theme.
  - A good trajectory establishes an explicit Point-by-Point Alignment mechanism for argumentative queries. The operational path must showcase the agent extracting an allegation from source one, pivoting to locate verifying evidence in source two, prior to drafting the corresponding response sentence. Merely drafting lengthy analytical paragraphs devoid of specific evidentiary citations fails the core precision requirement.
  - A good trajectory utilizes decisive contradiction triage when crafting verified ground-truth narratives. Internal step logs effectively capture the moment chronological or factual conflicts were uncovered, followed by explicit prioritization favoring objectively verified documents over highly subjective personal testimonies. This proves resulting 'Trial Fact' drafts are formally logically deduced rather than purely averaged.
