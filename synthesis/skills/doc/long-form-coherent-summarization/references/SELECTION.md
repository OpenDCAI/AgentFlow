# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - The context must be massive enough to force cross-chunk reconciliation. Accept the trajectory only if the original documents materially exceed standard memory limits, mandating block-merging or multi-source synthesis. If the source can be comfortably summarized in one pass, the example does not belong to this skill. A simple threshold check is whether a one-shot read would be extremely trivial.
  - Drafted arguments must be directly linked to undeniable document facts. Accept only if trajectories for argumentative composition show explicit navigational mapping and citations backing every generated rebuttal. Syntheses that indulge in unverified, speculative narrative posturing without citing the provided evidence must be rejected. A failure case is a defense statement that denies a financial error but doesn't point to the specific accounting doc.
  - Timelines must resolve contradictions logically via evidence. Accept only when the chronological flow in the summary perfectly mirrors the factual documents, displaying active resolution of any conflicting accounts. Incorporating disjointed dates incorrectly or failing to referee a clear dispute based on the stamped receipts falls short of the skill's requirements. If the timeline awkwardly states an event happened on both Tuesday and Wednesday without addressing the conflict, discard it.
  - Multimodal interleaving must be contextually appropriate. Accept the trajectory only if requested visual assets or image placeholders are seamlessly embedded in the prose immediately next to relevant descriptions. Outputs that carelessly dump all requested images at the very end or beginning of the text, ignoring contextual adjacency, must be rejected. This ensures the model learns true inline multimodal formatting.
* **Rejection Criteria**:
  - Reject critically short-context environments operating under false pretenses. Discard straightforward paragraph ingestions handled smoothly by simplistic keyword filters that lack necessary progressive state tracking operations. Summarizing trivially sized files intentionally bypasses the specialized continuous generation capabilities entirely.
  - Reject Groundless Creativity or external hallucination insertions. Dismiss generated drafting profiles that invent customized dates, fictional names, or completely imaginary financial amounts noticeably absent throughout loaded validation evidence. Relying on external real-world knowledge substituting strictly constrained contextual sourcing completely ruins the synthesis dataset.
  - Reject completely broken bullet enumerations utterly devoid of narrative fluency. Eliminating core causal links by breaking intricate technical documents down into heavily fractured, unreadable text dumps abandons coherence directives fundamentally. While aggressive fragmentation offers optimal raw density, destroying readability violates essential baseline stylistic benchmarks.
  - Reject structural implementations completely segregating specified visual asset locations. Discard outputs dumping requested reference imagery en masse into a single list underneath the generated text entirely abandoning precise contextual sentence adjacency. Failing structural interleaving protocols systematically destroys multimodal thematic linking.
