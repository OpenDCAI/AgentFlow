# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Execute 'Semantic-Lexical Bridge Mapping' for paraphrased queries. The agent must systematically expand informal user terms into professional or institutional synonyms found in the document's domain (e.g., mapping 'money help' to 'financial grants' in a university database). This involves generating at least three internal sub-queries that use varied formal vocabulary to probe the vector database. A concrete step is recording the transition from 'how much do I pay' to 'tuition fee structure and installment regulations' to ensure high-recall retrieval.
  - Deconstruct the document into a 'Four-Tier Multiple Abstraction Level (MAL)' hierarchy. The agent must explicitly partition the document into multi-sentence, paragraph, section, and whole-document chunks based on inherent structural markers like headers. Chunks should be optimized for length—specifically testing 2K, 4K, and 8K character segments—to determine which granularity best captures the answer without exceeding context limits. For example, a query about a specific date uses a 2K chunk, while a query about 'general eligibility' might trigger a 4K summary chunk.
  - Implement 'Fuzzy Proximity Scanning' to manage OCR noise and visual degradation. For scanned or institutional archives, the agent must intentionally look for anchor words in the vicinity of a potentially corrupted target string (e.g., finding the word 'Section' to help resolve a blurry 'Statute' number). This strategy utilizes local syntax and spatial bounds rather than relying on rigid string matches which often fail in heritage or older institutional documents. A successful step logs: 'Detected visual noise on target span; broadening search to include adjacent semantic anchors to confirm localization.'
  - Perform 'Spatial-to-Logical Coordinate Mapping' for layout-rich documents like institutional forms or certificates. The agent must explicitly map localized semantic strings into machine-actionable spatial boundaries using a 0-1000 scale to ensure the answer is grounded in the correct visual container. This is crucial for documents where a table cell value (e.g., '$500') appears multiple times, requiring proximity to a label (e.g., 'Total Due') for disambiguation. An edge case is a multi-column resolution where the reading order is non-linear, requiring the agent to sort components by X-Y coordinates before parsing.
* **Target Trajectory Profile**:
  - The trajectory documents 'Lexical Gap Resolution' by recording the transformation of the user's informal query into the document's formal terminology. Event logs must show the agent explicitly noting that the user's term 'rule' was mapped to 'Regulation Article 14' in the retrieved chunk. This proves the agent is not just performing random keyword matches but is executing semantic alignment. A failure case is an agent failing to find an answer because it only searched for the user's exact casual words.
  - The trajectory exhibits 'Granularity-Level Selection' reasoning, matching the query's complexity to the retrieved chunk tier. Recorded steps must show the agent choosing between a 'Multi-sentence' chunk for specific values and a 'Section-summary' chunk for thematic or regulatory overviews. This proves the agent is navigating the hierarchy to optimize information density and avoid 'Lost-in-the-Middle' effects. A strong trace shows the agent filtering out irrelevant adjacent paragraphs to shorten the final context for the LLM.
  - The trajectory illustrates 'Coordinate-Semantic Grounding' for localized multimodal retrieval. Logs must show the agent identifying a target string (e.g., a specific student ID) and generating the exact integer spatial bounds confirmed against the document's layout. This ensures the agent is grounded in the physical environment of the PDF or scan. A concrete example in the log is recording: 'Identified target 'Resolution Header' at [X:100, Y:50]; extracting subordinate text block from coordinates [100, 100, 400, 200].'
  - The trajectory features 'Semantic Alignment Persistence' during paraphrased retrieval. For queries that are significantly reformulated from the source text, the path must show the agent verifying the answer's meaning against the document despite the word difference. This confirms that the agent is using the context to synthesize an answer rather than simply repeating snippets. An example is an agent identifying that 'academic performance' in the text satisfies the user's query about 'good grades'.
