# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Construct a 'Global Multi-hop Knowledge Graph (MKG)' by extracting entities and relations across the entire document pool or organizational directory. The agent must proactively identify high-degree nodes, such as entities appearing in multiple pages or persons listed as experts for specific folders, to act as potential 'bridge' points for reasoning. For example, if 'Revenue' appears in a text report and a 'Profit/Loss Chart' appears in a separate slide deck, the agent logs this as a critical relation link for future traversal. An edge case is a document where an entity is referred to by an acronym on Page 1 but the full name on Page 20, requiring an alias-resolution step in the graph to ensure the bridge is not broken.
  - Execute 'Organizational Redirection Navigation' to discover documents or profiles that act as 'referrals' rather than containing raw data directly. The agent must explicitly parse phrases like 'Chen might know about student demographics' as a mandatory intermediate hop, logging the person or repository identifier as a new retrieval target rather than a dead end. This procedural step involves searching meta-descriptions and hints to build a roadmap to the actual evidence source. A concrete example occurs when the agent encounters a 'knowledge hierarchy' where it must first retrieve a file-access-log to find which of three managers possesses the specific 'Quarterly Budget' document.
  - Execute 'Distributed Fragment Discovery' to identify scenario-specific silos where a single logical entity is split across multiple files. The agent should explicitly check for patterns indicating 'split tables' or 'partial records' where one file contains IDs and another contains the corresponding names or values. This involves scanning headers across the entire corpus to find matching keys (e.g., 'ID', 'SerialNo', 'EmpCode') that suggest fragments belong to the same parent object. A high-quality exploration step logs: 'Part 1 of the employee table found in PDF A; initiating search for the remaining columnar data in the repository.'
  - Perform 'Signature Information Mapping' to isolate unique identifying attributes for every candidate evidence page or personnel profile. The agent must scan for 'Distinguishing Details'—such as specific years, proper nouns, or unique formatting markers—that ensure the query points to one, and only one, set of evidence pages. For instance, instead of asking 'Who is the CEO?', the agent identifies the signature 'joined in 2018' to differentiate between current and historical officers in a large administrative archive. An edge case involves identifying when multiple pages share identical information, requiring a refinement pass to add a more specific discriminator derived from the context.
  - Establish a 'Multimodal Modality Split & Captioning' routine to ingest non-textual evidence into the reasoning chain. The agent must process tables and figures by generating high-fidelity, objective captions that map every data cell and visual trend into a text-based format suitable for retrieval. This involves using a Vision Language Model to describe a bar chart's axes and labels explicitly so they can be indexed alongside textual prose. A failure case is a retrieval attempt that misses a visual chart because the agent only scanned for the word 'revenue' in the text but not the label in the image.
  - Implement 'Iterative Query Calibration' to refine searches based on partial discoveries during the exploration phase. When an initial retrieval yields intermediate clues (e.g., discovering a previously unknown entity name), the agent must immediately generate a new sub-query to 'walk' the next node of the graph. This ensures the agent adapts its search parameters dynamically as it uncovers the organizational structure. A concrete step involves the agent recording: 'Retrieved student ID 10532; now initiating search for this ID in the Financial Aid folder to find grant amounts.'
* **Target Trajectory Profile**:
  - The trajectory documents 'Chain-of-Evidence (CoE) Verification' where each hop's result is used as a mandatory filter for the next traversal step. Event logs must show the agent explicitly using the output of Hop 1 (e.g., a referral to a specific person) to generate the search parameters for Hop 2 (e.g., that person's knowledge base). This proves the reasoning is sequential and linear rather than parallel keyword matching across unrelated documents. A strong trace shows: 'Extracted referral for Bhushan from the hint log; initiating direct survey of Bhushan's records for ID mapping.'
  - The trajectory exhibits 'Navigational Referral Logs' where redirections are handled as first-class logical steps. Recorded steps must show the agent identifying that a source does not have the final answer but provides a reliable pointer to the target source. This demonstrates organizational reasoning where the agent understands 'who knows what' rather than just 'what is written'. For example: 'Bhushan does not have student names; however, he points to Chen as the directory owner; moving to Chen's documents.'
  - The trajectory illustrates 'Fragment Merging Procedures' where siloes are combined to form a unified answer. The path must show the agent extracting pieces of data from different sources (e.g., names from File A and scores from File B) and explicitly documenting the 'join' operation based on a shared key. This prevents 'partial answer' hallucinations where the agent only reports findings from the first source it happens to find. A successful log entry states: 'Merging record fragment A from 2014 report with record fragment B from 2015 report to calculate total growth.'
  - The trajectory features 'Epistemic Humility & Honesty' markers where the agent explicitly checks for 'Insufficient Information' before answering. The log must record a verification step checking if all required components of a split document or multi-hop chain were successfully retrieved. If a critical link is missing, the agent must flag the task as unanswerable rather than manufacturing a plausible bridge. This prevents the 'Overconfidence' failure mode where agents manufacture answers purely because they are prompted to do so without identifying valid grounding.
