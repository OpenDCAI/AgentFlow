# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Verify the Indispensability of Timeline Tracking. Ascertain that the agent's successful handling of the task relies exclusively on selecting the structurally newest contextual string. Confirm that when the user invokes 'the most recent' or 'my current,' the agent entirely isolates the correct entity without falling back to simplistic statistical averaging.
  - Demand Maintenance Precision Scores enforcing flawless operational selection (Append vs. Update vs. Pass). Validate that redundant duplications (token bloat) are eradicated by at least 95% in the simulated database. For example, replacing a defined temperature setting demands an 'Update,' while expanding a list of favorite hobbies uses an 'Append.'
  - Check 'Reconciliation Alignment' for detected contradictions. Accept a trajectory only if the response contains a explicit 'Collision Marker' (e.g., 'But you previously mentioned...') citing *both* conflicting data points correctly. If the agent signals something is wrong but points to the wrong historical memory turn, it is a hallucinated correction and must be rejected.
  - Confirm 'Non-Committal Calibration' during intervention turns. Ensure the agent does not arbitrarily pick the older or newer fact as the 'truth' when faced with a blatant contradiction, but instead places the burden of truth on the user via a clarifying question (e.g., 'I notice a conflict here...').
* **Rejection Criteria**:
  - Reject Redundant Extraction Proliferation events where the agent erroneously duplicates active entries solely due to semantic paraphrasing. An agent maintaining separate distinct database rows for 'I enjoy swimming' and 'I like to swim' fundamentally fails the cognitive parameter-updating expectation and must be purged.
  - Discard Anachronistic Recall regressions occurring when the agent inadvertently deploys the 'Pass' function incorrectly, resurrecting irrelevant legacy facts. For instance, if the user relocated their office in turn 4, but the assistant's navigation output in turn 10 directs them to the pre-move location, the update tracking architecture has completely collapsed.
  - Eliminate 'Update-to-Contradiction' Misclassification where the agent flags a normal information update as a logical paradox. If a user says 'My budget was $50, but I've increased it to $100,' the agent must *not* trigger a contradiction alert, as this is standard sequential knowledge evolution. We specifically filter out semantic false-positives.
  - Refuse Schema-Binding Hallucinations where the agent invents novel memory categories to arbitrarily accommodate randomly ingested noise. If an enforced DB schema contains exactly three fixed slots, and the model unilaterally outputs a fourth unstructured key to capture an out-of-bounds topic, it destroys systemic memory integration.
