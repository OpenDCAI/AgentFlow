# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Focus on Same-Slot State Mutations by prioritizing exploration of trajectories centered around explicit or implicit updates to legacy memory variables. Search for casual dialogue occurrences where a user introduces a new value that overrides a previously established fact (e.g., moving to a new city). Establish precise diagnostic traces capturing the exact turn the agent executes the 'Update' command versus the 'Append' command.
  - Implement 'Two-Stage Plan Augmentation' to discover long-range logical landmines. Generate a coherent multi-day baseline memory and insert statements that explicitly negate established foundational facts (e.g., Turn 1: 'Visited Paris'; Turn 50: 'I have never been to Europe'). The agent must explore distinguishing between an 'Evolution/Update' (change of mind) and a 'Logical Contradiction' (mutually exclusive impossibilities).
  - Design Privacy and Opt-Out Probes to test strict data minimization boundaries concurrently with updates. Integrate strings where the user volunteers highly sensitive, non-actionable context (e.g., a medical condition) alongside a standard update request. Confirm the extracted summary log quarantines out-of-schema data to a 'Discard' queue while successfully updating the standard utility parameters.
  - Execute 'Absolute Negation Probes' using keywords like 'Always', 'Never', 'Only', and 'Impossible'. Map how the agent reacts when a historically absolute constraint ('I never drink soda') collides with an impulsive query ('Should I get a Coke today?'). Log whether the agent's internal reasoning detects the 'restoring force' of the absolute history to trigger a clarification intervention.
* **Target Trajectory Profile**:
  - Require Genuine Dependence on State Chronology showing the final generated response undeniably leverages the newest iteration of a dynamic fact. The trajectory should prove that if the agent only read the first half of the transcript, it would fail catastrophically. The internal tracking must specifically note: 'Older value = Hawaii; Newer value = Paris; Returning Paris for current_state target.'
  - Exhibit 'Cognitive Dissonance Detection' where the agent's internal thought block explicitly labels two turns as logically incompatible before responding. To satisfy this, the log should show a structured comparison: 'Fact A: Only Child; Fact B: Has Sister; Relationship: Mutually Exclusive.' The agent must pause and deploy a 'Reconciliation Question' rather than guessing.
  - Execute Exact Maintenance Logic Verification whenever updating strictly defined categories. The profile trace must exhibit structural categorization indicating whether a field is a 'Single Preference' (forcing a destructive Update) or a 'Multiple Preference' (allowing a cumulative Append), maintaining precise database schema fidelity.
  - Demonstrate Noise-Filtering and Category Adherence regarding specific privacy boundaries. A successful trajectory records zero schema 'bleed', meaning the agent successfully processed a user discussing forbidden private attributes without synthesizing new tracking nodes, while still flawlessly completing the allowed concurrent memory update request.
