# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Implement a Quad-Aspect State Analysis probe during early dialogue turns to isolate the semantic 'Main Issue' from the implicit 'Needs.' The agent must explicitly log the seeker's core conflict, their current emotional label, their unstated needs (validation vs. advice), and current trust levels. For example, if a user complains about a noisy neighbor, explore if they need a legal solution or just someone to listen to their frustration.
  - Execute 'Clinical Funnel Seeding' where the user is assigned a specific personal or medical 'Base Case' ground truth but reveals facts only incrementally. Start the agent in a 'Relationship' phase where it only validates frustration, then move to 'Gathering' where it probes for details, ensuring it does not jump to a diagnostic conclusion on turn 1.
  - Execute 'Intention-Strategy Mapping' by identifying which psychological intention (e.g., Cathart, Insight, Hope) best aligns with detected needs. Verify that for a user in high distress, the agent selects a 'Catharsis' or 'Support' intention rather than a 'Give Information' (advice) strategy which might feel dismissive.
  - Perform 'Acoustic-Sentiment Divergence' probes where textual content remains polite but situational context suggests deeper underlying pain (e.g., 'I'm fine' after a major trauma). Log transitions indicating the agent hunts for hidden feelings over literal token meanings.
* **Target Trajectory Profile**:
  - The trajectory must follow a strict ICECoT (Intention-Centric Chain-of-Thought) sequence: [Emotional State Analysis] -> [Intention Inference] -> [Strategy Selection] -> [Final Response]. The specific inferred intention (e.g., 'To provide validation') must directly justify the chosen strategy (e.g., 'Reflection of Feelings').
  - Demonstrate 'Stage-Aware Progression' following a linear sensemaking logic: Fostering -> Gathering -> Providing Info/Diagnosis -> Decision. If the agent skips the relationship building or jumps straight to a solution/diagnosis in Turn 1, the trajectory is rejected for violating the empathy arc.
  - Require 'Active Atomic Fact Integration' where every expert or supportive response is grounded in the accumulated set of previously extracted user facts. The trace must document the agent explicitly citing these personalized details to increase 'Perceived Support' and 'Shared Understanding'.
  - Demonstrate 'Dynamic Relationship Calibration' where the agent's tone shifts as the bond deepens. The trajectory must log a transition from 'Distant/Attentive' to 'Empathetic/Trusting,' deploying deeper 'Insight' strategies only after foundational trust is confirmed.
