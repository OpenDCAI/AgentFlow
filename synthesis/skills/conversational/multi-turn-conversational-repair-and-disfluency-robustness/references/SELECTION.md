# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Verify 'Corrective Intent Alignment' where 100% of the final response's functional parameters match the user's *interrupting* turn rather than the agent's *initial* hypotheses. Accept a trajectory only if the agent successfully prioritizes the user's aggressive override. Any trace showing the agent 'bulldozing' through its pre-planned response despite the user screaming 'Wait, stop!' is completely rejected.
  - Demand a 90% or higher 'Linguistic Noise Removal' confirm the synthesized answer includes zero stutters, filler tags, or unparsed translation artifacts in its internal action placeholders. The selector must verify that if a user says 'Give me... er... sushi... o sea... rolls', the agent's semantic action is `get_food(item='sushi rolls')`. High-quality samples must mathematically demonstrate this clean 'Signal vs. Noise' separation.
  - Assess 'Repair-Tone Appropriateness' by checking if the agent's de-escalation response matches the user's level of 'Social Pushback.' The selection rule accepts responses that adapt gracefully—gentle for mild corrections and more formal/apologetic for sharp, disruptive interruptions. A failure is an agent that sounds 'robotic' ('I will now use your corrected value') or 'condescending' ('Try to be clearer next time').
  - Measure 'Pivoting Latency' by ensuring the agent's response to an interruption occurs immediately in the turn-index. The selection phase must verify that no 'Ghost-Intent' turns exist where the agent tries to arbitrarily finish its old thought for one more turn before acknowledging the user's disruptive fix. A perfect sample shows an 'Instant-Halt' behavior indicating pristine floor-control logic.
* **Rejection Criteria**:
  - Reject 'System Blindness' samples where the agent's history shows it repeatedly making the same 'Premature Interruption' or 'Intent Error' despite the user's vocal corrections. If the user says 'Stop interrupting' in Turn 2, and the agent interrupts again in Turn 4, the model has failed the 'Social-Signal Awareness' requirement entirely. Repetitive stubborn failures must be purged.
  - Discard 'Disfluency/Translationese Mimicry' where the agent starts to use the user's stutters, filler words (uh/um), or broken grammatical translations in its own final authoritative answer. While 'mirroring' is a social skill, mirroring 'Speech Garbage' or broken 'Translationese' is an infection of the model's linguistic hygiene. Any trace that infects the agent's final JSON answer payload with phonetic errors is a hard rejection.
  - Eliminate 'Contextual Drift' cases where a user's corrective interruption causes the agent to forget the *rest* of the task array. If the user only interrupts to correct one part of a multi-layer trip plan, but the agent's subsequent response deletes the other valid hotels and flights, the state management has catastrophically collapsed. A high-quality repair ensures targeted, additive corrections only.
  - Refuse 'Meta-Linguistic Escapes' where the agent's response focuses ad-nauseam on the *fact* of the communication error rather than the *content* of the fix. Reject samples where the agent says 'I noticed our conversation had a structural mismatch, let's try again' without actually answering the user's corrected request. The user's interruption is a signal to fix the task, not start an AI-ethics debate about misunderstandings.
