# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Verify 'Verdict-to-Policy Alignment'. Accept only if the agent correctly enforces 100% of the ground-truth rules, including unbending parameters around privacy, transit times, and budgets.
  - Demand a 'Prerequisite Success Rate' (PSR) of 100%. Ensures final actions are strictly preceded by mandatory workflow checks and required dependent node verifications.
  - Confirm 'Disclosure Abstraction/Feasibility Logic'. Check that the agent provides compliant alternatives (generalized statuses or alternate routes) rather than flatly shutting down or bypassing spatial realities.
  - Assess 'Contextual Resilience to Parameter Shifts'. Evaluates whether an agent dynamically flushes stale dependencies and re-evaluates all constraints when a modifying factor is introduced mid-stream.
  - Validate against 'Teleportation or Hallucinated Authorization' ensuring zero events assume zero-travel time, impossibly cheap rates, or magical authorization sequence bypasses.
* **Rejection Criteria**:
  - Reject 'Helpfulness Bias (Sycophancy)'. Discard any trajectory where the agent bypasses a security gate, budget limit, or transit impossible gap merely because the user demanded it or complained.
  - Discard 'Contextual Bleed and Hallucination'. An agent reporting successful outcome confirmations without the user providing required procedural tokens (like email or location) constitutes a hard failure.
  - Eliminate 'Dimensional Silo Planning'. If the agent satisfies a temporal query but blatantly ignores a coupled geographical impossibility (booking tasks 10 miles apart back-to-back), purge the trace.
  - Refuse 'Privacy Fundamentalism' or 'Robotic Wall-Shaking'. Exclude runs where the agent opts for generic AI-refusals rather than navigating the complex boundary safely to provide remaining compliant utility.
  - Reject failures in 'Workflow Reset Logic', such as responding definitively to an older subset state rather than aggressively recalibrating the full matrix to newly injected facts.
