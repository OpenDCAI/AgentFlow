# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Start from capability-bearing situations centered on reasoning-heavy domains (math, economics) where answers require explanation, or open-ended chit-chat situations where the user provides background details (job/hobbies) expecting a proactive intellectual connection.
  - Implement 'Intent-Seeding' where a simulated user holds a complex reasoning goal but initially phrases it with heavy conversational entropy. Observe if the agent can correctly recover the context and construct the logical bridge step-by-step.
  - Utilize 'Face-Sensitive Topic Seeding' and 'Proactive Insight Injection' to discover moments where conversational harmony and user engagement can be optimized via active coordination and tailored thematic suggestions rather than generic service fillers.
  - Execute 'Dynamic User-AI Divergence' and 'Participation-Volume Probes' by simulating a user attempting to solve a problem alongside the agent but making an intermediate logical error, tracking which styles of agent correction or face-saving strategies elicit the highest user participation.
* **Target Trajectory Profile**:
  - The trajectory must require genuine dependence on conversation state, showing either an initial ambiguous prompt shifting to a grounded resolution, or a simple bio being transformed into a deep, proactive discussion topic.
  - Require evidence of 'Collaborative Correction' augmented by 'Face Preservation'. The trace must document an explicit turn where a previous user assumption is gently expanded/rectified utilizing politeness protocols that prevent the user from withdrawing from the dialogue.
  - Demonstrate 'Resolution Persistence' and 'Cognitive Immersion Maintenance' spanning 3 to 7 turns. The agent must sustain the logical thread of a difficult problem or nuance without drifting into off-topic distraction when the user gives short answers.
  - Feature 'Interactive Coordination' elements where the agent consistently synchronizes with the user's flow through echoing and verification steps before pushing the didactic logic forward, assuring mutual understanding.
