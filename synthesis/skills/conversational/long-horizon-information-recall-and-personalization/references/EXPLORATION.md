# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Implement 'Implicit Metadata Fragmentation' by taking a user's target attributes (e.g., age: 40, hobby: gardening) and scattering them as casual, off-hand remarks across a 10-turn dialogue trace. Instead of having the user provide a bio, force the agent to infer explicit traits from contextual dialogue such as 'I'm exhausted from pruning the roses today.' This strategy ensures exploration logs have high implicit understanding value, preventing the model from relying on rote keyword matching. An edge case to track is when a user's casual exaggeration triggers a false extraction, necessitating tight filtering.
  - Construct 'Interference Contexts' by having multiple participants or shifting scenarios mention polar-opposite or highly similar facts to test for semantic leakage across user boundaries. During exploration, simulate a participant saying they like 'Dogs' and another saying they like 'Cats,' then audit the memory bank to verify correct source attribution. An important edge case to record is when User Y changes their mind mid-conversation, requiring the agent to correctly update the conflicting fact without overwriting User X's static preference.
  - Execute 'Asynchronous Schedule Seeding' by introducing tasks and timestamps at Turn 2, then introducing a conflicting or related task at Turn 9. The agent should log these events as a timeline object in the trajectory state to simulate a 'Schedule Conflict' environment. For example, the user mentions an 8 PM flight early on, and later asks to book a dinner at 8:30 PM, forcing the agent to detect the narrow transition window. An edge case involves testing temporal overlap resolution when the second task spans across a vague timeframe such as 'tomorrow evening'.
  - Implement 'Memorable-vs-General Subject Partitioning' to discover past knowledge seeds that provide a high probability of future relevance for proactive topic steering. The agent should categorize historical turns separating 'Memorable' personal events from 'General' social chatter, subsequently using actionable memory to bridge current idle conversations back to the core persona. A critical edge case is an 'Anachronistic Interaction' where the agent attempts to proactively steer back to a topic the user already resolved or explicitly expressed a desire to avoid.
  - Leverage 'Distant-Turn Retrieval Probes' by designing 25-turn interactions where a crucial preference (e.g., 'I hate spicy food') mentioned at Turn 1 is relevant to a task at Turn 25. Ensure the intervening 20 turns involve significantly different topics to test the model's resistance to 'Recency Bias' and 'Intermediate Noise'. A successful exploration log will show the agent specifically pulling the remote preference forward to influence the final decision, with an edge case focusing on resolving conflicts if intermediate turns introduced nuanced exceptions.
* **Target Trajectory Profile**:
  - The trajectory must require 'Cross-Turn Synchronization' where the final answer is provably unattainable unless the agent reconciles at least two non-adjacent information nodes (e.g., Turn 1 and Turn 10). The log should document a sequence where answering via local context alone produces a generic failure, validating that deep historical tracking was utilized. A high-quality profile shows the agent's internal state actively linking 'User_Hobby_Dali' (Turn 3) and 'User_Job_Tourism' (Turn 8) to generate a personalized synthesis. If the question is solvable using only recent turns, it fails the profile constraint.
  - The profile must demonstrate 'Proactive Conflict Mitigation' in schedule-based scenarios to verify environmental consistency scaling. The trajectory trace needs to show the assistant actively interrupting a request to flag a temporal clash established previously in the history. For instance, if the user asks to 'Add a haircut at 3 PM,' the log must verify retrieval of the '3 PM Meeting' from Turn 5 and propose a clarification rather than blindly executing the overwrite. Failure to proactively flag scheduling collisions indicates shallow memory utilization.
  - Require 'Identity-to-Fact Grounding' logs where the final assistant response deploys a detail provided exclusively by the currently active speaker in a group setting. The profile must demonstrate that the agent explicitly ignored distractor facts provided by different speakers in adjacent turns. A high-quality trajectory features the agent stating 'As we discussed earlier, your favorite is sushi' for Jack, while actively shifting its memory matrix when Olivia speaks next. Mixing facts across participant timelines must be flagged as a strict rejection condition.
  - The sequence must feature 'Appropriate Opportunity Detection' when leveraging persistent memory for proactive engagement maneuvers. The generated logs must feature a clear transition mapping the current context gracefully into the historical memory without feeling abrupt or robotic. An optimal trace requires the internal thought process to map the logical bridge before speaking, ensuring the leap from 'hiking today' to 'weather in Paris last year' makes cohesive semantic sense. Poor profiles displaying forced or spammed historical recalls are demoted for lacking social calibration.
  - Demonstrate 'Semantic Diligence against Forgetting' guaranteeing the memory retrieval logic does not decay due to expanding token windows. The recorded timeline must show the accurate propagation of Turn 1 constraints through exactly 20 subsequent rounds of divergent distraction topics. A successful internal validation captures the model continuously auditing background policies despite intense local topic shifts. If the agent gradually loses profile attributes mid-conversation, the trace must document the exact contextual token threshold where the failure occurred.
