# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Verify a 'History-Dependency Ratio' of 100%, meaning the personalized answer mathematically cannot be produced if the dialogue history context is deleted. The sample is strictly accepted if the 'Personalized' version of the response is significantly more targeted and useful than a sanitized 'General' baseline. For an example to pass, suggesting a 'Dali museum' because the agent remembers the user's specific interest must demonstrably outperform a generic city itinerary.
  - Demand 'Attribute Alignment Precision' where every personalized detail utilized in the generation maps flawlessly to an explicit event or statement in the user's prolonged history. The evaluation mechanism must cross-reference claims like 'since you like football' to direct conversational evidence within the provided source logs. If the generative response invents a preference or hallucinates an assumption about the user's lifestyle, it immediately fails the integrity benchmark. Accurate memory retrieval must strictly bound the LLM's inherently creative priors.
  - Check for 'Zero Attribute Bleed' ensuring the synthesized response is free of keywords or relational concepts belonging to alternative participants in multi-interlocutor settings. The grader must verify that if User A listed their dietary restriction and User B listed theirs, the resultant answer for User A contains precisely zero elements referencing User B's diet. Any 'hybrid' response that merges multiple user states into a single conversational thread signifies critical identity-state tracking framework collapse.
  - Assess the 'Proactivity and Engagement Threshold' by scrutinizing whether the agent successfully pivots idle text to related historical elements optimally. The trajectory is accepted only if the 'Topic-shift Detection' module correctly identified an 'Appropriate Opportunity'—initiating the historical pivot at a logical conversational junction. Any trajectory that abruptly forces historical context onto an unrelated user crisis or professional query must be rejected for poor social intelligence mechanics.
  - Confirm 'Non-Sycophantic Clarification' whenever a newly provided memory variable conflicts ambiguously with deeply entrenched long-horizon constraints. True capability is accepted when the model asks 'You previously told me to block all dairy, but this recipe has cheese—are you sure?' rather than blindly fulfilling a potentially violating request. A passing sample proves the persistent memory architecture is authoritative enough to securely challenge new local context inputs.
* **Rejection Criteria**:
  - Reject 'Generic-Politeness Plateaus' where the agent's personalization is strictly limited to stylistic framing (e.g., saying 'I know you are very busy') entirely lacking actionable operational history details. The dataset must effectively teach 'Informational Grounding' where concrete previous facts definitively shape the generated outcome. Profiles that sound exceptionally personalized but contain absolutely zero factual anchors retrieved from the dialogue history must be discarded for superficiality.
  - Reject 'Omniscient Collapse' examples where the agent provides an overarching summary of everything everyone previously said in response to an individual participant's personal question. If Jack asks 'What do I want?' and the agent inexplicably answers 'Jack wants sushi and Olivia wants chocolate,' it fundamentally fails to emulate individual constrained perspective. The agent must strictly respect the individual nature of the inquiry by aggressively filtering out alternative users' personal data parameters.
  - Discard 'Linear Memory Leakage' situations where the agent hallucinates facts originating from completely disparate user sessions into the active user's persistent record. This directly highlights an architectural failure separating distinct 'User Trajectory Sets' in local testing environments. If response formatting for a current prompt injects preferences specific to an entirely distinct identity tracking log, it triggers an immediate catastrophic failure classification and must be deleted.
  - Eliminate 'Context-Length Amnesia' sequences where the agent's response helplessly reverts to a generic assistant persona solely because the target facts resided too deeply within the preceding contextual transcript. We specifically target instances where the model's 'Personalization Score' abruptly drops to zero due to implicit token-skipping in the underlying transformer architecture. An accepted trajectory absolutely must illustrate the agent reaching backwards across heavy contextual interference to fetch remote facts faithfully.
  - Refuse 'Aggressive Passive-Bypass' records where the agent possessed obvious access to highly relevant memory hooks but chose 'No' for topic-shifting throughout the entire extensive session. If a user discusses a generic concept for 5 turns and the agent completely ignores a directly mapping personal event located in the user's permanent profile, the sample embodies 'passive compliance'. These traces severely degrade the training logic prioritizing persistent and engaging historical synergy.
