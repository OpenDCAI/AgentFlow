# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Implement 'Conflicting Instruction Gradients' by establishing a set of rigid, mandatory instructions in Turn 1 (e.g., word counts, bullet limits, lexical complexity) and then introducing 'stylistic nudges' in Turns 2-10 that encourage a violation. At Turn 3, ask the agent to 'be more detailed'; at Turn 7, check if the model has drifted beyond the original constraint. Document specific conversational contexts that triggered the loss of intent.
  - Execute 'Proficiency-Tiered Persona Seeding' by assigning the agent specific pedagogical grammar constraints (e.g., 'Only use CEFR A2 vocabulary' or 'Must feature an inverted conditional phrase'). The explorer must log the 'complexity delta' between the user's evolving turns and the agent's strictly bound output, verifying the agent doesn't accidentally mimic advanced user vocabulary that violates its A2 constraint.
  - Utilize 'Reminder-Intervention Loops' to test the controllability of context drift. During exploration, identify a trajectory that is actively drifting (e.g., exceeding a word limit) and inject a 'Goal Reminder' (e.g., 'Remember the original rules') at Turns 4. Observe and log if the KL divergence from the reference policy immediately drops, confirming the 'restoring force' mechanism.
  - Develop 'Mixed-Initiative Consistency Matrices' inside multi-turn simulators to observe agents handling 'Stray Intents' (e.g., a user wants a flight but starts talking extensively about local restaurant prices). The agent must verify that the internal 'Next Steps' blueprint continues mapping the flight requirements securely within its token window, ignoring the high-volume restaurant noise.
* **Target Trajectory Profile**:
  - The trajectory must exhibit 'Stable Equilibrium Behavior' where divergence from the goal does not grow boundlessly but fluctuates within a strict noise-limited band across 8+ turns. The log must show that the model's 'Drift Velocity' decreases as it moves further from the anchor. If numerical limits or grammatical rules are entirely abandoned by Turn 6, the trajectory is a 'Runaway Drift' failure.
  - Require 'Syntactic-Semantic Coherence' for linguistic constraints, ensuring that mandated grammatical structures (like 'would have') are naturally integrated rather than randomly appended. The trace must document that the target grammar structure is the actual carrier of the communicative intent, rather than a robotic tag-on (e.g., 'I agree. I would have.') which reflects low-quality text generation.
  - Demonstrate 'Constraint Priority Resolution' where the agent successfully navigates turns containing contradictory instructions. The trajectory log must record a 'Verification Step' where the agent counts its own output tokens, bullets, or checks its vocabulary tier before finalizing the response. An edge case is an agent explicitly telling the user: 'I can't add that detail because it exceeds our 130-word limit'.
  - Feature 'High-Fidelity Reminder Recovery' where a drifting agent is pulled back to 'Perfectly Aligned' immediately following a system or user intervention reminder. The log must document the specific 'KL Divergence Drop', proving that the underlying probabilistic distribution reliably snapped back to the original foundational policy intent.
