# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Verify a 'Negative Bias Slope' in the drift diagnostic, confirming the agent exhibits a 'restoring force' to its original goal. Acceptance requires that when the model drifts further from the reference point, the subsequent turn-to-turn changes naturally direct back toward the anchor. Runaway divergence with a positive exponential slope is completely rejected.
  - Demand 100% 'Zero-Drift Baseline Fidelity' for Turn 1, ensuring the agent was perfectly compliant at the start of the interaction. If the model flips its answer, violates a bulleted counter, or breaks CEFR complexity rules on the very first try, it is a basic instruction-following failure, not a multi-turn drift failure, and must be eliminated.
  - Assess 'Grammar/Length Detection Precision' using internal strict counters to ensure target skills are physically present in the response tokens. Accept a trajectory only if the exact requested rule (e.g., exact word limits, exact EGP grammar rule #627) is demonstrably satisfied by a parser logic script. Constraint evasion by hallucination is strictly excluded.
  - Confirm 'Noise-Limited Stability' by ensuring the standard deviation of the drift trajectory is tightly bounded. We reject samples where the agent's performance becomes wildly inconsistent between turns. The trajectory is accepted only if the fluctuations from the reference policy can be explained by minor linguistic variation rather than a total abandonment of the goal-context.
* **Rejection Criteria**:
  - Reject 'Monotonic Intent Decay' samples where the agent's adherence to rules drops turn-by-turn without any sign of stabilization or recovery. A summarizer that slowly forgets its bullet-point-limit and devolves into a generic chatbot represents fundamental conversational decay and must be actively purged from the dataset.
  - Discard 'Helpfulness Bias (Sycophancy)' where the agent violates a mandatory Turn 1 rule simply because the user nudged them playfully in Turn 2. If the user says 'forget the word count' (when the system prompted it as absolute) and the agent agrees, it has failed the 'Instruction Persistence' test. Agents must protect the original system constraints above social agreeability.
  - Eliminate 'Contextual Bleed' from discarded branches in versioning scenarios. If the agent is instructed to revert to 'the plan from Turn 3' but its output still includes specific details uniquely injected in Turn 4, the state management module has catastrophically failed. Clean memory isolation between explicitly requested versions is paramount.
  - Refuse 'Out-of-Role Knowledge Leaks' where the agent utilizes advanced doctoral-level vocabulary while purportedly satisfying a beginner (A1-A2) linguistic constraint. We must verify 'Holistic Linguistic Calibration'—ensuring that vocabulary tiers, sentence length constraints, and explicit grammar templates all securely reside within the precise proficiency band requested in Turn 1.
