# Phase 3: Data Synthesis Instructions
* **Question Generation Rules**:
  - Layman Temporal Phrasing: Use natural, non-expert language to describe the physical timing requirements, avoiding technical terms like 'milliseconds' or 'asynchronous delay'. Start with a user-friendly instruction like 'Be patient and wait for it' or 'Hold that button down for a bit until it unlocks'. For example, instead of 'wait 5000ms,' ask: 'Wait for a few seconds until the password reveals itself on the screen.'
  - Constraint-Based Hinting: Design the question to include subtle hints about timing that force the agent to monitor on-screen indicators like 'Watch the timer' or 'Wait for the signal'. You should frame the task so the agent must ground its action duration in a specific visual indicator rather than a hard-coded value. For example, 'Keep holding the button until the light turns green' tests coordinate and temporal synchronization simultaneously.
  - Reactive Frequency Challenges: Synthesize tasks that require rapid-fire repetition or precise coordination with moving parts using action-oriented language. Specify a count or a speed condition in the prompt to structure the difficulty, such as 'Click that target three times before the time runs out'. A concrete question would be: 'The star is moving faster every time; can you click it three times in a row to get the code?'
  - Outcome-Linked Synchronization: Ensure the 'Answer' or 'Goal' is a unique piece of data that is only generated by the environment *after* the precise timing condition is met. This ensures the synthesized task measures the agent's ability to achieve the state-change through timing rather than guessing. For example, 'Enter the secret code that appears only after you wait the perfect amount of time' links the answer directly to the temporal interaction.
  - Temporal Integrity Distractors: Include a distractor in the environment that looks like a shortcut but actually resets the timer or aborts the hold. You must design the task so the agent must choose to 'ignore' the distractor and maintain its temporal posture (like continuing to wait). For example, place a prominent 'Skip' button that actually fails the task, forcing the agent to stick with the 'Patience' requirement.
