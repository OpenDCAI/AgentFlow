# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Textual-Visual Memory Consistency: Accept trajectories exclusively where the 'Action Result' logged in agent memory flawlessly corresponds to the visual UI transformation between screenshots. Ensure physical delta validation, rejecting paths where memory claims completion but the screen dictates otherwise. For example, discarding a trace that notes 'Search success' while the visual UI is still trapped navigating a loading spinner.
  - Information Recall Fidelity: Accept cases solely where the exact character casing and semantic substance transferred perfectly into the destination context. Verify no truncation, typo mutations, or latent hallucinations snuck into the finalized input field payload. For instance, rejecting a trace if a booking request mutated 'Trojan Crossfit' into 'Trojan Gym' during the application transfer process.
  - Widget Protocol Form Compliance: Accept files tracking successful interactions with complex GUI widgets (like dropdown arrays or radio elements) mapped from text-based concepts. Verify the final rendered state of the non-text widget physically reflects the user's documented intent. For example, accepting a case where a PDF mentioning '10 years experience' resulted correctly in checking a radio box explicitly labeled 'Senior Level'.
  - Worth-to-Save LTM Efficiency: Accept trajectories demonstrating selective abstraction, exclusively storing high-utility procedural variables within long-term memory structures. Audit the context memory ensuring extraneous UI labels, irrelevant ad content, or background noise were successfully pruned out. For example, penalizing a trace that memorized a map's entirety instead of solely the destination venue's name.
  - App-Switching Navigation Stability: Accept inputs where the procedural transition betwixt differing operational scopes or software apps completes without destructive looping. Ensure direct trajectories from 'Source Desktop' to 'Sink Dashboard' successfully bypass irrelevant or crashed environments. For example, validating a direct switch from Google Keep to Slack via standard OS Recent App functionality without losing focus.
* **Rejection Criteria**:
  - Data Hallucination from Snippets: Reject occurrences where the intended transfer variable is 'guessed' via offline knowledge rather than robustly extracted from the rendered live-source application. Confirm extraction steps exist prior to populating the sink application. For instance, hallucinating an executive's name based on training data instead of visibly extracting it from their rendered web biography.
  - Context Window Trivialization: Reject trajectories attempting to brute-force cross-app context by dragging 100 historical screenshots without executing any explicit 'extraction and abstraction' actions. Deny behaviors failing to distill image data into concise cross-turn variables. For example, an oversized trace lacking discrete memory extraction labels violates the core abstraction mechanic of this capability.
  - Semantic Mapping Omission: Reject instances entering misaligned variable values into contradictory or incorrect destination input labels. Verify the text classification aligns fundamentally with the UI element's structural purpose. For instance, failing the task if the user's phone integer string is incorrectly pasted into the destination's 'Email Address' contact box.
  - Incomplete State Terminal Omission: Reject traces ignoring required document data parameters during population, abruptly terminating prior to concluding the full workflow transition. Confirm visually any required field error highlights to enforce exhaustive task monitoring. For example, prematurely finalizing an Uber request before actually pasting the destination derived from the calendar application.
  - Disconnected Task Parallelism: Reject paths manipulating two differing applications entirely autonomously without any dynamic shared data transfer string linking them sequentially. Demand causal interconnectedness. For example, opening Maps and sequentially opening Chrome to unrelated URLs does not constitute coordinated cross-app structural processing.
