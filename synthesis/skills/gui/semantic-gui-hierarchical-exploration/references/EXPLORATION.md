# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Semantic Hierarchy Hypothesis Generation: The agent must predict which top-level menu label (e.g., 'Settings', 'Profile', 'More') is most mathematically likely to contain the targeted leaf-level function. By ranking visible labels according to their semantic proximity to the user's intent, the agent creates an ordered list of navigation branches to probe. For instance, if the user wants to 'Change Private Messages', the agent must prioritize 'Settings' or 'Privacy' over 'Discovery' or 'Feeds' icons.
  - Hierarchical Depth Auditing: Systematically record the number of interaction hops and the 'Parent-Child' relationships between UI screens to map the application's structural skeleton. You should explicit log whether a function was discovered within a primary view, a nested list, or an off-screen scrollable area to establish a navigation prior. A concrete case involves noting that the 'Avatar' change is nested under 'Personal Information' inside the 'Profile' page, marking this path for future discovery.
  - Functional Icon-to-Intent Mapping: Scan for elements lacking text labels and assign functional keywords to them based on universal GUI symbol conventions (e.g., gear for settings, headset for support). You should record the bounding boxes of these icons and document the screen transition they trigger to verify your hypothesis. For example, clicking an 'Ellipsis' icon and documenting that it reveals a 'Drafts' option confirms the icon acts as a gateway to hidden hierarchical functions.
  - Backtracking and Error Sensitivity Probing: Intentionally enter semantically plausible but ultimately incorrect menus to identify the visual cues that signal a dead end. You should record the first state where it becomes clear the target is not present—such as a blank list or a mismatched category—and execute a 'Back' action to return to the last valid decision layer. An example is entering the 'Display' settings to find 'Language', realizing it is missing, and immediately returning to the root settings list.
  - Off-Screen Content Sweeping: Perform vertical and horizontal scroll gestures on deep-level pages to ensure functionalities hidden by viewport constraints are accounted for. You should check if the scroll result reveals new distinct element types, such as a 'Log Out' button or custom 'Theme' toggles that were previously obscured. A successful sweep identifies that certain critical settings only appear after three consecutive upward scrolls in a dense account profile.
* **Target Trajectory Profile**:
  - Intent-Aligned Path Progress: A high-quality trajectory must show the agent navigating directly through increasingly specific menus that match the goal's semantic domain. You should ensure each transition leads to a screen with higher informational density related to the target function (e.g., moving from 'General' to 'Account' to 'Security'). A trace that wanders into the 'Language' settings while trying to find 'Payment' must be marked as sub-optimal during processing.
  - Verified Backtracking Recovery: The trajectory should demonstrate the agent's ability to recover from an exploratory mistake without user intervention. You must verify that if the agent enters an incorrect sub-menu, it perceives the absence of the target, executes a 'Back' command, and then selects the correct alternate branch. A gold trace would show an agent entering 'About' to find 'Privacy', realizing the mistake, and then choosing the 'Privacy' menu at the 12th step.
  - Hierarchical Landmark Persistence: The agent must maintain the terminal goal intent (e.g., '15-minute timer') throughout all intermediate navigation layers until the final widget is reached. You should provide coordinates for interactions that occur at least two levels deep in the hierarchy to prove the discovery wasn't a one-hop fluke. A valid trace records the 'Settings' click, the 'General' click, and the final 'Timer' entry in a strict, purposeful order.
  - Zero-Loop Discovery Efficiency: For deep hierarchy tasks, the trajectory must achieve the target while visiting a minimal number of irrelevant parent screens. You should audit the action log to ensure the agent didn't recursively visit the same 'Help' page multiple times due to a lack of state awareness. A successful discovery trace minimizes the steps between the starting app view and the final leaf-level functional state to within 1.5x of the golden human path.
