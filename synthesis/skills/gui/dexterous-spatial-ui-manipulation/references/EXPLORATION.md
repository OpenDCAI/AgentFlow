# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Textual Density Auditing. Identify and log GUI regions that are text-dense versus text-sparse. Record whether target spans are isolated or tightly surrounded by distractors to calibrate the required precision for dragging. For example, check if a sentence in a Word doc is surrounded by other lines, which would require tighter start/end coordinate calculations than an isolated text box.
  - Coordinate-to-Span Calibration. Perform test drags in document-centric interfaces (Word, PDF) to determine the 'text snapping' behavior of the current OS. Record how far the cursor can overshoot a word boundary before the selection extends to the next character or line. A concrete case is dragging past the end of a sentence and observing if the selection encompasses the period or jumps to the next line's whitespace.
  - Relational Workspace Calibration. When drawing or manipulating grids, systematically identify the absolute pixel boundaries of the active layout area to establish the origin. Calculate geometric constraints (e.g., center, top-left quadrant) and record bounds so that a user prompt like 'inside the square' can be mathematically satisfied using intersection logic.
  - Drag-and-Drop Portability Probing. Test the relationship between 'Draggable' sources and 'Droppable' targets by attempting to move objects between different application panes. Record which elements provide visual feedback, like a ghost icon or cursor change, during a drag operation to identify the valid action space. For instance, check if a file can be dragged into a browser upload zone versus just being moved within the file manager itself.
  - State-Change Proportionality Probing. Identify continuous widgets like sliders, dials, or scrollbars. Measure the pixel-to-value correlation by dragging the slider a specific distance and recording the resulting numerical or percentage change. For example, verifying that a 50-pixel drag corresponds to a 20% volume increase ensures strict coordinate motor planning.
* **Target Trajectory Profile**:
  - Continuous Range Fidelity. A high-quality trajectory for text-dragging must capture the specific start (x_start, y_start) and end (x_end, y_end) pixels to ensure the exact span is selected. Provide coordinates that fall precisely within or at the edges of the target word bounding boxes. For example, a successful trace should show the cursor starting at the beginning of 'For' and ending exactly after the period following 'Word'.
  - Trajectory Continuity. For movement-based actions like file dragging or shape drawing, the trajectory must capture the transition between point A and point B without coordinate jumps. Provide coordinates for the multi-point mouse-down and mouse-up events to show the physical path taken by the cursor. A file move must definitively document the source coordinates and target coordinates continuously.
  - Geometric Relational Fidelity. When tasked with arranging grid offsets or drawing elements 'inside' others, the calculated mouseUp and mouseDown vectors must mathematically fulfill the constraint. Provide evidence showing that Bounding Box B is completely subsumed by Bounding Box A for 'inside' tasks. For example, a valid trace shows the circle drawing action starting at (X+10, Y+10) where the previous square was generated at (X, Y).
  - State-Change Proportionality. For slider or scale interactions, the trajectory must show a clear correlation between the cursor's movement distance and the resulting value change. Record the initial percentage, the drag distance, and the final percentage to prove the manipulation was purposeful. A good trace would show a move of 100 pixels resulting in a volume increase from 10% to 50%, validating the motor control.
  - Stable End-State Anchoring. The trajectory must terminate with an explicit observation that the final rendered state is visibly maintained on the canvas or screen. Provide a final screenshot or metadata check verifying the object selection, drawn object, or moved file persists in the correct bounds. For example, if a selection fails mid-way and un-highlights, the trajectory represents a dexterity failure.
