# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  * Begin by normalizing the user’s length demand into a measurable target and tolerance policy. Convert words, sentences, or paragraphs into an explicit internal budget, and decide whether the request is a hard ceiling, hard floor, approximate range, or exact target. For example, “less than 487 words” should be handled differently from “around 500 words” because one punishes overflow much more severely.
  * Estimate the minimum semantic load required to satisfy the task before assigning length. This prevents the common failure mode where the agent hits the length target but omits essential content or answer fields. An important edge case is a short answer with mandatory keys, where structure consumes a large fraction of the available budget.
  * For long outputs, decompose the document into sections with local budgets. Assign each section a purpose, a rough token budget, and a continuity dependency on earlier sections if needed. A practical example is a 10,000-word historical article whose introduction, chronology, institutions, decline, and legacy must all have separate budget envelopes.
  * Plan expansion and compression operations before drafting. Decide which details can be added if the text is running short and which details can be trimmed if the text is running long, so the agent does not panic-edit at the end. A useful edge case is keeping one optional example per section that can be removed cleanly without damaging coherence.
* **Target Trajectory Profile**:
  * A good trajectory tracks cumulative length throughout generation rather than checking only once at the end. It should show intermediate progress against the target and allow controlled expansion or contraction. This is especially important in long-form writing, where a late-stage correction often destroys flow.
  * A good trajectory links local section budgets to global document adequacy. Each segment should contribute new information instead of filler, and the trajectory should make clear how much room remains for unresolved content. For instance, if the article is already 80% of target length but has not yet covered the decline of the empire, the trajectory is still poor.
  * A good trajectory preserves semantic density under short constraints. When the budget is tight, the agent should use direct factual phrasing instead of throat-clearing, hedging, or unnecessary transitions. A concrete example is answering a factual prompt with labeled fields rather than with an essay-style introduction.
  * A good trajectory preserves long-range coherence under large constraints. When the budget is large, the agent should extend through planned depth and breadth instead of repetitive paraphrase. An edge case is a draft that reaches the target word count by repeatedly summarizing prior sections, which should not count as a good trajectory.
