# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept a trajectory only if 'Multi-Sensory Grounding' is evident. The agent must integrate at least two distinct sensory tracks (e.g., sight and sound) to create an immersive experience rather than a one-dimensional visual report.
  - Accept a trajectory only if the 'Thematic Echo' is executed as a structural closure. The conclusion must functionally resolve a motif raised in the opening of the document, creating a unified narrative aesthetic.
  - Accept a trajectory only if the final draft achieves zero 'Lexical Saturation' of known AI-robovoice tokens. The plan must show that specialized synonyms and active verbs have replaced generic 'AI slop' (e.g., 'comprehensive,' 'testament,' 'multifaceted').
  - Accept a trajectory only if 'N-gram Diversity' is maximized relative to the target length, indicating a lack of template-like sentence repetition. Success is defined by text where every paragraph opening uses a uniquely orchestrated syntactic structure.
* **Rejection Criteria**:
  - Reject any trajectory that relies on 'General Fluency' as a proxy for 'Professional Quality.' A draft may be grammatically perfect yet fail if it remains rhetorically flat, lacks sensory details, or provides an unearned, generic summary conclusion.
  - Reject any trajectory where 'Semantic Cycling' occurs. Rephrasing the same foundational idea repeatedly to fill space, even with slight synonyms, destroys the stylistic richness parameter.
  - Reject any trajectory that fails the 'Echo Test.' A conclusion that starts with 'In summary' or 'To conclude' and merely lists the preceding body points without elevating the thematic motif is an automatic refusal.
  - Reject any trajectory using 'Forced Rhetoric' where metaphors feel like appended AI-isms. Utilizing a 'sea of knowledge' metaphor when a paper discusses a dry database schema is flagged as catastrophic stylistic failure.
