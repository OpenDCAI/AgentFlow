# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Conduct a 'Sensory Modality Audit' to identify opportunities to ground abstract descriptions in physical reality. You must traverse the five sensory tracks—visual, auditory, tactile, gustatory, and olfactory—and select at least two specific 'anchors' per section (e.g., the 'iron scent' of old machinery). An edge case involves identifying a technical document where sensory detail should be replaced by 'precision metaphors' to explain data without becoming overly flowery.
  - Map 'Thematic Echo Nodes' by identifying a central motif, image, or question in the introduction that can be 'mirrored' in the conclusion. You must explicitly plan the 'Ending Echo' before drafting the body text to ensure the document possesses a circular, unified structure. For example, if an essay starts with a metaphor about a 'blank canvas,' the conclusion must refer back to the 'first brushstroke.'
  - Execute a 'Robovoice Token Scan' to blacklist high-frequency AI linguistic signatures and prepare low-frequency, diverse synonyms. Flag and eliminate words like 'delve,' 'realm,' 'tapestry,' 'pivotal,' and 'underscore.' Search for 'Grounded Verbs' that imply direct action (e.g., 'carves,' 'ignites') rather than abstract enhancement.
  - Calculate a 'Lexical Target Budget' and map 'Synonym Clusters' to prevent semantic cycling. If the user prompt repeats a core theme ('coffee') multiple times, map wide-ranging alternative phrases ('rich brew', 'morning extraction') before drafting. This protects the Type-Token Ratio (TTR) from degrading as document length expands.
* **Target Trajectory Profile**:
  - The trajectory contains an 'Imagery and Rhetoric Ledger' explicitly listing the sensory details to be integrated. It should show the agent rejecting a 'telling' sentence ('The room was scary') and proposing a 'showing' alternative ('The floorboards groaned under a weight that wasn't there').
  - The trajectory documents 'Thematic Mapping' between the start and end of the document. It contains a reasoning step where the agent writes: 'Will introduce the Mountain metaphor in the intro; will return to the View from the Summit in the conclusion.'
  - The trajectory exhibits 'Standardization Resistance' by actively tracking Document Length vs Unique Word Count. It should record the agent noting: 'Length is 300 words with low diversity; I will introduce new, specific technical nouns in the next section to prevent repetitive linguistic looping.'
  - The trajectory demonstrates 'Information-to-Ornamentation Ratio' monitoring. It evaluates if a metaphor is 'forced' or if it clarifies the narrative. An edge case is deciding to delete a personification altogether because it confuses the objective accuracy of an expository draft.
