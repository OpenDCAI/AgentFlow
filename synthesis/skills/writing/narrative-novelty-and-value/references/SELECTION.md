# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept a trajectory only if it specifies a concrete, definable novelty source at the level of premise execution, timeline structure, or tonal move, paired with a recognizable human-value target (humor, aesthetic payoff).
  - Accept a trajectory only if 'Speculative Logic' is 100% consistent throughout the plan. Every effect must have a cause within the world's established rules.
  - Accept a trajectory only if the 'Character Cognition Boundary' is strictly respected across the plot, ensuring no character acts on information or secrets they haven't personally encountered.
  - Accept a trajectory only if 'Multi-Chapter Causal Fidelity' is maintained, where every event in the current segment is a logical consequence of previously established plot points and relationship strengths.
* **Rejection Criteria**:
  - Reject any trajectory that produces only generic story competence using standard, linear, predictable tropes, as clean prose alone is absolutely insufficient.
  - Reject any trajectory where 'Speculative Logic' is sacrificed for 'Plot Convenience' (e.g., characters suddenly gain unestablished capabilities to escape a conflict).
  - Reject any trajectory exhibiting 'Omniscient Drift', where characters suddenly gain knowledge of events they never participated in, indicating a failure to track individual character cognition.
  - Reject any trajectory that treats raw shock value or chaotic structural experimentation (unmotivated timeline jumps, extreme darkness) as a substitute for actual storytelling value.
