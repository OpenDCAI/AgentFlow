# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept a trajectory only if 'Citation Closure' is strictly enforced, meaning 100% of references in the draft map to a verified ID in the session index. The agent must verify that no 'Ghost Citations' (items that look academic but aren't in the provided set) exist in the plan. A positive example is a revision where an agent deletes a plausible-looking citation because it wasn't explicitly retrieved in the current run.
  - Accept a trajectory only if the 'Boundary-Condition Gap' is clearly articulated in the output plan for any missing high-stakes technical metrics. The agent must prove it can identify what it *doesn't* know. An edge case is accepting a plan that answers 3 out of 4 sub-questions but provides a high-confidence disclaimer for the 4th instead of hallucinating a 'best guess' value.
  - Accept a trajectory exclusively if a 'Strict Consistency Criterion' is applied to all citations, verifying Title, Author, Venue, and Year against external records. The agent must prove that it did not just accept a paper because it 'sounded academic' but confirmed its presence in the global scholarly graph. A prime example is a legal or scientific justification where the DOI was resolved to a valid landing page.
  - Accept a trajectory only if 'Confidence Calibration' is evident. Extracted assertions should explicitly mirror the confidence metrics (high vs low) natively listed in the environmental source data. The plan must show that claims derived from 'Tier-4' preprints are couched in more cautious language than those from 'Tier-1' journals like Nature or Optica.
* **Rejection Criteria**:
  - Reject any trajectory that solves retrieval gaps by utilizing 'Parametric Memory Hallucination' to fill in missing numerical specs or dates. If the agent provides a bandwidth of '40 GHz' because it's 'common for this device' but the source doesn't say it, it is a catastrophic failure. In professional photonics or legal assistants, estimating is treated as a major error.
  - Reject any trajectory where 'Citation Decay' occurs, particularly if the agent emits references that are not present in the evidence table. If the Knowledge GPT template produces a reference to 'Smith 2024' but only 'Zhang 2023' was retrieved, the trajectory must be disqualified. This prevents 'Reference Injection'—a subtle form of hallucination.
  - Reject any trajectory that solves 'Source Conflict' by fabricating a middle-ground compromise that neither source supports. If Source A says '10 units' and B says '30 units', a synthesis saying '20 units' without a logical reason is a 'Hallucination of Compromise.' The agent must instead choose the more credible source or report the range as a documented disagreement.
  - Reject any trajectory failing the 'Temporal Filter' defined in the prompt. No knowledge from the 'future' must inadvertently slip into a historically bounded request, such as mentioning 'Large Language Models' in a 1990s computation analysis. This leakage is a disqualifying failure of temporal grounding and era-contextualization.
