# Phase 1: Environment Exploration Guide
* **Exploration Strategy**:
  - Initialize a 'Closed-World Evidence Table' prior to generation where every incoming document chunk is assigned a unique, immutable ID (e.g., DOI + Span Index). You must treat this table as the only legal source of truth. A concrete step involves building a ledger that links specific technical metrics (e.g., 3-dB bandwidth) to their exact passage offsets. An edge case is identifying a 'pay-walled' or 'missing-ID' paper and immediately blacklisting its content to prevent citation corruption.
  - Conduct a 'Boundary-Condition Sensitivity Audit' by identifying high-stakes numerical or technical variables mentioned in the user prompt (e.g., VπL, insertion loss, bitrate). You must verify if the retrieved context contains explicit, verified values for these variables. For instance, if a user asks for a 'total system design,' you must identify which components lack evidence and mark them as 'Evidence Gaps' in your plan. This ensures the output prioritizes 'safety over speculation.'
  - Execute a 'Scholarly Graph Cross-Checking' protocol to query authoritative databases (e.g., Crossref, Google Scholar, PubMed) using extracted citation anchors. You must proactively search for the paper's existence across multiple silos to distinguish between a 'missing paper' and an 'unindexed preprint.' A concrete action is searching by DOI or arXiv ID specifically if the title search yields multiple ambiguous results. This prevents 'False Positives' where a real but niche paper is incorrectly flagged as fake.
  - Establish a 'Temporal Grounding and Cutoff Index' to prevent 'Chronological Anachronisms' in era-restricted documents. You must log the specific year constraints in the prompt and evaluate whether retrieved sources post-date the target era, explicitly ignoring any 'Future Spoilers' that would break the document's historical logic. For example, a 1920s historical draft where the agent must suppress knowledge of the atom bomb. This ensures the output remains epistemically valid.
* **Target Trajectory Profile**:
  - The trajectory MUST document the 'Self-Evaluation of Answerability' scoring each subtopic on a scale (0, 0.25, 0.5, 0.75, 1.0). It should explicitly record the agent noting: 'Confidence score for "Insertion Loss" is 0.25; context is missing specific p-cladding results; will invoke a knowledge-gap disclaimer.' This provides a transparent, auditable trace of the decision to either answer or abstain.
  - A good trajectory contains a 'Deterministic Citation Alignment' step where candidate claims are mapped to Evidence IDs before prose is finalized. It should show the agent rejecting a planned sentence because its supporting DOI was not found in the verified session evidence table. A strong indicator is a trajectory that surgically removes a 'typical' value for an engine's horsepower because it wasn't in the specific manual provided.
  - A good trajectory prioritizes 'Semantic Integrity' over 'Surface Plausibility' when evaluating conflicting claims. It should contain an explicit reasoning sequence where the model compares two sources and selects the one with superior bibliometric authority or neutral motivational standing. For instance, prioritizing a longitudinal academic study over an optimistic industry blog post concerning device performance highlights expert discernment.
  - A good trajectory identifies and flags 'Motivation Incentive Risks' in retrievals. It should document the agent noticing that a whitepaper praising a 100% efficiency rating was published by the manufacturer and flagging it for a 'Reliability Discount' in the synthesis plan. This ensures that 'motivated testimony' does not infect the analytical grounding of the document.
