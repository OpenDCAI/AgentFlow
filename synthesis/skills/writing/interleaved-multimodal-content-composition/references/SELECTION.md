# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept a trajectory only if 'Chart-Text Consistency' is confirmed: every claim in the text must be explicitly supported by the data shown in the immediately preceding or succeeding visualization. The agent must verify that units, categories (e.g., 'Female' vs. 'Male'), and numerical values (e.g., '53.6% median') match exactly across the multimodal boundary. A positive example is a paragraph that mentions a specific 12.6% decline found in the annotated line chart [IMG#13].
  - Accept a trajectory only if 'Decision-Oriented Insight Depth' is achieved, meaning the text moves beyond a surface description of the chart (e.g., 'the line goes down') to explain the 'why' or 'what next' (e.g., 'this downward trend reflects effective cigarette taxation'). The agent must prove the visual evidence catalyzed a deeper analytical step. An edge case is accepting a report where a chart's outlier (e.g., high-GDP, high-emission countries) is used to start a new section on industrial efficiency.
  - Accept a trajectory only if 'Targeted Evidence Grounding' is visible: the visualization request must be fine-grained and intent-aligned rather than generic. The agent should verify that the requested chart specifically targets the variables mentioned in the user's report title. A successful selection involves a request like 'Compare regions by their average monthly sales, excluding those with fewer than 10 records,' showing sophisticated data filtering and intent.
  - Accept a trajectory critically only if the final report exhibits 'Publication-Ready Visual Consistency,' where all charts share a unified design language (palette, font, gridlines). The agent must verify that the visual identity remains professional even across diverse chart types (e.g., from a choropleth map to a divergent bar chart). A success case shows the same primary and secondary colors representing 'Male' and 'Female' across every figure in the 10,000-word report.
  - Accept a trajectory if it demonstrates 'Recursive Evidence Seeking'—recognizing that an initial chart discovery (e.g., a massive regional energy gap) requires a second, follow-up chart (e.g., a GDP-to-access scatter plot) to explain. This iterative construction proves the agent is performing 'Writing-Time Discovery' rather than fulfilling a pre-defined template. This satisfies the high-utility and informativeness metrics found in professional journalism evaluations.
* **Rejection Criteria**:
  - Reject any trajectory that exhibits 'Insight Freezing,' where the agent generates all charts at the start and then writes the text as a separate, unrelated step. This asynchronous behavior causes 'Text-Chart Inconsistency' because the narrative often drifts from the actual visual evidence. A common failure is a report that lists 5 charts at the end of a long text with no in-text interpretation.
  - Reject any trajectory where 'Visual-Textual Discordance' occurs, such as a chart about 'Emissions' being placed after a paragraph about 'Energy Access.' If the multimodal interweaving lacks a logical causal link, the report loses its authoritative 'Analytical Backbone.' This often happens when agents use 'generic' charts that do not match the specific localized claims of the narrative.
  - Reject any trajectory containing 'Index or Content Hallucination,' where the agent references a visual element (e.g., 'the red bar') that is not present in the actual constructed chart. Even if the text is fluent, any mismatch between the prose and the visual datum is a catastrophic grounding failure. A classic example is an agent claiming a trend is 'increasing' when the data in the chart clearly shows a plateau.
  - Reject any trajectory that results in 'Surface-Level Analysis,' where the text only repeats the numbers already visible in the chart legend. If the narrative adds no value beyond what a human could see by looking at the image for one second, the report fails the 'Report-Level Usefulness' standard. High-quality reports must use the visual as a springboard for multi-step reasoning.
  - Reject any trajectory showing 'Momentum Collapse' after a visualization failure. If a code-execution error occurs during chart construction, and the agent simply stops requesting further visuals and reverts to a 'Text-Only' mode, the informativeness of the long-form generation is compromised. The agent must show 'Recovery' techniques like simplifying the chart request or using a different data subset.
