# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept a trajectory only if the 'Incorporation Rate' (for feedback targets) and 'Break Rate' (for unrelated content) are measured and optimized. The agent must prove it achieved Turn t's goal (Inc > 90%) without dropping Turn t-1's content (Brk < 10%). A positive example is a revision that adds a TL;DR summary but yields a 0% break rate on the technical body sections. In many-turn writing, stability is prioritized over minor stylistic flourishes.
  - Accept a trajectory only if 'Citation Integrity' is bidirectionally preserved: every Turn-1 citation marker must survive in the Turn-2 text unless the underlying claim was deleted. The agent must verify that the 'Groundedness' score (ratio of supported claims to total claims) remains stable or improves. An edge case is accepting a revision that replaces a dead link with a fresh URL while keeping the original claim text identical.
  - Accept a trajectory only if 'Multi-Turn Dependency Alignment' is satisfied. IfTurn 3 requested bolding and Turn 4 requested shortening, the final output must show both bolding and shortening. The agent should explicitly check its 'All-History Incorporation Rate' to ensure earlier user formatting preferences didn't 'evaporate' during subsequent content expansions. A failure to show all-round consistency across the revision history is grounds for rejection.
  - Accept a trajectory that uses 'Localized Modifiers' rather than full paragraph regenerations. The final instruction should target a specific 'Anchor' (verbatim sentence) to guide the change. A success case is identified when the agent performs a 'MODIFY' action that replaces only the 15 tokens requested rather than the 500 tokens in the surrounding block.
* **Rejection Criteria**:
  - Reject any trajectory that exhibits 'Global Rewrite Recidivism,' where the agent simply produces a whole new report from scratch given the original question and the new feedback. This 'one-shot' behavior is the primary cause of unreliability in deep research; it habitually loses context-specific nuances and established facts from Turn 1. A report that looks 80% different during a 5% content-change request is a failure of consistency.
  - Reject any trajectory where 'Presentation Regression' occurs, such as a revision that loses Turn 1's formatting (markdown tables, headings) while fixing Turn 2's content. If the user previously asked for parallel heading names and the newest turn reverts them to inconsistent styles, the agent has lost track of the 'Document State.' Revision must be a cumulative positive delta, not a 'one-step-forward, one-step-back' cycle.
  - Reject any trajectory that solves 'Self-Reflection Feedback' by deleting difficult sections to avoid fixing them. If the agent 'reflects' and decides the report is better without the 'Limitations' section because it couldn't find more sources, it is failing the comprehensiveness goal. Professional 'Self-Improvement' requires identifying and *filling* gaps, not erasing the gaps to improve a metric.
  - Reject any trajectory that results in 'Citation Decay,' where the revised report contains fewer in-text markers or a shorter bibliography than the turn before (unless explicitly asked to be more concise). This 'vanishing evidence' is a primary signal of low-integrity revision that damages the scholarly value of the report.
