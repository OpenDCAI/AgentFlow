# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept a trajectory only if the 'Feedback Strategy' (Hint vs. Direct) matches the treatability of the error. Rule-based patterns must receive hints to prompt reflection, while idiosyncratic collocations must receive direct corrections to prevent user frustration. A positive example is giving a hint for a pluralization error but a direct fix for a specialized legal term.
  - Accept a trajectory only if the 'SLOWPR Saturation' is 100%, meaning the audit covers all six dimensions (Structure, Logic, Originality, Writing, Proficiency, Rigor). If the assessment ignores 'Rigor' in a thesis context, it is incomplete and fails the multi-granular requirement. A success case is a report where a student receives six distinct scores and a coherent weight-based holistic judgment.
  - Accept a trajectory only if 'Metalinguistic Depth' is achieved, meaning the explanation addresses 'The Why' (the rule or reason) and not just 'The What' (the location). The agent must provide a rationale that maps to a learner's knowledge gap, such as explaining the difference between 'generic' and 'specific' articles. A failure to provide this reasoning results in a 'Direct Correction only' rejection.
  - Accept a trajectory only if 'Criterion-Specific Justification' is present for every score, using grounded technical terms. The justifying text must reference specific parts of the thesis, such as 'convolutional decomposition' or 'loss function selection,' to prove the audit is not generic. An edge case is rejecting an audit that says 'Writing is good' without citing specific issues like 'inconsistent figure source annotations.'
  - Accept a trajectory only if the 'Actionability Score' of the suggestions is high, providing a clear path for user repair. For macro-flaws like 'Missing Motivation,' the suggestion must include a specific 'Feed Forward' instruction (e.g., 'Try adding a sentence about the current gap in LLM feedback'). Identifying a flaw without a corresponding improvement step is considered an incomplete audit.
* **Rejection Criteria**:
  - Reject any trajectory that provides 'Holistic-Only' scores without fine-grained dimension evaluations. Providing a single 8.0/10 rating for a complex document like an undergraduate thesis is a failure of interpretability and diagnostic value. This 'Generic Score' behavior is a primary signal of low-quality education intelligence.
  - Reject any trajectory where 'Classification-Explanation Discordance' occurs, such as labeling an error as 'Logic' but explaining it as a 'Writing/Grammar' issue. Precision in the label-to-explanation mapping across the SLOWPR framework is mandatory. If the explanation does not logically support the selected SLOWPR tag, the trajectory is broken.
  - Reject any trajectory that solves 'Syntactic Difficulty' by ignoring the user's specific authorial intent or tone. If the critique suggests a change that makes a 'casual' draft sound 'robotic' or 'overly academic,' it violates the persona-alignment constraint. The agent must provide feedback that is within the 'CEFR/HSK' or situational range of the user.
  - Reject any trajectory that performs 'Surface-Level Smoothing' by only fixing grammar while ignoring catastrophic structural omissions. If the agent makes a report 'pretty' but misses that the student didn't include the 'Evaluation' section required by the rubric, the audit is a failure. This reflects the 'AI-slop' failure mode where the model is too polite to be critical.
  - Reject any trajectory that uses 'Generic/Canned AI Prose' (e.g., 'your writing is great but could be more impactful') instead of citing specific quotes. Professional feedback must be 'Targeted, Specific, and Timely.' Any comment that could apply to any essay in any field is rejected for lack of grounding.
