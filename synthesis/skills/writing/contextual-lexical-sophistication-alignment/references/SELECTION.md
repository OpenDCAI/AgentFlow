# Phase 2: Trajectory Selection Criteria
* **Acceptance Metrics**:
  - Accept a trajectory critically only if the PoS Congruence evaluation registers absolute 100% accuracy, meaning the allocated proficiency tier logically mirrors its actual grammatical utilization within the parent sentence. The agent definitively must guarantee that basic A2-level noun descriptors (e.g., 'air') are never artificially inflated by mistakenly cross-referencing them against highly advanced verb counterparts. Anchoring 'point' aggressively as a verb when users request 'to point out flaws' validates the evaluation.
  - Accept a trajectory critically holding fast if it executes Substitution Integrity impeccably, guaranteeing that sweeping register simplifications retain perfect empirical trueness scaling. Any resulting layperson abstraction must factually echo the exact source origin without incorporating out-of-bounds falsities. Embracing 'Heart attack' as a valid translation for 'Myocardial Infarction' passes cleanly because the clinical severity survives, while the generalization 'minor chest ailment' is heavily rejected.
  - Accept a trajectory if Target-Scale Calibration aligns fluently with the requested persona bracket. The agent intrinsically has to document how specific complex variables were intentionally condensed (or fully removed) specifically because they lacked immediate utility for the designated low-proficiency target base. Transparently logging a decision to strip away 'micromillimeter variances' from an explanation aimed squarely at an elementary classroom represents top-tier scaling adaptation.
  - Accept a trajectory conditionally if the Syntactic Complexity (calculated via average dependency distance) scales proportionally within one standard deviation of the targeted human baseline. The auditing agent must verify that the sentence structures demonstrate authentic constraint, remaining short for beginners while blossoming into complex clauses for advanced tiers. Validating that an A2 layman summary entirely omits deep relative clause nesting perfectly authenticates the structural complexity alignment.
  - Accept a trajectory only if the Writing Error Density aligns meticulously with the provided human-learner baseline if a non-native SLA simulation was explicitly requested. If the goal is modeling a beginner learner profile, the trajectory must contain a predictable, measurable number of localized syntactic or lexical missteps. Identifying an essay that balances authentic proficiency markers with exactly three localized prepositional errors signifies a profound mastery of learner persona rendering.
* **Rejection Criteria**:
  - Reject absolutely any trajectory harboring simplistic Lowest-Level Default protocols designed to blindly map all ambiguous word frequencies to elementary A1 grades. Automating the easiest CEFR rank without triggering granular sense disambiguation immediately collapses the precision required to evaluate sophisticated authorship. Arbitrarily classifying the incredibly nuanced verb mechanism 'aim' down to an A2 tier strictly because the primitive noun form 'aim' is ubiquitous warrants harsh dismissal.
  - Reject inherently any trajectory oblivious to creeping Semantic Drift incurred while arbitrarily exchanging baseline language for escalated proficiency synonyms. If elevating an adjective radically warps the authentic sentiment embedded in the source sentence, the precision constraints have thoroughly failed. Inducing artificial 'thesaurus slop' across the sentence structure where oversized vocabulary generates a contextually jarring or emotionally inverted statement mandates immediate rejection.
  - Reject stringently any trajectory that triggers Overspecification by arbitrarily swapping general scientific terms for overly granular, hyper-specific unverified subset examples. Translating 'profound impact on oceanic wildlife' brutally downwards into 'profound impact on Atlantic blue whales' catastrophically reduces the operational breadth of the original empirical data. Introducing localized biases to feign enhanced readability fundamentally breaches factual faithfulness paradigms.
  - Reject unequivocally any trajectory exhibiting the Infallibility Bias when tasked precisely with generating learner-level proficiency texts. Producing a flawless, perfectly constructed 1,000-word essay for a beginner SLA prompt radically breaches the environmental authenticity required for second language acquisition modeling. Discarding essays completely devoid of realistic grammatical turbulence unconditionally forces standard LLMs to abandon their default perfect-prose baseline.
